Lay of the land — this block's toolkit

0 Dimensional Homogeneity & the Method of Repeating Variables

Building on Week 1's introduction to dimensional homogeneity, dimensional analysis is a systematic technique for reducing the number of variables needed to describe a physical problem, by grouping the original (dimensional) variables into a smaller number of dimensionless groups — dramatically reducing the number of experiments needed to fully characterise a physical phenomenon, and revealing the underlying physical structure of a problem.

The fundamental dimensions used throughout fluid mechanics are mass $[M]$, length $[L]$, time $[T]$ (and sometimes temperature $[\Theta]$ for compressible/heat-transfer problems). Every fluid-mechanics variable can be expressed in terms of these: e.g. $[\text{velocity}]=LT^{-1}$, $[\text{density}]=ML^{-3}$, $[\text{viscosity}]=ML^{-1}T^{-1}$, $[\text{force}]=MLT^{-2}$ — the starting point for the Buckingham Pi theorem (Section 1).

Key idea

$$[M],[L],[T] \ \text{(fundamental dimensions)} \qquad [V]=LT^{-1} \quad [\rho]=ML^{-3} \quad [\mu]=ML^{-1}T^{-1} \quad [F]=MLT^{-2}$$

Worked example

Example. Find the dimensions of kinematic viscosity $\nu=\mu/\rho$.

$[\nu]=\dfrac{[\mu]}{[\rho]}=\dfrac{ML^{-1}T^{-1}}{ML^{-3}}=L^2T^{-1}$ — matching the known SI units of m$^2$/s for kinematic viscosity. ✓

Practice 1

Find the dimensions of pressure $P$ (force per unit area).

Solution

$[P]=[F]/[L^2]=MLT^{-2}/L^2=ML^{-1}T^{-2}$.

Practice 2

Find the dimensions of volume flow rate $Q$.

Solution

$[Q]=[L^3]/[T]=L^3T^{-1}$.

Practice 3

Find the dimensions of surface tension $\sigma_s$ (force per unit length, from Week 2).

Solution

$[\sigma_s]=[F]/[L]=MLT^{-2}/L=MT^{-2}$.

Practice 4

Find the dimensions of specific weight $\gamma$ (weight per unit volume, from Week 1).

Solution

$[\gamma]=[F]/[L^3]=MLT^{-2}/L^3=ML^{-2}T^{-2}$.

Practice 5

Verify that the Reynolds number $Re=\rho VD/\mu$ (Week 9) is genuinely dimensionless, by substituting the dimensions of each variable.

Solution

$[Re]=\dfrac{[\rho][V][D]}{[\mu]}=\dfrac{(ML^{-3})(LT^{-1})(L)}{ML^{-1}T^{-1}}=\dfrac{ML^{-1}T^{-1}}{ML^{-1}T^{-1}}=1$ (dimensionless). ✓

Practice 6

Verify that the Darcy friction factor $f$ (Weeks 9-10), defined via $h_L=f(L/D)(V^2/2g)$, is dimensionless by checking that $f$ itself must have no dimensions for the equation to be dimensionally homogeneous.

Solution

$[h_L]=L$ (a head, in metres). $[(L/D)]=1$ (dimensionless, a ratio of two lengths). $[V^2/2g]=(LT^{-1})^2/(LT^{-2})=L^2T^{-2}/(LT^{-2})=L$ (also a length/head). So $[h_L]=[f]\times1\times L\Rightarrow L=[f]\times L\Rightarrow[f]=1$ (dimensionless), confirming $f$ must indeed be dimensionless for the Darcy-Weisbach equation to be dimensionally homogeneous.

1 The Buckingham Pi Theorem

The Buckingham Pi theorem states: if a physical problem involves $n$ dimensional variables, and these variables can be fully described using $k$ fundamental dimensions ($M,L,T$, etc.), then the problem can be expressed using exactly $n-k$ independent dimensionless groups (traditionally denoted $\Pi_1,\Pi_2,\dots$) — a dramatic reduction from, say, needing to test every combination of 6 separate dimensional variables individually, down to characterising the relationship between perhaps only 2 or 3 dimensionless groups.

Standard procedure: (1) list all $n$ relevant dimensional variables; (2) identify $k$, the number of fundamental dimensions involved; (3) choose $k$ repeating variables (typically including a length scale, a velocity scale, and a density or viscosity, chosen to collectively include all $k$ fundamental dimensions among them, and NOT forming a dimensionless group themselves); (4) combine each remaining (non-repeating) variable with the repeating variables to form each $\Pi$ group, solving for the exponents that make each combination dimensionless.

Key idea

$$\text{Number of dimensionless groups} = n-k \qquad n=\text{number of variables}, \quad k=\text{number of fundamental dimensions}$$

Worked example

Example. A problem involves pressure drop $\Delta P$, pipe diameter $D$, velocity $V$, density $\rho$, and viscosity $\mu$ (i.e. $n=5$ variables). Using $M,L,T$ ($k=3$), how many dimensionless groups does the Buckingham Pi theorem predict?

Number of dimensionless groups $=n-k=5-3=2$.

This matches the known result for pipe flow: one group is the friction-factor-related pressure coefficient $\Delta P/(\rho V^2)$ (or a closely related form), and the other is the Reynolds number $Re=\rho VD/\mu$ — exactly the two-variable relationship ($f$ vs $Re$, at fixed $\varepsilon/D$) that underlies the Moody chart (Week 10).

Practice 7

A problem involves drag force $F$, velocity $V$, density $\rho$, and a length scale $L$ (i.e. $n=4$ variables), using $M,L,T$ ($k=3$). How many dimensionless groups does the theorem predict?

Solution

$n-k=4-3=1$ — a single dimensionless group, which turns out to be the drag coefficient $C_D=F/(\rho V^2L^2)$ (or an equivalent form).

Practice 8

A problem involves 6 dimensional variables and requires 3 fundamental dimensions. How many dimensionless groups result?

Solution

$6-3=3$ dimensionless groups.

Practice 9

A capillary rise problem involves height $h$, surface tension $\sigma_s$, density $\rho$, gravitational acceleration $g$, and tube radius $R$ (i.e. $n=5$ variables, $M,L,T$, $k=3$). How many dimensionless groups result?

Solution

$5-3=2$ dimensionless groups.

Practice 10

Explain why choosing 'good' repeating variables (Step 3 of the procedure) is important, specifically why the chosen set must collectively include all $k$ fundamental dimensions, and must NOT themselves be combinable into a dimensionless group.

Solution

The repeating variables serve as the fundamental 'building blocks' used to make every other variable dimensionless; if they don't collectively span all $k$ fundamental dimensions, it becomes impossible to cancel out every dimension when forming each $\Pi$ group (some dimension would be left unaccounted for). If the repeating variables themselves could be combined into a dimensionless group, they would not be dimensionally independent of each other, meaning they couldn't serve as a complete, non-redundant basis for expressing every other variable's dimensions — leading to an inconsistent or incomplete set of resulting $\Pi$ groups.

Practice 11

Explain the main PRACTICAL benefit of reducing, say, a 5-variable problem to just 2 dimensionless groups, in terms of the number of experiments required to fully characterise the phenomenon.

Solution

Characterising a relationship between 5 independent dimensional variables directly would require systematically varying each variable independently while holding the others fixed — an enormous, often practically infeasible number of experiments (e.g. testing even just 10 values of each of 5 variables independently would require $10^5=100{,}000$ experiments). Reducing the same problem to a relationship between just 2 dimensionless groups means only a single experimental curve (one dimensionless group plotted against the other) needs to be determined, requiring perhaps only 10-20 well-chosen experimental data points to fully characterise the same underlying physical relationship — a dramatic, often orders-of-magnitude reduction in required experimental effort, which is precisely the theorem's main practical value.

2 Common Dimensionless Groups

Certain dimensionless groups recur so frequently across fluid mechanics that they have standard names, each representing the ratio of two competing physical effects. Reynolds number $Re=\rho VL/\mu$ (inertia/viscous forces, Week 9) — the single most important group in this subject, governing laminar/turbulent transition and viscous-flow behaviour generally. Froude number $Fr=V/\sqrt{gL}$ (inertia/gravity forces) — governs free-surface (open-channel) flows and wave phenomena, e.g. determining whether an open-channel flow is subcritical or supercritical.

Weber number $We=\rho V^2L/\sigma_s$ (inertia/surface-tension forces) — important for droplet formation, atomisation, and other small-scale free-surface phenomena. Euler number $Eu=\Delta P/(\rho V^2)$ (pressure/inertia forces) — the general form underlying pressure-coefficient and friction-factor-type quantities seen throughout Weeks 6–11. Mach number $M=V/c$ (velocity/speed-of-sound, i.e. inertia/compressibility effects) — governs compressible flow behaviour (largely beyond this subject's scope, but essential context for why the incompressible-flow assumption used throughout this subject is a reasonable one for typical liquid-flow and low-speed gas-flow problems).

Key idea

$$Re=\frac{\rho VL}{\mu} \quad Fr=\frac{V}{\sqrt{gL}} \quad We=\frac{\rho V^2L}{\sigma_s} \quad Eu=\frac{\Delta P}{\rho V^2} \quad M=\frac Vc$$

Worked example

Example. Water flows in an open channel at $V=2$ m/s, depth $L=0.5$ m. Find the Froude number and determine whether the flow is subcritical ($Fr<1$) or supercritical ($Fr>1$).

$Fr=\dfrac{V}{\sqrt{gL}}=\dfrac2{\sqrt{9.81(0.5)}}=\dfrac2{2.215}=0.903$.

$Fr<1$: subcritical flow (relatively slow, deep flow, where gravity effects dominate over inertia — small disturbances can propagate both upstream and downstream, the more common condition in most natural rivers and canals).

Practice 12

$Fr=4/\sqrt{9.81(0.8)}=4/2.802=1.428>1$: supercritical.

A pressure drop of 5 kPa occurs in a flow with density 1000 kg/m$^3$ and velocity 3 m/s. Find the Euler number.

$Eu=\Delta P/(\rho V^2)=5000/(1000\times9)=0.556$.

Practice 15

A high-speed gas flow has velocity 100 m/s, and the local speed of sound is 340 m/s. Find the Mach number, and state whether the flow can reasonably be treated as incompressible (a common rule of thumb: $M<0.3$ is considered acceptably incompressible).

Solution

$M=100/340=0.294<0.3$ — just within the commonly used threshold for treating the flow as approximately incompressible, consistent with the incompressible-flow assumption used throughout the rest of this subject.

Practice 16

Explain the physical significance of the Froude number, in terms of the two competing physical effects (forces) it represents, and why it is the key parameter governing whether a surface wave can travel upstream against a current.

Solution

The Froude number represents the ratio of inertial forces (associated with the flow's own momentum, driving it downstream) to gravitational forces (associated with the restoring/wave-propagation tendency of a free surface under gravity). When $Fr<1$ (subcritical), gravitational/wave effects are strong enough relative to the flow's inertia that a surface disturbance (wave) can propagate upstream against the current, in addition to downstream. When $Fr>1$ (supercritical), the flow's own downstream inertia overwhelms the wave's ability to propagate upstream, so all disturbances are swept downstream only — exactly analogous to the Mach number's role in determining whether disturbances (sound waves) can propagate upstream in a compressible gas flow (subsonic vs supersonic), with the Froude number playing the identical conceptual role for free-surface gravity waves.

Practice 17

Explain why the Weber number becomes particularly important for very SMALL length scales (e.g. small droplets or thin liquid films), but is usually negligible for large-scale flows (e.g. flow in a large river or a large industrial pipe).

Solution

The Weber number is the ratio of inertial to surface-tension forces, $We=\rho V^2L/\sigma_s$; since surface tension forces scale with the LENGTH of the interface (roughly proportional to $L$) while inertial forces scale with volume/mass effects (roughly proportional to $L^3$ for a fixed velocity, or more precisely with the $V^2L$ combination seen in the formula), the RELATIVE importance of surface tension compared to inertia grows rapidly as the length scale $L$ shrinks. For small droplets or thin films (small $L$), surface tension effects become comparably important to (or can even dominate) inertial effects, making $We$ a critical parameter; for large-scale flows (large $L$, e.g. rivers or large pipes), inertial effects overwhelmingly dominate surface tension, making $We$ effectively irrelevant to the flow's overall behaviour.

3 Similarity & Modelling

Similarity between a small-scale physical model (tested in a laboratory, e.g. a wind tunnel or water flume) and the full-size prototype requires three conditions: geometric similarity (identical shape, all linear dimensions scaled by the same ratio), kinematic similarity (velocity fields have the same shape, scaled consistently), and dynamic similarity (all relevant dimensionless groups, e.g. $Re$, $Fr$, match exactly between model and prototype) — the last condition, dynamic similarity, is what actually guarantees that measured forces/coefficients on the model can be reliably scaled up to predict the prototype's behaviour.

In practice, it is often impossible to match every relevant dimensionless group simultaneously (e.g. matching both $Re$ and $Fr$ between a small model and a full-size prototype typically requires physically inconsistent, contradictory fluid properties or velocities) — engineers must then decide which dimensionless group is most physically important for the specific phenomenon being studied (e.g. $Fr$ for free-surface ship-hull wave testing, $Re$ for fully-submerged aerodynamic/pipe-flow testing) and match that group as closely as possible, while accepting some unavoidable, carefully-estimated discrepancy in the other, less critical groups.

Key idea

$$\text{Geometric similarity: shape} \qquad \text{Kinematic similarity: velocity field shape} \qquad \text{Dynamic similarity: matching dimensionless groups } (Re,Fr,\dots)$$

Worked example

Example. A 1:20 scale ship-hull model is tested in a towing tank, matching Froude number (the dominant effect for free-surface/wave-making resistance). If the prototype ship travels at 8 m/s, find the required model test velocity for Froude similarity.

Froude similarity: $Fr_{\text{model}}=Fr_{\text{prototype}}\Rightarrow\dfrac{V_m}{\sqrt{gL_m}}=\dfrac{V_p}{\sqrt{gL_p}}\Rightarrow V_m=V_p\sqrt{\dfrac{L_m}{L_p}}$.

$V_m=8\sqrt{\dfrac1{20}}=8(0.2236)=1.789\ \text{m/s}$ — a much lower test velocity than the full-scale ship's speed, exactly as Froude scaling predicts for a smaller model.

Practice 18

A 1:10 scale model of an open channel is tested for Froude similarity. If the model velocity is 0.5 m/s, find the corresponding prototype velocity.

Solution

$V_p=V_m\sqrt{L_p/L_m}=0.5\sqrt{10}=0.5(3.162)=1.581\ \text{m/s}$.

Practice 19

A 1:5 scale model is tested for Reynolds number similarity, using the SAME fluid as the prototype. Find the required ratio $V_m/V_p$ (using $Re_m=Re_p$ with the same $\rho,\mu$, so $V_mL_m=V_pL_p$).

Practice 21

Explain why Froude similarity is the dominant/chosen criterion for ship-hull model testing (free-surface wave-making resistance), while Reynolds similarity is instead the dominant criterion for fully-submerged submarine or aircraft wind-tunnel testing.

Solution

Ship-hull resistance at the water surface is significantly influenced by wave-making (free-surface gravity wave) effects, which are governed primarily by the Froude number (the ratio of inertial to gravitational forces) — matching $Fr$ ensures the model correctly reproduces the relative wave pattern and wave-making resistance behaviour of the full-size prototype. A fully submerged body (a submarine deep underwater, or an aircraft in flight, away from any free surface) experiences no free-surface wave-making effects at all; its dominant resistance mechanism is instead viscous/pressure drag, governed primarily by the Reynolds number (the ratio of inertial to viscous forces) — so Reynolds similarity, rather than Froude similarity (which becomes essentially irrelevant with no free surface present), is the appropriate criterion to match for such fully-submerged testing.

Practice 22

A 1:8 scale model of a spillway (an open-channel, free-surface structure) is tested using Froude similarity, and the measured model flow rate is $0.15\ \text{m}^3/\text{s}$. Using the fact that flow rate scales as $Q_m/Q_p=(L_m/L_p)^{5/2}$ under Froude similarity (a standard derived result, combining the length-squared area scaling with the square-root velocity scaling), find the corresponding prototype flow rate.

Solution

$Q_p=Q_m(L_p/L_m)^{2.5}=0.15(8)^{2.5}=0.15(181.0)=27.15\ \text{m}^3/\text{s}$.
