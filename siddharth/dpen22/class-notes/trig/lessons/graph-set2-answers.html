Answers (10)

Q1. Start at \(x=-\dfrac{\pi}{2}\): \(\left(-\dfrac{\pi}{2},0\right),(0,2),\left(\dfrac{\pi}{2},0\right),(\pi,-2),\left(\dfrac{3\pi}{2},0\right)\) (or shift the window to \([0,2\pi]\) equivalently). Note \(\sin(x+\pi/2)=\cos x\), so same shape as \(2\cos x\).
Q2. \((\pi,2),\left(\dfrac{3\pi}{2},1\right),(2\pi,0),\left(\dfrac{5\pi}{2},1\right),(3\pi,2)\).
Q3. Max/min swapped vs \(2\cos x\): \((0,-2),\left(\dfrac{\pi}{2},0\right),(\pi,2),\left(\dfrac{3\pi}{2},0\right),(2\pi,-2)\).
Q4. Amp \(3\), period \(\pi\), midline \(1\): \((0,1),\left(\dfrac{\pi}{4},4\right),\left(\dfrac{\pi}{2},1\right),\left(\dfrac{3\pi}{4},-2\right),(\pi,1)\).
Q5. Start \(x=\dfrac{\pi}{6}\): \(\left(\dfrac{\pi}{6},0\right),\left(\dfrac{5\pi}{12},1\right),\left(\dfrac{2\pi}{3},0\right),\left(\dfrac{11\pi}{12},-1\right),\left(\dfrac{7\pi}{6},0\right)\).
Q6. Asymptotes \(x=\pm\dfrac{\pi}{2}\); steeper than \(\tan x\); through \((0,0)\).
Q7. e.g. \(y=5\sin(2x)+2\); points \((0,2),\left(\dfrac{\pi}{4},7\right),\left(\dfrac{\pi}{2},2\right),\left(\dfrac{3\pi}{4},-3\right),(\pi,2)\).
Q8. \(y=\cos x-3\); \((0,-2),\left(\dfrac{\pi}{2},-3\right),(\pi,-4),\left(\dfrac{3\pi}{2},-3\right),(2\pi,-2)\).
Q9. Period \(\dfrac{2\pi}{3}\): \((0,4),\left(\dfrac{\pi}{6},0\right),\left(\dfrac{\pi}{3},-4\right),\left(\dfrac{\pi}{2},0\right),\left(\dfrac{2\pi}{3},4\right)\).
Q10. \((0,2),\left(\dfrac{\pi}{4},1\right),\left(\dfrac{\pi}{2},2\right),\left(\dfrac{3\pi}{4},3\right),(\pi,2)\).
