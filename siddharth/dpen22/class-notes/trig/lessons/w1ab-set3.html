Angles of any magnitude (degrees)

From Week 1B: unit circle, CAST signs, reference angles, exact values beyond \(90^\circ\), and solving trig equations in degrees.

1. Short lesson

On the unit circle, a point \(P\) at angle \( heta\) (from the positive \(x\)-axis, anticlockwise positive) has coordinates \((\cos heta,\sin heta)\). This extends trig ratios to any magnitude, including negatives.

Signs by quadrant (CAST / ASTC): All positive in Q1; Sin positive in Q2; Tan positive in Q3; Cos positive in Q4.

A reference angle is the acute angle between the terminal ray and the \(x\)-axis. Exact values for non-acute angles = (sign from quadrant) × (exact acute value).

To solve equations like \(\sin heta=k\) on \(0^\circ\le heta\le360^\circ\): find the reference angle, then list all solutions in the correct quadrants.

Worked example. \(\sin 150^\circ=\sin 30^\circ=\dfrac12\) (Q2, sin +). \(\cos 210^\circ=-\cos 30^\circ=-\dfrac{\sqrt3}{2}\) (Q3, cos −).

2. Key points summary

  • \(P(\cos\theta,\sin\theta)\) on the unit circle.
  • Positive angles anticlockwise; negative clockwise.
  • Remember CAST for signs.
  • Reference angle is always acute.
  • Axis angles: \(0^\circ,90^\circ,180^\circ,270^\circ,360^\circ\) have simple coordinates.
  • Equation solving: reference angle → correct quadrants → list all in the interval.

3. Formulas & identities

  • \(\sin\theta=y,\ \cos\theta=x,\ \tan\theta=\dfrac{y}{x}\) on the unit circle.
  • Reference angles: Q2: \(180^\circ-\theta\); Q3: \(\theta-180^\circ\); Q4: \(360^\circ-\theta\).
  • \(\sin(180^\circ-\theta)=\sin\theta,\ \cos(180^\circ-\theta)=-\cos\theta\).
  • \(\sin(-\theta)=-\sin\theta,\ \cos(-\theta)=\cos\theta,\ \tan(-\theta)=-\tan\theta\).

4. Practice problems (15)

  1. State the sign of \(\sin\theta\), \(\cos\theta\), \(\tan\theta\) in Quadrant 2.
  2. Find the reference angle for \(150^\circ\).
  3. Find the reference angle for \(240^\circ\).
  4. Find the reference angle for \(-135^\circ\).
  5. Exact value of \(\sin 150^\circ\).
  6. Exact value of \(\cos 210^\circ\).
  7. Exact value of \(\tan 315^\circ\).
  8. Exact value of \(\sin(-90^\circ)\).
  9. Which quadrant contains \(\theta\) if \(\sin\theta<0\) and \(\cos\theta>0\)?
  10. Which quadrant if \(\sec\theta<0\) and \(\cot\theta>0\)?
  11. Solve \(\sin\theta=\dfrac12\) for \(0^\circ\le\theta\le360^\circ\).
  12. Solve \(\cos\theta=-\dfrac{\sqrt3}{2}\) for \(0^\circ\le\theta\le360^\circ\).
  13. Solve \(\tan\theta=1\) for \(0^\circ\le\theta\le360^\circ\).
  14. Solve \(2\sin\theta=-1\) for \(0^\circ\le\theta\le360^\circ\).
  15. Solve \(2\cos\theta=\sqrt{2}\) for \(0^\circ\le\theta\le360^\circ\).
