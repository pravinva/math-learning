Reading features of transformed models

From Week 1D: amplitude, period, phase and midline for multi-parameter sine and cosine models; locate max/min points.

1. Short lesson

For \(y=a\sin(b(x-c))+d\) or \(y=a\cos(bx-c)+d\), list amplitude \(|a|\), period \(\dfrac{2\pi}{|b|}\), phase shift, and midline \(y=d\) before sketching.

A maximum value is \(d+|a|\) and a minimum is \(d-|a|\). For a sine model with \(a\gt 0\), a maximum occurs when the argument equals \(\dfrac{\pi}{2}+2k\pi\); for cosine with \(a\gt 0\), when the argument is \(2k\pi\).

If the form is \(a\sin(bx-c)+d\), rewrite as \(a\sin\!\big(b\big(x-\dfrac{c}{b}\big)\big)+d\) to read the phase shift \(\dfrac{c}{b}\).

Negative \(a\) reflects the graph in the midline: maxima and minima swap roles relative to the unreflected wave.

Worked example. \(y=-3\cos\!\left(2x-\dfrac{\pi}{3}\right)+1\): amp \(3\), period \(\pi\), phase \(\dfrac{\pi}{6}\) right, midline \(y=1\), range \([-2,4]\). A maximum \(4\) occurs when \(\cos(\ldots)=-1\).

2. Key points summary

  • Amplitude \(|a|\); period \(\dfrac{2\pi}{|b|}\); midline \(y=d\).
  • Phase: factor \(b\) out of the angle.
  • Max \(d+|a|\); min \(d-|a|\).
  • Negative \(a\) reflects through the midline.
  • State one max point and one min point when asked.

3. Formulas & identities

  • \(y=a\sin(b(x-c))+d\): amp \(|a|\), period \(\dfrac{2\pi}{|b|}\), phase \(c\), midline \(d\)
  • \(y=a\sin(bx-c)+d\): phase shift \(\dfrac{c}{b}\)
  • Range \([d-|a|,d+|a|]\)
  • For \(a\gt 0\): \(\sin\) max when argument \(\dfrac{\pi}{2}\); \(\cos\) max when argument \(0\)
  • Tangent: period \(\dfrac{\pi}{|b|}\) for \(y=a\tan(bx-c)\)

4. Practice problems (15)

  1. For \(y=5\sin\!\left(3x-\dfrac{\pi}{2}\right)-2\), state amplitude, period, phase shift and midline.
  2. For the model in Q1, state the range and the maximum and minimum values.
  3. Find one \(x\)-coordinate in \([0,2\pi]\) where \(y=5\sin\!\left(3x-\dfrac{\pi}{2}\right)-2\) attains its maximum.
  4. For \(y=-4\cos\!\left(2\!\left(x+\dfrac{\pi}{6}\right)\right)+1\), state amp, period, phase shift, midline.
  5. Find the first positive \(x\) where the model in Q4 attains its minimum value.
  6. For \(y=2\sin\!\left(\dfrac{x}{2}+\dfrac{\pi}{4}\right)\), rewrite in the form \(a\sin\!\big(b(x-c)\big)\) and state phase shift.
  7. State amp, period and midline of \(y=7\cos(4x)+3\), and find max/min \(y\)-values.
  8. For \(y=-2\sin(\pi x)+5\) (period in terms of the variable \(x\)), state amp, period, midline.
  9. How many complete cycles of \(y=3\cos(4x)\) occur on \(0\le x\le 2\pi\)?
  10. For \(y=\tan\!\left(2x-\dfrac{\pi}{3}\right)\), state the period and the first positive asymptote.
  11. Compare \(y=4\sin(2x)\) and \(y=4\sin\!\left(2x-\dfrac{\pi}{2}\right)\): what is the horizontal shift from the first to the second?
  12. For \(y=-6\cos\!\left(x-\dfrac{\pi}{3}\right)+2\), find the coordinates of a maximum point.
  13. State amp, period, phase, midline for \(y=1.5\sin\!\left(6x+\dfrac{\pi}{2}\right)-0.5\).
  14. Find the midline and amplitude of \(y=8-3\cos(5x)\), and explain which way the cosine is reflected.
  15. For \(y=2\cos\!\left(3x+\dfrac{\pi}{2}\right)\), find one \(x\in[0,2\pi]\) where \(y=0\).
