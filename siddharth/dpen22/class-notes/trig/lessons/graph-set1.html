Sketching sin and cos transformations (Set 1)

Dedicated sketching practice: read amplitude, period, phase and midline, then list the five key points for one full cycle.

1. Short lesson

To sketch \(y=a\sin(b(x-c))+d\) or \(y=a\cos(b(x-c))+d\): first read amplitude \(|a|\), period \(\dfrac{2\pi}{|b|}\), phase shift \(c\) (right if \(c>0\)), and midline \(y=d\).

For sine with \(a>0\), one cycle’s five key \(y\)-levels (relative to the midline) are: mid → max → mid → min → mid. For cosine with \(a>0\): max → mid → min → mid → max.

Space the five \(x\)-values evenly using quarter-periods \(\dfrac{T}{4}\). Start at the phase-shifted “beginning” of the cycle, then add \(\dfrac{T}{4}\) four times.

Worked example. For \(y=2\sin\!\left(x-\dfrac{\pi}{2}\right)+1\): \(A=2\), \(T=2\pi\), phase right \(\dfrac{\pi}{2}\), midline \(y=1\). Key points: \(\left(\dfrac{\pi}{2},1\right),(\pi,3),\left(\dfrac{3\pi}{2},1\right),(2\pi,-1),\left(\dfrac{5\pi}{2},1\right)\).

2. Key points summary

  • Always measure max/min from the midline \(y=d\), not from \(y=0\).
  • Period \(T=\dfrac{2\pi}{|b|}\) for sin/cos; \(T=\dfrac{\pi}{|b|}\) for tan.
  • Phase: form \(b(x-c)\) shows shift \(c\) clearly.
  • Sketch one full cycle unless a different interval is asked.
  • Mark asymptotes for tangent graphs.

3. Sketching checklist

  • Amplitude \(=|a|\); midline \(y=d\); range \([d-|a|,d+|a|]\).
  • Period of sin/cos: \(\dfrac{2\pi}{|b|}\).
  • Phase shift from \(a\sin(b(x-c))+d\): right by \(c\) if \(c>0\).
  • Quarter step: \(\dfrac{T}{4}\).

4. Practice problems (10)

  1. Sketch one cycle of \(y=\sin x\) for \(0\le x\le 2\pi\). List the five key points.
  2. Sketch one cycle of \(y=\cos x\) for \(0\le x\le 2\pi\). List the five key points.
  3. Sketch \(y=2\sin x\) on \(0\le x\le 2\pi\). State amplitude and the five key points.
  4. Sketch \(y=\sin(2x)\) on \(0\le x\le\pi\). State period and the five key points.
  5. Sketch \(y=\cos x+2\) on \(0\le x\le 2\pi\). State midline, range and five key points.
  6. Sketch \(y=-\sin x\) on \(0\le x\le 2\pi\). How does the pattern change?
  7. Sketch \(y=3\cos(x)\) on \(0\le x\le 2\pi\). Give amplitude and five key points.
  8. Sketch \(y=\sin\!\left(x-\dfrac{\pi}{2}\right)\) on \(\dfrac{\pi}{2}\le x\le\dfrac{5\pi}{2}\). Give the five key points.
  9. Sketch \(y=2\cos(2x)\) on \(0\le x\le\pi\). State amplitude, period and five key points.
  10. Sketch \(y=\tan x\) on \(-\dfrac{\pi}{2}<x<\dfrac{\pi}{2}\). Mark the asymptotes and the point at \(x=0\).
