Tan graphs

1. Short lesson

Tangent has no amplitude and range \(\mathbb{R}\). The period of \(y=a\tan(bx)\) is \(\dfrac{\pi}{|b|}\).

Vertical asymptotes occur where \(\cos(bx)=0\), i.e. \(bx=\dfrac{\pi}{2}+k\pi\). Always mark them before drawing the curve.

A factor \(a\) stretches vertically (steeper if \(|a|>1\)). A phase \(c\) in \(b(x-c)\) shifts the whole pattern (including asymptotes) right by \(c\). Adding \(d\) lifts the curve so it crosses \(y=d\) where \(\tan=0\).

Worked example. For \(y=2\tan(2x)\): period \(\dfrac{\pi}{2}\); asymptotes \(x=\pm\dfrac{\pi}{4}\); through \((0,0)\); steeper than \(\tan 2x\). Key mid-points: \(\left(-\dfrac{\pi}{8},-2\right),\ (0,0),\ \left(\dfrac{\pi}{8},2\right)\).

2. Key points summary

  • Period of tan: \(\dfrac{\pi}{|b|}\) (half of sin/cos with the same \(b\)).
  • Mark asymptotes first — the curve never crosses them.
  • Negative \(a\) reflects (decreasing through the intercept instead of increasing).
  • Vertical shift \(+d\) moves the \(x\)-intercept up to the midline \(y=d\).

3. Tangent sketching checklist

  • Period of \(a\tan(bx)\): \(\dfrac{\pi}{|b|}\).
  • Asymptotes: \(\cos(bx)=0\Rightarrow bx=\dfrac{\pi}{2}+k\pi\).
  • Key mid-points of one branch: where \(\tan=\pm1\), i.e. angle \(=\pm\dfrac{\pi}{4}\) (then apply \(a\) and \(d\)).
  • Phase form \(a\tan(b(x-c))+d\): shift right by \(c\).

4. Practice problems (5)

  1. Sketch \(y=\tan x\) on \(-\dfrac{\pi}{2}<x<\dfrac{\pi}{2}\). Mark the asymptotes, the point at \(x=0\), and the points where \(y=\pm1\).
  2. Sketch \(y=3\tan x\) on \(-\dfrac{\pi}{2}<x<\dfrac{\pi}{2}\). State the asymptotes and the three key points (where \(\tan=\pm1\) and the intercept).
  3. Sketch \(y=\tan(2x)\) on \(-\dfrac{\pi}{4}<x<\dfrac{\pi}{4}\). State the period, asymptotes and three key points.
  4. Sketch \(y=\tan\!\left(x-\dfrac{\pi}{4}\right)\) between its consecutive asymptotes. State the asymptotes and three key points.
  5. Sketch \(y=-\tan x+1\) on \(-\dfrac{\pi}{2}<x<\dfrac{\pi}{2}\). State the asymptotes, midline and three key points.
