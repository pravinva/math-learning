Phase shift & full transformations

From Week 1D: horizontal shifts / phase, and reading/writing full models \(y=a\sin(b(x-c))+d\).

1. Short lesson

A phase shift appears when the angle is \(b(x-c)\) or \(bx-c\). In the form \(a\sin(b(x-c))+d\), the graph shifts right by \(c\) if \(c>0\).

If written as \(a\sin(bx-c)+d\), the phase shift is \(\dfrac{c}{b}\) (to the right if \(\dfrac{c}{b}>0\)).

When sketching: mark midline, amplitude envelope, period length, then place one key point using the phase shift.

Worked example. \(y=2\sin\!\left(3x-\dfrac{\pi}{2}\right)+1\): amp \(2\), period \(\dfrac{2\pi}{3}\), phase shift \(\dfrac{\pi}{6}\) right, midline \(y=1\).

2. Key points summary

  • Factor \(b\) out of the angle to read phase cleanly.
  • Right shift for \((x-c)\); left for \((x+c)\).
  • List amp, period, phase, midline, range.
  • Check one easy point to verify the sketch.

3. Formulas & identities

  • \(y=a\sin(b(x-c))+d\): amp \(|a|\), period \(\dfrac{2\pi}{|b|}\), phase shift \(c\), midline \(d\)
  • \(y=a\sin(bx-c)+d\): phase shift \(\dfrac{c}{b}\)
  • Range: \([d-|a|, d+|a|]\)

4. Practice problems (15)

  1. State phase shift of \(y=\sin\!\left(x-\dfrac{\pi}{3}\right)\).
  2. State phase shift of \(y=\cos\!\left(x+\dfrac{\pi}{4}\right)\).
  3. For \(y=3\sin\!\left(2x-\dfrac{\pi}{2}\right)\), find amp, period, phase shift.
  4. For \(y=2\cos\!\left(3\!\left(x-\dfrac{\pi}{6}\right)\right)\), find amp, period, phase shift.
  5. State midline and range of \(y=4\sin(x-\pi)-1\).
  6. Write a sine equation with amp \(5\), period \(2\pi\), shift right \(\dfrac{\pi}{2}\), midline \(0\).
  7. Write a cosine equation with amp \(1\), period \(\pi\), shift left \(\dfrac{\pi}{4}\), midline \(2\).
  8. Sketch description: key starting point for \(y=\sin\!\left(x-\dfrac{\pi}{2}\right)\).
  9. Find period and phase of \(y=-\sin\!\left(4x+\pi\right)\).
  10. Does a vertical shift change the period? Explain.
  11. Does a phase shift change the amplitude? Explain.
  12. Match: \(y=\cos x\) equals which phase-shifted sine?
  13. On \([0,2\pi]\), how many peaks does \(y=\sin(3x)\) have?
  14. Find an \(x\)-intercept of \(y=\sin\!\left(x-\dfrac{\pi}{6}\right)\) in \((0,2\pi)\).
  15. State amp, period, phase, midline for \(y=-2\cos\!\left(2x+\dfrac{\pi}{3}\right)+5\).
