Writing models, sketches & solving on graphs

From Week 1D: construct sine/cosine equations from descriptions, give sketch instructions, and solve when a model equals a stated value.

1. Short lesson

To write a model from a description: read amplitude, period (hence \(b=\dfrac{2\pi}{\text{period}}\)), midline \(d\), and phase from a stated starting behaviour (e.g. sine through the midline going up, or cosine at a maximum).

Sketch instructions should name: midline, amplitude envelope, period length, phase placement of one key point, and whether the graph is sine- or cosine-shaped (or reflected).

To solve \(a\sin(bx-c)+d=k\), isolate the trig function, then solve the resulting equation on the required interval using reference angles and CAST (in radians).

More than one equation can fit the same data (e.g. a phase-shifted sine versus a cosine). Prefer the form requested by the question.

Worked example. Amp \(2\), period \(\pi\), midline \(1\), passes through a maximum at \(x=0\): \(y=2\cos(2x)+1\). Solve \(2\cos(2x)+1=0\) on \([0,\pi]\): \(\cos(2x)=-\dfrac12\Rightarrow 2x=\dfrac{2\pi}{3},\dfrac{4\pi}{3}\Rightarrow x=\dfrac{\pi}{3},\dfrac{2\pi}{3}\).

2. Key points summary

  • \(b=\dfrac{2\pi}{\text{period}}\) for sine/cosine.
  • Choose sine or cosine to match a stated key point.
  • Sketch: midline → envelope → one key point → period.
  • To solve \(y=k\): isolate trig, then CAST on the interval.
  • State all solutions in the given domain.

3. Formulas & identities

  • \(y=a\sin(b(x-c))+d\) or \(y=a\cos(b(x-c))+d\)
  • Period \(=\dfrac{2\pi}{|b|}\Rightarrow |b|=\dfrac{2\pi}{\text{period}}\)
  • Solve \(a\sin(\ldots)+d=k\Rightarrow\sin(\ldots)=\dfrac{k-d}{a}\)
  • Range check: if \(\left|\dfrac{k-d}{a}\right|\gt 1\), no solution.

4. Practice problems (15)

  1. Write a sine equation with amplitude \(4\), period \(\dfrac{2\pi}{3}\), phase shift \(\dfrac{\pi}{6}\) right, midline \(y=-1\).
  2. Write a cosine equation with amplitude \(2\), period \(4\pi\), no phase shift, midline \(y=5\), reflected in the midline.
  3. A tide height is modelled by \(h(t)=3\cos\!\left(\dfrac{\pi}{6}t\right)+7\) (metres, \(t\) in hours). State amp, period, midline, and max/min heights.
  4. Using the model in Q3, find the first two times \(t\ge 0\) when \(h(t)=8.5\).
  5. Write a model \(y=a\sin(bx)+d\) with range \([1,7]\) and period \(\pi\).
  6. Describe how to sketch one full cycle of \(y=3\sin\!\left(2x-\dfrac{\pi}{2}\right)+1\) for \(x\) starting at the phase-shifted origin.
  7. Solve \(2\sin x+1=0\) for \(0\le x\le 2\pi\).
  8. Solve \(4\cos(2x)=2\) for \(0\le x\le\pi\).
  9. Solve \(3\sin\!\left(x-\dfrac{\pi}{4}\right)=-\dfrac{3\sqrt2}{2}\) for \(0\le x\le 2\pi\).
  10. Solve \(-2\cos x+3=4\) for \(0\le x\le 2\pi\).
  11. A temperature model \(T(t)=10\sin\!\left(\dfrac{\pi}{12}t\right)+18\) (\(t\) hours after midnight). Find all \(t\in[0,24]\) with \(T(t)=23\).
  12. Write two different equations (one sine, one cosine) for a wave with amp \(1\), period \(2\pi\), midline \(0\), maximum at \(x=\dfrac{\pi}{2}\).
  13. Solve \(\sin(3x)=\dfrac12\) for \(0\le x\le\pi\).
  14. Explain why \(y=2\sin x+5=1\) has no real solution, and find all solutions of \(2\sin x+5=5\) on \([0,2\pi]\).
  15. For \(y=5\cos\!\left(x+\dfrac{\pi}{3}\right)-1\), find all \(x\in[0,2\pi]\) where \(y=1.5\).
