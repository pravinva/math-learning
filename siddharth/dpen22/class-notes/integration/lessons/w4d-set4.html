Reverse chain for linear insides

From Week 4D: multi-step reverse chain rule mentally for forms like \(\int(ax+b)^n\,dx\).

← Lesson sets hub Open Separate Answers Class notes DPEN22 home
4D Set 14D Set 24D Set 34D Set 44D Set 5

1. Short lesson

If the inside is linear \(ax+b\), \(\displaystyle\int(ax+b)^n\,dx=\dfrac{(ax+b)^{n+1}}{a(n+1)}+C\) for \(n\neq -1\).

Check by differentiating: chain rule brings back the factor \(a\).

Same idea for \(\displaystyle\int e^{ax+b}\,dx=\dfrac{1}{a}e^{ax+b}+C\).

Worked example. \(\displaystyle\int(2x+1)^5\,dx=\dfrac{(2x+1)^6}{12}+C\).

2. Key points summary

  • Reverse chain: divide by inner derivative.
  • For \(n=-1\): log form.
  • Verify by differentiating.
  • Watch the constant \(a\).
  • Add \(+C\).

3. Formulas & identities

  • \(\displaystyle\int(ax+b)^n\,dx=\dfrac{(ax+b)^{n+1}}{a(n+1)}+C\)
  • \(\displaystyle\int e^{ax}\,dx=\dfrac{e^{ax}}{a}+C\)
