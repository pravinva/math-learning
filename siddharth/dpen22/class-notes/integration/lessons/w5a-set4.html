Multi-piece definite integrals

From Week 5A: multi-step definite integrals that split into sums or use properties without substitution.

← Lesson sets hub Open Separate Answers Class notes DPEN22 home
5A Set 15A Set 25A Set 35A Set 45A Set 5

1. Short lesson

Split \(\displaystyle\int_a^b(f+g)=\int_a^b f+\int_a^b g\) and evaluate each piece.

Use \(\displaystyle\int_a^b=-\int_b^a\) and additivity over adjacent intervals.

Combine polynomial and simple trig/exp pieces carefully with FTC.

Worked example. \(\displaystyle\int_0^1(x^2+2x)\,dx+\displaystyle\int_1^2 3\,dx=\dfrac43+1+3=\dfrac{16}{3}\).

2. Key points summary

  • Split sums inside the integral.
  • FTC on each antiderivative.
  • Mind the order of limits.
  • Exact fractions.
  • No \(+C\) for definite.

3. Formulas & identities

  • \(\displaystyle\int_a^b f=F(b)-F(a)\)
  • \(\displaystyle\int_a^c+\int_c^b=\int_a^b\)
