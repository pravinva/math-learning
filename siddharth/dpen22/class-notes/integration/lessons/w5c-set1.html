Integrating \(\dfrac{1}{x}\)

From Week 5C: \(\int \dfrac{1}{x}\,dx = \ln|x|+C\).

← Lesson sets hub Open Separate Answers Class notes DPEN22 home
5C Set 15C Set 25C Set 35C Set 45C Set 5

1. Short lesson

The special case \(n=-1\) in the power rule gives \(\displaystyle\int \dfrac{1}{x}\,dx=\ln|x|+C\).

For \(\displaystyle\int \dfrac{f^{\prime}(x)}{f(x)}\,dx=\ln|f(x)|+C\) (reverse of log derivative).

Domain: \(x\neq 0\) for \(\ln|x|\).

Worked example. \(\displaystyle\int \dfrac{2}{x}\,dx=2\ln|x|+C\).

2. Key points summary

  • \(\int \dfrac{1}{x}=\ln|x|+C\)
  • \(\int \dfrac{f^{\prime}}{f}=\ln|f|+C\)
  • Use absolute value in \(\ln\).
  • Check by differentiating.
  • Linear numerator over function.

3. Formulas & identities

  • \(\displaystyle\int \dfrac{1}{x}\,dx=\ln|x|+C\)
  • \(\displaystyle\int \dfrac{f^{\prime}}{f}=\ln|f(x)|+C\)
  • \(\displaystyle\int \dfrac{k}{x}\,dx=k\ln|x|+C\)
