Answers (15)

Q1. Power rule with \(n=-4\).\[\dfrac{d}{dx}x^{-4}=-4x^{-5}=-\dfrac{4}{x^5}.\]\[\boxed{-\dfrac{4}{x^5}}\]
Q2. Write \(\dfrac{1}{x^3}=x^{-3}\).\[\dfrac{d}{dx}x^{-3}=-3x^{-4}=-\dfrac{3}{x^4}.\]\[\boxed{-\dfrac{3}{x^4}}\]
Q3. Write \(\sqrt[3]{x}=x^{1/3}\).\[\dfrac{d}{dx}x^{1/3}=\dfrac{1}{3}x^{-2/3}=\dfrac{1}{3x^{2/3}}.\]\[\boxed{\dfrac{1}{3x^{2/3}}}\]
Q4. Power rule with \(n=\dfrac{5}{2}\).\[\dfrac{d}{dx}x^{5/2}=\dfrac{5}{2}x^{3/2}.\]\[\boxed{\dfrac{5}{2}x^{3/2}}\]
Q5. Write \(\dfrac{3}{\sqrt{x}}=3x^{-1/2}\).\[\dfrac{d}{dx}(3x^{-1/2})=3\cdot\left(-\dfrac{1}{2}\right)x^{-3/2}=-\dfrac{3}{2}x^{-3/2}.\]\[\boxed{-\dfrac{3}{2x^{3/2}}}\]
Q6. Differentiate term by term.\[\dfrac{d}{dx}(4x^{-2}+x^{1/2})=-8x^{-3}+\dfrac{1}{2}x^{-1/2}=-\dfrac{8}{x^3}+\dfrac{1}{2\sqrt{x}}.\]\[\boxed{-\dfrac{8}{x^3}+\dfrac{1}{2\sqrt{x}}}\]
Q7. Write \(x\sqrt{x}=x^{3/2}\).\[\dfrac{d}{dx}x^{3/2}=\dfrac{3}{2}x^{1/2}=\dfrac{3}{2}\sqrt{x}.\]\[\boxed{\dfrac{3}{2}\sqrt{x}}\]
Q8. Split: \(\dfrac{x^2+1}{x}=x+x^{-1}\).\[\dfrac{d}{dx}(x+x^{-1})=1-x^{-2}=1-\dfrac{1}{x^2}.\]\[\boxed{1-\dfrac{1}{x^2}}\]
Q9. Constant multiple and power rule.\[\dfrac{d}{dx}(2x^{7/3})=2\cdot\dfrac{7}{3}x^{4/3}=\dfrac{14}{3}x^{4/3}.\]\[\boxed{\dfrac{14}{3}x^{4/3}}\]
Q10. Write as \(5x^{-2}-x^{-1}\).\[\dfrac{d}{dx}(5x^{-2}-x^{-1})=-10x^{-3}+x^{-2}=-\dfrac{10}{x^3}+\dfrac{1}{x^2}.\]\[\boxed{-\dfrac{10}{x^3}+\dfrac{1}{x^2}}\]
Q11. For \(x\ge 0\), \(\sqrt{x^3}=x^{3/2}\).\[\dfrac{d}{dx}x^{3/2}=\dfrac{3}{2}x^{1/2}.\]\[\boxed{\dfrac{3}{2}\sqrt{x}}\]
Q12. Term by term.\[\dfrac{d}{dx}(x^{-1/2}+3x)=-\dfrac{1}{2}x^{-3/2}+3.\]\[\boxed{-\dfrac{1}{2}x^{-3/2}+3}\]
Q13. Write \(\dfrac{1}{2}x^{-5}\).\[\dfrac{d}{dx}\!\left(\dfrac{1}{2}x^{-5}\right)=\dfrac{1}{2}(-5)x^{-6}=-\dfrac{5}{2x^6}.\]\[\boxed{-\dfrac{5}{2x^6}}\]
Q14. Power rule.\[\dfrac{d}{dx}(6x^{2/5})=6\cdot\dfrac{2}{5}x^{-3/5}=\dfrac{12}{5}x^{-3/5}.\]\[\boxed{\dfrac{12}{5}x^{-3/5}}\]
Q15. Split: \(x-2x^{-2}\).\[\dfrac{d}{dx}(x-2x^{-2})=1+4x^{-3}=1+\dfrac{4}{x^3}.\]\[\boxed{1+\dfrac{4}{x^3}}\]
