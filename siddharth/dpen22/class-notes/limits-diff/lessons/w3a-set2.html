Power rule, constant multiple & sum rule

From Week 3A: differentiate polynomials using \(\dfrac{d}{dx}x^n=nx^{n-1}\), constant multiple and sum rules.

1. Short lesson

The power rule: \(\dfrac{d}{dx}x^n=nx^{n-1}\) for real \(n\) (in this course, mainly integer \(n\)).

Constant multiple: \(\dfrac{d}{dx}[cf(x)]=c\,f^{\prime}(x)\). Sum rule: \(\dfrac{d}{dx}[f(x)+g(x)]=f^{\prime}(x)+g^{\prime}(x)\).

Differentiate term-by-term for polynomials. Constants differentiate to \(0\).

Worked example. \(\dfrac{d}{dx}(3x^4-5x^2+7)=12x^3-10x\).

2. Key points summary

  • Power rule on each term.
  • Constants \(\to 0\).
  • Pull constants out (multiple rule).
  • Differentiate sums term by term.
  • Simplify before differentiating when helpful.

3. Formulas & identities

  • \(\dfrac{d}{dx}x^n=nx^{n-1}\)
  • \(\dfrac{d}{dx}c=0\)
  • \(\dfrac{d}{dx}[cf]=c\,f^{\prime}\)
  • \(\dfrac{d}{dx}[f+g]=f^{\prime}+g^{\prime}\)
