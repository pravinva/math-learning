Answers (15)

Q1. Rewrite using \(\sin u/u\) with \(u=5x\).\[\lim_{x\to 0}\dfrac{\sin(5x)}{x}=\lim_{x\to 0}5\cdot\dfrac{\sin(5x)}{5x}=5\cdot 1=5.\]\[\boxed{5}\]
Q2. Write each sine over its argument.\[\lim_{x\to 0}\dfrac{\sin(2x)}{\sin(3x)}=\lim_{x\to 0}\dfrac{\sin(2x)}{2x}\cdot\dfrac{3x}{\sin(3x)}\cdot\dfrac{2}{3}=\dfrac{2}{3}.\]\[\boxed{\dfrac{2}{3}}\]
Q3. Multiply by \(1+\cos x\), or use \(\dfrac{1-\cos x}{x}=\dfrac{\sin^2 x}{x(1+\cos x)}\).\[\lim_{x\to 0}\dfrac{1-\cos x}{x}=\lim_{x\to 0}\dfrac{\sin^2 x}{x(1+\cos x)}=\lim_{x\to 0}\sin x\cdot\dfrac{\sin x}{x}\cdot\dfrac{1}{1+\cos x}=0.\]\[\boxed{0}\]
Q4. Write \(\tan x=\dfrac{\sin x}{\cos x}\).\[\lim_{x\to 0}\dfrac{\tan x}{x}=\lim_{x\to 0}\dfrac{\sin x}{x}\cdot\dfrac{1}{\cos x}=1\cdot 1=1.\]\[\boxed{1}\]
Q5. For \(x>0\), \(|x|=x\).\[\lim_{x\to 0^+}\dfrac{|x|}{x}=\lim_{x\to 0^+}\dfrac{x}{x}=1.\]\[\boxed{1}\]
Q6. For \(x<0\), \(|x|=-x\).\[\lim_{x\to 0^-}\dfrac{|x|}{x}=\lim_{x\to 0^-}\dfrac{-x}{x}=-1.\]\[\boxed{-1}\]
Q7. Divide top and bottom by \(x^3\).\[\lim_{x\to\infty}\dfrac{2-1/x^2}{5+4/x^3}=\dfrac{2}{5}.\]\[\boxed{\dfrac{2}{5}}\]
Q8. Divide by \(x^2\).\[\lim_{x\to -\infty}\dfrac{3+1/x^2}{1-1/x}=3.\]\[\boxed{3}\]
Q9. As \(x\to 1^+\), numerator \(\to 3\) and denominator \(\to 0^+\).\[\lim_{x\to 1^+}\dfrac{x+2}{x-1}=+\infty.\]\[\boxed{+\infty}\]
Q10. As \(x\to 1^-\), denominator \(\to 0^-\).\[\lim_{x\to 1^-}\dfrac{x+2}{x-1}=-\infty.\]\[\boxed{-\infty}\]
Q11. Split the fraction.\[\lim_{x\to 0}\dfrac{\sin x}{x\cos x}=\lim_{x\to 0}\dfrac{\sin x}{x}\cdot\dfrac{1}{\cos x}=1.\]\[\boxed{1}\]
Q12. Rationalise (or factor \(x\) out of the square root for \(x>0\)).\[\lim_{x\to\infty}\left(\sqrt{x^2+4x}-x\right)=\lim_{x\to\infty}\dfrac{4x}{\sqrt{x^2+4x}+x}=\lim_{x\to\infty}\dfrac{4}{\sqrt{1+4/x}+1}=2.\]\[\boxed{2}\]
Q13. Write \(\dfrac{\sin(x^2)}{x}=x\cdot\dfrac{\sin(x^2)}{x^2}\).\[\lim_{x\to 0}x\cdot\dfrac{\sin(x^2)}{x^2}=0\cdot 1=0.\]\[\boxed{0}\]
Q14. \(|x\sin x|\le|x|\) and \(\dfrac{|x|}{x^2+1}\to 0\), so by squeeze the limit is \(0\).\[\left|\dfrac{x\sin x}{x^2+1}\right|\le\dfrac{|x|}{x^2+1}\to 0\Rightarrow\lim_{x\to\infty}\dfrac{x\sin x}{x^2+1}=0.\]\[\boxed{0}\]
Q15. Rewrite using \(\sin(4x)/(4x)\).\[\lim_{x\to 0}\dfrac{x}{\sin(4x)}=\lim_{x\to 0}\dfrac{1}{4}\cdot\dfrac{4x}{\sin(4x)}=\dfrac{1}{4}.\]\[\boxed{\dfrac{1}{4}}\]
