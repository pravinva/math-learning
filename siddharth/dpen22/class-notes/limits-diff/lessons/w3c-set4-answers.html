Q1. Rewrite as \((3x+1)^{12}\) or nest chain.\[\dfrac{d}{dx}(3x+1)^{12}=12(3x+1)^{11}\cdot 3=36(3x+1)^{11}.\]\[\boxed{36(3x+1)^{11}}\]
Q2. Write \(((2x+1)^3)^{1/2}=(2x+1)^{3/2}\).\[\dfrac{3}{2}(2x+1)^{1/2}\cdot 2=3\sqrt{2x+1}.\]\[\boxed{3\sqrt{2x+1}}\]
Q3. Quotient with chain on numerator.\[u=(x+1)^2,\ u^{\prime}=2(x+1),\ v=x-1,\ v^{\prime}=1.\]\[\dfrac{2(x+1)(x-1)-(x+1)^2}{(x-1)^2}=\dfrac{(x+1)\bigl[2(x-1)-(x+1)\bigr]}{(x-1)^2}=\dfrac{(x+1)(x-3)}{(x-1)^2}.\]\[\boxed{\dfrac{(x+1)(x-3)}{(x-1)^2}}\]
Q4. Chain: write \((x^2+1)^{-3}\).\[-3(x^2+1)^{-4}\cdot 2x=-\dfrac{6x}{(x^2+1)^4}.\]\[\boxed{-\dfrac{6x}{(x^2+1)^4}}\]
Q5. Note \(x^2+2x+1=(x+1)^2\), so for \(x\ge -1\), \(\sqrt{\,\cdot\,}=|x+1|\). Differentiating \((x+1)^2)^{1/2}\) via chain:\[\dfrac{2x+2}{2\sqrt{x^2+2x+1}}=\dfrac{x+1}{|x+1|}\ \text{(or }\operatorname{sign}(x+1)\text{)}.\]Alternatively leave as \(\dfrac{x+1}{\sqrt{(x+1)^2}}\).\[\boxed{\dfrac{x+1}{|x+1|}\ (x\neq -1)}\]
Q6. Quotient + chain on denominator.\[u=x,\ u^{\prime}=1,\ v=(2x+1)^2,\ v^{\prime}=4(2x+1).\]\[\dfrac{(2x+1)^2-x\cdot 4(2x+1)}{(2x+1)^4}=\dfrac{(2x+1)-4x}{(2x+1)^3}=\dfrac{1-2x}{(2x+1)^3}.\]\[\boxed{\dfrac{1-2x}{(2x+1)^3}}\]
Q7. Product + chain.\[2(x^2+1)\cdot 2x\cdot(3x-1)+(x^2+1)^2\cdot 3=4x(x^2+1)(3x-1)+3(x^2+1)^2.\]\[\boxed{4x(x^2+1)(3x-1)+3(x^2+1)^2}\]
Q8. \[u=(2x-1)^3,\ u^{\prime}=6(2x-1)^2,\ v=x.\]\[\dfrac{6(2x-1)^2\cdot x-(2x-1)^3}{x^2}=\dfrac{(2x-1)^2\bigl[6x-(2x-1)\bigr]}{x^2}=\dfrac{(2x-1)^2(4x+1)}{x^2}.\]\[\boxed{\dfrac{(2x-1)^2(4x+1)}{x^2}}\]
Q9. Write \((5x-2)^{2/3}\).\[\dfrac{2}{3}(5x-2)^{-1/3}\cdot 5=\dfrac{10}{3(5x-2)^{1/3}}.\]\[\boxed{\dfrac{10}{3(5x-2)^{1/3}}}\]
Q10. \[u=x^{1/2},\ u^{\prime}=\dfrac{1}{2\sqrt{x}},\ v=x+2.\]\[\dfrac{\dfrac{x+2}{2\sqrt{x}}-\sqrt{x}}{(x+2)^2}=\dfrac{x+2-2x}{2\sqrt{x}(x+2)^2}=\dfrac{2-x}{2\sqrt{x}(x+2)^2}.\]\[\boxed{\dfrac{2-x}{2\sqrt{x}(x+2)^2}}\]
Q11. \[-2(1-4x)^{-3}\cdot(-4)=8(1-4x)^{-3}.\]\[\boxed{8(1-4x)^{-3}}\]
Q12. \[u^{\prime}=2x,\ v^{\prime}=2(x+1).\]\[\dfrac{2x(x+1)^2-(x^2+1)\cdot 2(x+1)}{(x+1)^4}=\dfrac{2(x+1)\bigl[x(x+1)-(x^2+1)\bigr]}{(x+1)^4}=\dfrac{2(x-1)}{(x+1)^3}.\]\[\boxed{\dfrac{2(x-1)}{(x+1)^3}}\]
Q13. Chain with inner \(1+\dfrac{1}{2\sqrt{x}}\).\[4\bigl(x+\sqrt{x}\bigr)^3\left(1+\dfrac{1}{2\sqrt{x}}\right).\]\[\boxed{4(x+\sqrt{x})^3\left(1+\dfrac{1}{2\sqrt{x}}\right)}\]
Q14. Write \((3x+1)^{-1/2}\).\[-\dfrac{1}{2}(3x+1)^{-3/2}\cdot 3=-\dfrac{3}{2}(3x+1)^{-3/2}.\]\[\boxed{-\dfrac{3}{2}(3x+1)^{-3/2}}\]
Q15. \[u^{\prime}=2(x-1),\ v^{\prime}=3(x+1)^2.\]\[\dfrac{2(x-1)(x+1)^3-(x-1)^2\cdot 3(x+1)^2}{(x+1)^6}=\dfrac{(x-1)(x+1)^2\bigl[2(x+1)-3(x-1)\bigr]}{(x+1)^6}=\dfrac{(x-1)(5-x)}{(x+1)^4}.\]\[\boxed{\dfrac{(x-1)(5-x)}{(x+1)^4}}\]
