Answers (15)

Q1. Point \((0,1)\), \(y^{\prime}=2e^{2x}\), \(m=2\).\[y-1=2(x-0)\Rightarrow y=2x+1.\]\[\boxed{y=2x+1}\]
Q2. Point \((1,e)\), \(m=e\).\[y-e=e(x-1)\Rightarrow y=ex.\]\[\boxed{y=ex}\]
Q3. Point \((0,3)\), \(y^{\prime}=-3e^{-x}\), \(m=-3\).\[y-3=-3x\Rightarrow y=-3x+3.\]\[\boxed{y=-3x+3}\]
Q4. Point \((0,1)\), tangent slope \(1\), normal slope \(-1\).\[y-1=-1(x-0)\Rightarrow y=-x+1.\]\[\boxed{y=-x+1}\]
Q5. \(y^{\prime}=3e^{3x}\), so at \(x=\ln 2\): \(3e^{3\ln 2}=3\cdot 8=24\).\[\boxed{24}\]
Q6. Point \((0,3)\), \(m=2\).\[y-3=2x\Rightarrow y=2x+3.\]\[\boxed{y=2x+3}\]
Q7. Point \((1,e)\), \(y^{\prime}=2xe^{x^2}\), \(m=2e\).\[y-e=2e(x-1).\]\[\boxed{y-e=2e(x-1)}\]
Q8. Point \((0,1)\), \(m=-2\), normal slope \(\dfrac12\).\[y-1=\dfrac12 x\Rightarrow y=\dfrac12 x+1.\]\[\boxed{y=\dfrac{1}{2}x+1}\]
Q9. Point \((0,0)\), \(y^{\prime}=e^x+xe^x=(1+x)e^x\), \(m=1\).\[y=x.\]\[\boxed{y=x}\]
Q10. Point \((0,2)\), \(y^{\prime}=e^x-e^{-x}\), \(m=0\).\[y=2.\]\[\boxed{y=2}\]
Q11. \(y^{\prime}=20e^{4x}=20\Rightarrow e^{4x}=1\Rightarrow x=0\).\[\boxed{x=0}\]
Q12. Point \(\bigl(\tfrac12,1\bigr)\), \(m=2e^{2x-1}=2\).\[y-1=2\bigl(x-\tfrac12\bigr)\Rightarrow y=2x.\]\[\boxed{y=2x}\]
Q13. Point \((a,e^a)\), \(m=e^a\).\[y-e^a=e^a(x-a)\Rightarrow y=e^a(x-a+1).\]\[\boxed{y=e^{a}(x-a+1)}\]
Q14. Point \((0,2)\), \(y^{\prime}=2e^x-1\), \(m=1\).\[y-2=x\Rightarrow y=x+2.\]\[\boxed{y=x+2}\]
Q15. Point \((0,1)\), \(y^{\prime}=-e^{-x}+1\), \(m=0\) — horizontal tangent, so normal is vertical \(x=0\).\[\boxed{x=0}\]
