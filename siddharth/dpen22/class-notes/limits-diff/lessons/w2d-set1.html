1. Short lesson

The limit \(\displaystyle\lim_{x\to a} f(x)\) describes the value \(f(x)\) approaches as \(x\) gets close to \(a\) (from either side). It may exist even when \(f(a)\) is undefined.

If \(f\) is continuous at \(a\), then \(\displaystyle\lim_{x\to a} f(x)=f(a)\). This is direct substitution: plug in \(x=a\) after checking the function is well-behaved there.

Use tables or graphs to estimate limits when an expression is awkward; exact work often starts with substitution, then algebra if you get an indeterminate form.

Worked example. \(\displaystyle\lim_{x\to 3}(2x^2-5)=2(9)-5=13\).

2. Key points summary

  • Limit notation uses \(x\to a\), not \(x=a\).
  • Continuous functions: substitute \(x=a\).
  • A limit can exist when \(f(a)\) does not.
  • Estimate from a graph or table when needed.
  • Indeterminate forms such as \(\frac00\) need other methods (next sets).

3. Key limit results

  • \(\displaystyle\lim_{x\to a} f(x)=L\) means \(f(x)\to L\) as \(x\to a\)
  • If \(f\) continuous at \(a\): \(\displaystyle\lim_{x\to a} f(x)=f(a)\)
  • \(\displaystyle\lim_{x\to c} k = k\) for constant \(k\)
  • \(\displaystyle\lim_{x\to 0}\frac{\sin x}{x}=1\)
