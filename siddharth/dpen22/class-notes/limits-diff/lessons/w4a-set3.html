Mixed log, exponential & trig derivatives

From Week 4A: combine rules on functions involving \(e^x\), \(\ln x\), and trig.

← Lesson sets hub Open Separate Answers Class notes DPEN22 home
4A Set 14A Set 24A Set 3

1. Short lesson

Identify which rule applies to each factor: exponential, log, trig, product, quotient, chain.

Mixed problems are common on tests — organise work clearly.

Simplify using identities (\(\sin^2+\cos^2=1\), log laws) only when it helps.

Worked example. \(\dfrac{d}{dx}[x e^x]=e^x+x e^x\); \(\dfrac{d}{dx}[\ln(\cos x)]=-\tan x\).

2. Key points summary

  • Pick the right rule per term.
  • Chain on compositions.
  • Product/quotient when needed.
  • Check domain (log, tan).
  • Factor final answers when neat.

3. Formulas & identities

  • \(\dfrac{d}{dx}e^{f}=f^{\prime}e^{f}\)
  • \(\dfrac{d}{dx}\ln f=\dfrac{f^{\prime}}{f}\)
  • \(\dfrac{d}{dx}\sin f=f^{\prime}\cos f\)
