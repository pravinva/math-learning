Block Substitution Drill — Questions

Two sets of eight proofs. Every one is finished in two or three lines by replacing a Pythagorean or double-angle block with its single-term equivalent, then cancelling. Every one becomes a five-step grind if you convert to sines and cosines first.

Why this drill exists

Five questions were lost on the main proof tests, and they are all the same question wearing different clothes:

  • Set 1 Q1 — \(\dfrac{1-\cos^2x}{\sin x}\), where \(1-\cos^2x\) is \(\sin^2x\)
  • Set 1 Q6 — \(\dfrac{1-\cos 2x}{\sin 2x}\), where the two blocks are \(2\sin^2x\) and \(2\sin x\cos x\)
  • Set 3 Q1 — \(\dfrac{1-\cos^2x}{\cos^2x}\), again \(1-\cos^2x=\sin^2x\)
  • Set 3 Q4 — \(\dfrac{\sec^2x-1}{\sec^2x}\), where \(\sec^2x-1\) is \(\tan^2x\)
  • Set 3 Q5 — \(\dfrac{\csc^2x-1}{\csc^2x}\), where \(\csc^2x-1\) is \(\cot^2x\)

In each case the expression contains a block that collapses to one term. Expanding everything into sines and cosines does eventually work, and it still needs the same identity buried three lines further down, with more algebra stacked on top and more places to drop a sign.

The scan to run before writing anything

Read the expression once and check these four things in order. Stop at the first hit.

  1. Is there \(1-\cos^2x\) or \(1-\sin^2x\)? Replace with \(\sin^2x\) or \(\cos^2x\).
  2. Is there \(\sec^2x-1\), \(\csc^2x-1\), \(1+\tan^2x\) or \(1+\cot^2x\)? Replace with \(\tan^2x\), \(\cot^2x\), \(\sec^2x\), \(\csc^2x\).
  3. Is there \(1\pm\cos 2x\) or \(\sin 2x\)? Replace with \(2\sin^2x\), \(2\cos^2x\) or \(2\sin x\cos x\).
  4. Only if none of those appear, convert to sines and cosines.

The nine blocks

Each left-hand form is worth one mark of recognition. Learn to see the whole left column as a single object.

When you see this blockWrite thisWhat tips you off
Pythagorean, sine and cosine
\(1-\cos^2x\)\(\sin^2x\)A 1 sitting beside a lone squared cosine
\(1-\sin^2x\)\(\cos^2x\)A 1 sitting beside a lone squared sine
Pythagorean, the tan and cot families
\(\sec^2x-1\)\(\tan^2x\)Squared secant with a 1 subtracted
\(1+\tan^2x\)\(\sec^2x\)Squared tangent with a 1 added
\(\csc^2x-1\)\(\cot^2x\)Squared cosecant with a 1 subtracted
\(1+\cot^2x\)\(\csc^2x\)Squared cotangent with a 1 added
Double angle and power reduction
\(1-\cos 2x\)\(2\sin^2x\)A doubled angle after a minus sign
\(1+\cos 2x\)\(2\cos^2x\)A doubled angle after a plus sign
\(\sin 2x\)\(2\sin x\cos x\)Any doubled angle in a sine

Two ratios worth memorising as finished results, since they close out several of the questions below: \(\dfrac{\tan^2x}{\sec^2x}=\sin^2x\) and \(\dfrac{\cot^2x}{\csc^2x}=\cos^2x\).

Set A — Substitute the block

8 questions · suggested time: 20 minutes · target 3 lines each
  • Name the block you are substituting before you write the first line.
  • Your first line must be a block substitution. Writing \(\sin x/\cos x\) on line one costs the method mark even when the final answer is right.
  • Work on the left-hand side only, until it becomes the right-hand side.
  • If a proof runs past four lines, stop, go back to the scan, and start again.
  1. Prove \(\displaystyle \frac{1-\sin^2x}{\cos x}=\cos x.\)[2 marks]
  2. Prove \(\displaystyle \frac{\csc^2x-1}{\cot x}=\cot x.\)[2 marks]
  3. Prove \(\displaystyle \frac{1+\tan^2x}{\sec x}=\sec x.\)[2 marks]
  4. Prove \(\displaystyle \frac{1-\cos^2x}{1-\sin^2x}=\tan^2x.\)[3 marks]
  5. Prove \(\displaystyle \frac{\sec^2x-1}{\csc^2x-1}=\tan^4x.\)[3 marks]
  6. Prove \(\displaystyle \frac{1+\cos 2x}{1-\cos 2x}=\cot^2x.\)[3 marks]
  7. Prove \(\displaystyle \frac{\sin 2x}{1-\cos 2x}=\cot x.\)[3 marks]
  8. Prove \(\displaystyle \frac{1+\cot^2x}{\cot^2x}=\sec^2x.\)[3 marks]

Set B — Substitute the block (second pass)

8 questions · suggested time: 20 minutes · target 3 lines each
  • Same skills as Set A, with the sine and cosine roles swapped so recognition cannot run on memory of Set A.
  • Name the block first. First line must be the substitution.
  • Sit this one on a different day from Set A.
  1. Prove \(\displaystyle \frac{1-\cos^2x}{\cos x}=\sin x\tan x.\)[3 marks]
  2. Prove \(\displaystyle (\sec^2x-1)\cot x=\tan x.\)[2 marks]
  3. Prove \(\displaystyle \frac{1+\cot^2x}{\csc x}=\csc x.\)[2 marks]
  4. Prove \(\displaystyle \frac{1-\sin^2x}{1-\cos^2x}=\cot^2x.\)[3 marks]
  5. Prove \(\displaystyle \frac{\csc^2x-1}{\sec^2x-1}=\cot^4x.\)[3 marks]
  6. Prove \(\displaystyle \frac{1-\cos 2x}{1+\cos 2x}=\tan^2x.\)[3 marks]
  7. Prove \(\displaystyle \frac{1+\cos 2x}{\sin 2x}=\cot x.\)[3 marks]
  8. Prove \(\displaystyle \frac{1+\tan^2x}{\tan^2x}=\csc^2x.\)[3 marks]

Marking yourself: award the method mark only when line one is a block substitution. A correct answer reached by converting everything to sines and cosines scores the answer and loses the method, because the same approach on a longer question in an exam runs out of time. Worked answers show the short route and, beside it, the length of the grind you avoided.
