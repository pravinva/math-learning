Focused Differentiation Practice

DPEN022 practice organised by skill. Differentiate with respect to \(x\) unless another variable is stated. Give exact values and use radians for trigonometric questions.

Structure: Group 1: three sets of 24 · Group 2: three sets of 8 · Group 3: three sets of 8 · Limits: three sets of 8. Show working and name the main differentiation rule used.

Group 1 — Differentiation Rules

Each set contains four questions from each of six types: powers; basic rules and chain on powers; products; quotients; exponential/logarithmic/trigonometric composites; and mixed combinations.

Set 1

24 questions · 4 from each rule family
  1. Differentiate \(y=x^5-3x^2+7\).Power rule
  2. Differentiate \(y=\sqrt{x}\).Rewrite the root as a power
  3. Differentiate \(f(x)=\dfrac{4}{x^2}\).Rewrite with a negative exponent
  4. Differentiate \(y=3x^{2/3}-2x^{-1}\).Fractional and negative powers
  5. Differentiate \(y=(2x+1)^4\).Chain rule on a power
  6. Differentiate \(y=\sqrt{3x-2}\).Power form, then chain rule
  7. Differentiate \(f(x)=(x^2+4)^3\).Chain rule on a power
  8. Differentiate \(y=\dfrac{1}{(5x+1)^2}\).Negative power and chain rule
  9. Differentiate \(y=x^2(x+3)\).Product rule
  10. Differentiate \(y=(x^2+1)(2x-5)\).Product rule
  11. Differentiate \(y=x^3e^x\).Product rule
  12. Differentiate \(y=x\sin x\).Product rule; radians
  13. Differentiate \(y=\dfrac{x+1}{x-2}\).Quotient rule
  14. Differentiate \(y=\dfrac{x^2}{x+3}\).Quotient rule
  15. Differentiate \(y=\dfrac{\sin x}{x}\).Quotient rule; radians
  16. Differentiate \(y=\dfrac{e^x}{x+1}\).Quotient rule
  17. Differentiate \(y=e^{3x}\).Exponential composite
  18. Differentiate \(y=\ln(2x+5)\).Logarithmic composite
  19. Differentiate \(y=\sin(4x)\).Trigonometric composite; radians
  20. Differentiate \(y=\cos(x^2)\).Trigonometric composite; radians
  21. Differentiate \(y=(x^2+1)e^x\).Mixed combination
  22. Differentiate \(y=x\ln x\).Mixed combination
  23. Differentiate \(y=\dfrac{\sin x}{x^2+1}\).Mixed combination; radians
  24. Differentiate \(y=e^{2x}\cos x\).Mixed combination; radians

Group 2 — Higher Derivatives and Values at a Point

Each set contains four higher-derivative questions and four derivative-at-a-point questions.

Set 1

  1. Find \(y''\) if \(y=x^4-3x^2+2x\).
  2. Find \(y''\) if \(y=\sqrt{x}\).
  3. Find \(y''\) if \(y=e^{2x}\).
  4. Find \(y''\) if \(y=\sin(3x)\).
  5. For \(f(x)=x^3-2x+1\), find \(f'(2)\).
  6. For \(f(x)=e^{3x}\), find \(f'(0)\).
  7. For \(f(x)=\ln(2x+1)\), find \(f'(1)\).
  8. For \(f(x)=\cos(2x)\), find \(f'(\pi/4)\).

Set 2

  1. Find \(f'''(x)\) if \(f(x)=2x^5-x^3+4x\).
  2. Find \(y''\) if \(y=(2x+1)^4\).
  3. Find \(y''\) if \(y=xe^x\).
  4. Find \(y''\) if \(y=\ln x\).
  5. For \(f(x)=(x^2+1)^3\), find \(f'(1)\).
  6. For \(f(x)=x^2e^x\), find \(f'(0)\).
  7. For \(f(x)=\dfrac{x+1}{x+2}\), find \(f'(1)\).
  8. For \(f(x)=\sin(3x)\), find \(f'(\pi/6)\).

Set 3

  1. Find \(y'''\) if \(y=x^{7/2}\).
  2. Find \(y''\) if \(y=e^{x^2}\).
  3. Find \(y''\) if \(y=x^2\ln x\).
  4. Find \(y''\) if \(y=\dfrac{1}{x+1}\).
  5. For \(f(x)=e^{x^2-1}\), find \(f'(1)\).
  6. For \(f(x)=\ln(x^2+3)\), find \(f'(1)\).
  7. For \(f(x)=\dfrac{\sin x}{x}\), find \(f'(\pi)\).
  8. For \(f(x)=e^x\cos(2x)\), find \(f'(0)\).

Group 3 — Tangents and Applications

Each set contains four tangent-equation questions and four applications involving horizontal or parallel tangents and motion.

Set 1

  1. Find the tangent to \(y=x^2+1\) at \(x=2\).
  2. Find the tangent to \(y=\sqrt{x}\) at \(x=4\).
  3. Find the tangent to \(y=e^x\) at \(x=0\).
  4. Find the tangent to \(y=\ln x\) at \(x=1\).
  5. Find the points where \(y=x^3-3x\) has a horizontal tangent.
  6. Find the point on \(y=x^2-4x+1\) where the tangent is parallel to \(y=2x-5\).
  7. Find the point on \(y=x^2\) where the tangent has gradient \(6\).
  8. A particle has position \(s(t)=t^3-6t^2+9t\). Find its velocity and the times it is at rest.

Set 2

  1. Find the tangent to \(y=x^3-2x\) at \(x=-1\).
  2. Find the tangent to \(y=\dfrac1x\) at \(x=2\).
  3. Find the tangent to \(y=e^{2x}+x\) at \(x=0\).
  4. Find the tangent to \(y=\sin x\) at \(x=\pi/3\).
  5. Find all points on \(y=x^3-3x^2+2\) where the tangent is horizontal.
  6. Find the points on \(y=x^3-x\) where the tangent is parallel to \(y=2x+4\).
  7. Find the point on \(y=\ln x\) where the tangent is parallel to \(y=\dfrac{x}{e}+4\).
  8. For \(s(t)=t^4-4t^3+2t\), find the acceleration at \(t=2\).

Set 3

  1. Find the tangent to \(y=(x^2+1)^3\) at \(x=1\).
  2. Find the tangent to \(y=xe^x\) at \(x=1\).
  3. Find the tangent to \(y=\ln(x^2+1)\) at \(x=1\).
  4. Find the tangent to \(y=\dfrac{\sin x}{x}\) at \(x=\pi\).
  5. Find all points where \(y=x^4-4x^2\) has a horizontal tangent.
  6. Find the tangent(s) to \(y=x^3-2x\) parallel to \(y=10x-7\).
  7. Find the tangent to \(y=e^{2x}\) that is parallel to \(y=2x-3\).
  8. A particle has \(s(t)=t^3e^t\). Find its velocity and acceleration at \(t=1\).

Limits

Evaluate each limit, or state that it does not exist. Give a one-sided reason where appropriate.

Set 1

  1. Evaluate \(\displaystyle\lim_{x\to2}(x^2+3x-1)\).
  2. Evaluate \(\displaystyle\lim_{x\to3}\dfrac{x^2-9}{x-3}\).
  3. Evaluate \(\displaystyle\lim_{x\to4}\dfrac{\sqrt{x}-2}{x-4}\).
  4. Evaluate \(\displaystyle\lim_{x\to\infty}\dfrac{3x^2+1}{x^2-5}\).
  5. Evaluate \(\displaystyle\lim_{x\to0}\dfrac{\sin x}{x}\).
  6. Evaluate \(\displaystyle\lim_{x\to0^+}\dfrac{|x|}{x}\).
  7. Does \(\displaystyle\lim_{x\to0}\dfrac{|x|}{x}\) exist? Justify.
  8. If \(f(x)=\begin{cases}x+2,&x<1\\3x,&x\ge1,\end{cases}\) find \(\displaystyle\lim_{x\to1}f(x)\).

Set 2

  1. Evaluate \(\displaystyle\lim_{x\to-1}\dfrac{x^3+1}{x+1}\).
  2. Evaluate \(\displaystyle\lim_{x\to9}\dfrac{x-9}{\sqrt{x}-3}\).
  3. Evaluate \(\displaystyle\lim_{x\to\infty}\dfrac{5x-2}{2x+7}\).
  4. Evaluate \(\displaystyle\lim_{x\to\infty}\dfrac{4x+1}{x^2+3}\).
  5. Evaluate \(\displaystyle\lim_{x\to0}\dfrac{\sin(5x)}{x}\).
  6. Evaluate \(\displaystyle\lim_{x\to2^-}\dfrac{|x-2|}{x-2}\).
  7. If \(g(x)=\begin{cases}2x+1,&x<2\\x^2-1,&x\ge2,\end{cases}\), determine whether \(\displaystyle\lim_{x\to2}g(x)\) exists.
  8. Evaluate \(\displaystyle\lim_{x\to1}\dfrac{x^2+x-2}{x-1}\).

Set 3

  1. Evaluate \(\displaystyle\lim_{x\to2}\dfrac{x^3-8}{x^2-4}\).
  2. Evaluate \(\displaystyle\lim_{x\to0}\dfrac{\sqrt{1+3x}-1}{x}\).
  3. Evaluate \(\displaystyle\lim_{x\to\infty}\dfrac{2x^3-x}{5x^3+4x^2+1}\).
  4. Evaluate \(\displaystyle\lim_{x\to-\infty}\dfrac{3x^2+x}{\sqrt{x^4+1}}\).
  5. Evaluate \(\displaystyle\lim_{x\to0}\dfrac{\sin(3x)}{\sin(2x)}\).
  6. Evaluate \(\displaystyle\lim_{x\to0^+}\dfrac{x}{|x|}\) and \(\displaystyle\lim_{x\to0^-}\dfrac{x}{|x|}\).
  7. If \(h(x)=\begin{cases}x^2+a,&x<1\\3x-1,&x\ge1,\end{cases}\), find \(a\) so that \(\displaystyle\lim_{x\to1}h(x)\) exists.
  8. Evaluate \(\displaystyle\lim_{x\to-2}\dfrac{x^2+5x+6}{x^2-4}\).

Complete the questions before opening the worked answers. Equivalent simplified derivative forms are acceptable where their equality is clear.
