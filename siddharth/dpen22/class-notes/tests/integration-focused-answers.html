Group 1 — Integration Techniques

Set 1 — Worked Solutions

Q1. Expand first: \((x+2)^2=x^2+4x+4\). Then \(\dfrac{x^3}{3}+2x^2+4x+C\).
Q2. Split: \(\dfrac{x^2+3x}{x}=x+3\). So \(\dfrac{x^2}{2}+3x+C\).
Q3. Expand: \(1+\dfrac{2}{x}+\dfrac{1}{x^2}\). Integrate: \(x+2\ln|x|-\dfrac{1}{x}+C\).
Q4. Distribute: \(\int(x^{3/2}+x^{1/2})\,dx=\dfrac{2}{5}x^{5/2}+\dfrac{2}{3}x^{3/2}+C\).
Q5. Power rule: \(x^4-3x^2+C\).
Q6. Powers: \(\sqrt{x}=x^{1/2}\), so \(\dfrac{2}{3}x^{3/2}+\ln|x|+C\).
Q7. Rewrite: \(5x^{-2}\). Antiderivative \(-\dfrac{5}{x}+C\).
Q8. Power rule: \(\dfrac{9}{4}x^{4/3}-4x^{1/2}+C\).
Q9. Reverse chain: \(\dfrac{1}{2}e^{2x}+C\).
Q10. Reverse chain: \(-\dfrac{1}{3}\cos(3x)+C\).
Q11. Log form: \(\ln|x+4|+C\).
Q12. Trig reverse: \(4\sin x+C\).
Q13. Substitution: \(u=x^2+1\), \(du=2x\,dx\). \(\displaystyle\int u^3\,du=\dfrac{u^4}{4}+C=\dfrac{(x^2+1)^4}{4}+C\).
Q14. Substitution: \(u=x^2\), \(du=2x\,dx\). \(\dfrac12\int e^u\,du=\dfrac12 e^{x^2}+C\).
Q15. Substitution: \(u=x^2+9\), \(du=2x\,dx\). \(\ln|x^2+9|+C\).
Q16. Substitution: \(u=x^2+1\), \(du=2x\,dx\). \(2\int u^{1/2}\,du=\dfrac{4}{3}(x^2+1)^{3/2}+C\).

Set 2 — Worked Solutions

Q1. Expand: \(x^2-6+\dfrac{9}{x^2}\). Then \(\dfrac{x^3}{3}-6x-\dfrac{9}{x}+C\).
Q2. Split: \(x^2-x^{-1}\). Then \(\dfrac{x^3}{3}-\ln|x|+C\).
Q3. Expand: \(x-2+\dfrac{1}{x}\). Then \(\dfrac{x^2}{2}-2x+\ln|x|+C\).
Q4. Expand: \(x(x^2-4x+4)=x^3-4x^2+4x\). Then \(\dfrac{x^4}{4}-\dfrac{4}{3}x^3+2x^2+C\).
Q5. Powers: \(2x^4-\dfrac{1}{2x^2}+C\).
Q6. Powers: \(6\cdot\dfrac23 x^{3/2}-4\cdot(-x^{-1})=4x^{3/2}+\dfrac{4}{x}+C\).
Q7. Powers: \(\dfrac{2}{7}x^{7/2}-2x^{-1/2}+C\).
Q8. Powers: \(\dfrac13 x^6-3\ln|x|+C\).
Q9. Exponential: \(-e^{-x}+C\).
Q10. Reverse chain: \(9\sin\dfrac{x}{3}+C\).
Q11. Log chain: \(u=2x+1\), \(du=2\,dx\), so \(2\ln|2x+1|+C\).
Q12. Tan reverse: \(\tan(2x)+C\).
Q13. Substitution: \(u=x^3-1\), \(du=3x^2\,dx\). \(\dfrac{u^6}{6}+C=\dfrac{(x^3-1)^6}{6}+C\).
Q14. Substitution: \(u=x^2+4\), \(du=2x\,dx\). \(2(x^2+4)^{1/2}+C\).
Q15. Substitution: \(u=\sin x\), \(du=\cos x\,dx\). \(\dfrac{\sin^4 x}{4}+C\).
Q16. Substitution: \(u=3x^2-2x\), \(du=(6x-2)\,dx\). \(\dfrac{2}{3}u^{3/2}+C=\dfrac{2}{3}(3x^2-2x)^{3/2}+C\).

Set 3 — Worked Solutions

Q1. Expand: \(4+\dfrac{4}{x}+\dfrac{1}{x^2}\). Then \(4x+4\ln|x|-\dfrac{1}{x}+C\).
Q2. Rewrite: \(x^{3/2}+2x^{1/2}\). Then \(\dfrac{2}{5}x^{5/2}+\dfrac{4}{3}x^{3/2}+C\).
Q3. Expand then split: \((x^3-3x^2+3x-1)/x=x^2-3x+3-x^{-1}\). Then \(\dfrac{x^3}{3}-\dfrac{3}{2}x^2+3x-\ln|x|+C\).
Q4. Expand then split: \((x+2x^{3/2}+x^2)/x=1+2x^{1/2}+x\). Then \(x+\dfrac{4}{3}x^{3/2}+\dfrac{x^2}{2}+C\).
Q5. Powers: \(\dfrac{3}{2}x^6+x^3+C\).
Q6. Powers: \(\dfrac{3}{4}x^4-4\ln|x|+C\).
Q7. Powers: \(\dfrac{3}{5}x^{5/3}-\dfrac{5}{3x^3}+C\).
Q8. Powers: \(14x^{1/2}-\dfrac{2}{5}x^{5/2}+C\).
Q9. Mix of reverse chain and power: \(\dfrac12 e^{2x}+2x^2+C\).
Q10. Trig reverse: \(\dfrac32\sin 2x+2\cos x+C\).
Q11. Log form: \(\ln|x+5|+C\).
Q12. Trig reverse: \(2\tan x-3\sin x+C\).
Q13. Given substitution: \(du=2x\,dx\). \(\dfrac{(x^2-3)^4}{4}+C\).
Q14. Substitution: \(u=x^2+9\), \(du=2x\,dx\). \(2\sqrt{x^2+9}+C\).
Q15. Substitution: \(u=\sin 2x\), \(du=2\cos 2x\,dx\), so \(\cos 2x\,dx=\tfrac12 du\). \(\dfrac14\ln|\sin 2x|+C\).
Q16. Substitution: \(u=x^2+1\), \(du=2x\,dx\). \(\dfrac12\ln(x^2+1)+C\).

Group 2 — Definite Integrals

Set 1 — Worked Solutions

Q1. FTC: \([x^3-x]_0^1=0\).
Q2. FTC: \(\bigl[\tfrac12 x^4+2x\bigr]_{-1}^{2}=(8+4)-\bigl(\tfrac12-2\bigr)=\tfrac{27}{2}\).
Q3. FTC: \([2\sqrt{x}]_1^4=4-2=2\).
Q4. FTC: \(\bigl[\tfrac14 x^4-\tfrac12 x^2\bigr]_0^2=4-2=2\).
Q5. FTC: \([x^3]_{-2}^{1}=1-(-8)=9\).
Q6. FTC: \(\bigl[\tfrac34 x^{4/3}\bigr]_1^8=\tfrac34(16-1)=\tfrac{45}{4}\).
Q7. FTC: \([2x^2-2x]_0^1=0\).
Q8. FTC: \(\bigl[-x^{-1}\bigr]_1^2=-\tfrac12+1=\tfrac12\).
Q9. FTC: \([\sin x]_0^{\pi/2}=1\).
Q10. FTC: \([\tan x]_0^{\pi/4}=1\).
Q11. FTC: \([e^x]_0^1=e-1\).
Q12. FTC: \(\bigl[x+\tfrac12\cos 2x\bigr]_0^{\pi/2}=\tfrac{\pi}{2}-\tfrac12-\tfrac12=\dfrac{\pi}{2}-1\).
Q13. FTC: \([e^x+x^2]_0^1=(e+1)-1=e\).
Q14. FTC: \([\sin 3x]_0^{\pi/6}=1\).
Q15. FTC: \([\ln|x|]_1^{e}=1\).
Q16. FTC: \([-\cos x]_0^{\pi}=1+1=2\).

Set 2 — Worked Solutions

Q1. Even integrand: \(2\bigl[\tfrac15 x^5-\tfrac13 x^3\bigr]_0^1=2\bigl(\tfrac15-\tfrac13\bigr)=-\dfrac{4}{15}\).
Q2. FTC: \([x^2+x]_0^3=12\).
Q3. FTC: \(\bigl[\tfrac23 x^{3/2}-x^{-1}\bigr]_1^4=\bigl(\tfrac{16}{3}-\tfrac14\bigr)-\bigl(\tfrac23-1\bigr)=\dfrac{65}{12}\).
Q4. Even: \(2\bigl[4x-\tfrac13 x^3\bigr]_0^2=2\bigl(8-\tfrac83\bigr)=\dfrac{32}{3}\).
Q5. FTC: \([\sqrt{x}]_1^9=2\).
Q6. FTC: \([x^6-x^3]_0^1=0\).
Q7. Expand then FTC: \(\bigl[\tfrac13 x^3+x^2+x\bigr]_0^1=\dfrac73\).
Q8. FTC: \([x^3+x^2]_{-1}^{0}=0-(-1+1)=0\).
Q9. FTC: \([-\cos x]_0^{\pi/3}=\tfrac12\).
Q10. FTC: \([x+\cos x]_0^{\pi/2}=\dfrac{\pi}{2}-1\).
Q11. FTC: \(\bigl[\tfrac12 e^{2x}\bigr]_0^1=\dfrac12(e^2-1)\).
Q12. Log chain: \(\bigl[\tfrac12\ln|2x+1|\bigr]_1^2=\dfrac12\ln\dfrac53\).
Q13. FTC: \(\bigl[\tfrac12\sin 2x\bigr]_0^{\pi/6}=\dfrac{\sqrt3}{4}\).
Q14. Substitute and change limits: \(u=x^2+1\), from \(1\) to \(2\). \(\bigl[\tfrac13 u^3\bigr]_1^2=\dfrac73\).
Q15. Substitute: \(u=\sin x\), from \(0\) to \(1\). \(\bigl[\tfrac13 u^3\bigr]_0^1=\dfrac13\).
Q16. Substitute: \(u=x^2\), from \(0\) to \(1\). \(\dfrac12(e-1)\).

Set 3 — Worked Solutions

Group 3 — Area

Set 1 — Worked Solutions

Q1. Area under a line: \(\displaystyle\int_0^3 x\,dx=\dfrac92\).
Q2. Area: \(\displaystyle\int_0^1(x-x^2)\,dx=\bigl[\tfrac12 x^2-\tfrac13 x^3\bigr]_0^1=\dfrac16\).
Q3. Intercepts \(x=\pm 2\): \(\displaystyle\int_{-2}^{2}(4-x^2)\,dx=\dfrac{32}{3}\).
Q4. Area: \(\displaystyle\int_0^4 x^{1/2}\,dx=\bigl[\tfrac23 x^{3/2}\bigr]_0^4=\dfrac{16}{3}\).
Q5. Area: \(\displaystyle\int_0^{\pi}\sin x\,dx=2\).
Q6. Area: \(\displaystyle\int_0^2 x^2\,dx=\dfrac83\).
Q7. Area: \(\displaystyle\int_0^2(2x+1)\,dx=6\).
Q8. Area: \(\displaystyle\int_0^1 e^x\,dx=e-1\).
Q9. Intersections \(0,1\); \(y=x\) on top: \(\displaystyle\int_0^1(x-x^2)\,dx=\dfrac16\).
Q10. Solve \(x^2=2-x^2\Rightarrow x=\pm 1\). \(\displaystyle\int_{-1}^{1}(2-2x^2)\,dx=\dfrac83\).
Q11. Top \(y=x\): \(\displaystyle\int_0^1(x-x^3)\,dx=\dfrac14\).
Q12. Solve \(x^2=4x\Rightarrow x=0,4\). \(\displaystyle\int_0^4(4x-x^2)\,dx=\dfrac{32}{3}\).
Q13. Solve \(x^2-x=0\Rightarrow x=0,1\). \(\displaystyle\int_0^1(x-x^2)\,dx=\dfrac16\).
Q14. \(\sqrt{x}\) on top: \(\displaystyle\int_0^1(\sqrt{x}-x)\,dx=\dfrac16\).
Q15. Even: \(2\displaystyle\int_0^1(1-x^2)\,dx=\dfrac43\).
Q16. Solve \(x^2=4x-x^2\Rightarrow x=0,2\). \(\displaystyle\int_0^2(4x-2x^2)\,dx=\dfrac83\).
