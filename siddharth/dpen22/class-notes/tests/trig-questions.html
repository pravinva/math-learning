Test 1

Total number of questions: 15
  • Questions 1–6 are multiple choice. Each question is worth 1 mark; marks are awarded for the answer only.
  • Questions 7–15 are long-answer questions. The value of each question is indicated; show all working.

Questions 1–6: Multiple choice

  1. In a right triangle, adjacent side \(5\) m and angle \(13^\circ45'\). Find the hypotenuse correct to 2 d.p.
    (A) \(1.19\) m
    (B) \(5.15\) m
    (C) \(21.04\) m
    (D) \(4.86\) m
    (E) \(20.43\) m
  2. What is the reference angle for \(\theta=-135^\circ\)?
    (A) \(135^\circ\)
    (B) \(225^\circ\)
    (C) \(315^\circ\)
    (D) \(45^\circ\)
    (E) \(90^\circ\)
  3. If \(\sec\theta<0\) and \(\cot\theta>0\), which quadrant contains \(\theta\)?
    (A) 1
    (B) 2
    (C) 3
    (D) 4
    (E) none
  4. Convert \(\dfrac{11\pi}{12}\) to degrees.
    (A) \(165^\circ\)
    (B) \(195^\circ\)
    (C) \(150^\circ\)
    (D) \(135^\circ\)
    (E) \(15^\circ\)
  5. Starting from \(y=\cos x\): amplitude \(3\), period \(4\pi\), shift down \(2\). The equation is
    (A) \(3\cos(4\pi x)-2\)
    (B) \(3\cos\!\left(\dfrac{x}{2}\right)-2\)
    (C) \(3\cos(2x)-2\)
    (D) \(2\cos(4\pi x)-3\)
    (E) \(2\cos(3x)-2\)
  6. Simplify \((1-\sin^2 x)\sec^2 x\).
    (A) \(\cos^2 x\)
    (B) \(0\)
    (C) \(1\)
    (D) \(\tan^2 x\)
    (E) \(\sec^2 x\)

Questions 7–15: Long answer

  1. Hypotenuse \(15\) m, adjacent \(7\) m. Find the included angle to the nearest minute.[2 marks]
  2. If \(\sin\theta=\dfrac{3}{5}\) and \(\theta\) is acute: (i) draw a diagram; (ii) find the exact value of \(\sec\theta\).[3 marks]
  3. Find \(x\) if \(\sin 80^\circ=\cos(90^\circ-2x)\).[2 marks]
  4. Find the exact value of \(\tan\dfrac{2\pi}{3}\).[2 marks]
  5. Solve \(\cos\theta=\dfrac{1}{2}\) for \(0^\circ\le\theta\le360^\circ\). Give exact answers in degrees.[3 marks]
  6. Solve \(\cot\theta=\sqrt{3}\) for \(0\le\theta\le2\pi\). Give exact answers in radians.[3 marks]
  7. Sketch \(y=\dfrac12\sin 2x\) for \(-\pi\le x\le\pi\) and state its amplitude and period.[3 marks]
  8. Prove \(\sin 2\theta=2\sin\theta\cos\theta\).[3 marks]
  9. Solve \(2\sin^2 x-\cos 2x=2\) for \(0^\circ\le x\le360^\circ\). Give exact answers in degrees.[3 marks]

    (C) \(\sin(2x)+2\)
    (D) \(2\sin(\pi x)+1\)

Questions 7–15: Long answer

  1. Opposite \(9\) m, hypotenuse \(15\) m. Find the angle opposite the \(9\) m side to the nearest degree.[2 marks]
  2. If \(\cos\theta=\dfrac{5}{13}\) and \(\theta\) is acute: (i) draw a diagram; (ii) find exact \(\tan\theta\).[3 marks]
  3. Find \(x\) if \(\cos 35^\circ=\sin(2x)\).[2 marks]
  4. Find the exact value of \(\sin\dfrac{5\pi}{6}\).[2 marks]
  5. Solve \(2\sin\theta=-1\) for \(0^\circ\le\theta\le360^\circ\). Exact answers in degrees.[3 marks]
  6. Solve \(\tan\theta=1\) for \(0\le\theta\le2\pi\). Exact answers in radians.[3 marks]
  7. Sketch \(y=2\cos 3x\) on \([0,2\pi]\) and state amplitude and period.[3 marks]
  8. Prove \((\sec\theta-\tan\theta)(\sec\theta+\tan\theta)=1\).[3 marks]
  9. Solve \(2\cos^2\theta-1=0\) for \(0^\circ\le\theta\le360^\circ\). Exact answers in degrees.[3 marks]
