MATH141 Revision — Integration Set 6

12 exam-style questions · Week 12: average value & volumes of revolution
Scope: Average value of a function; volumes by disks/washers (and shells where natural).
  1. Find the average value of $f(x)=\sin x$ on $[0,\pi]$.
  2. Find the average value of $f(x)=e^x$ on $[0,1]$.
  3. The region under $y=\sqrt{x}$ from $0$ to $4$ is rotated about the $x$-axis. Find the volume.
  4. The region under $y=x^2$ from $0$ to $2$ is rotated about the $x$-axis. Find the volume.
  5. The region bounded by $y=x$ and $y=x^2$ is rotated about the $x$-axis. Find the volume (washers).
  6. Find the volume generated when the region under $y=\cos x$ from $0$ to $\pi/2$ is rotated about the $x$-axis.
  7. Find the average value of $f(x)=|x|$ on $[-2,2]$.
  8. The region bounded by $y=4-x^2$ and $y=0$ is rotated about the $x$-axis. Find the volume.
  9. Use cylindrical shells to find the volume when the region under $y=\sqrt{x}$ from $0$ to $1$ is rotated about the $y$-axis.
  10. Find the volume when the region between $y=\sqrt{x}$ and $y=x$ from their intersections is rotated about the $x$-axis.
  11. A solid has base the disk $x^2+y^2\le1$; cross-sections perpendicular to the $x$-axis are squares. Find the volume.
  12. Find $c$ in $(0,2)$ such that $f(c)$ equals the average value of $f(x)=x^2$ on $[0,2]$.
