High-yield reminders

When solving trig equations, solve general form first, then restrict to interval.

For inverse functions, verify one-to-one on stated domain before inverting.

Worked example

Solve \(\sin(2x)=\frac{\sqrt3}{2}\) for \(0\le x<2\pi\).

\(2x=\frac{\pi}{3}+2k\pi\) or \(2x=\frac{2\pi}{3}+2k\pi\).

\(x=\frac{\pi}{6}+k\pi\) or \(x=\frac{\pi}{3}+k\pi\). In interval: \(\frac{\pi}{6},\frac{\pi}{3},\frac{7\pi}{6},\frac{4\pi}{3}\).

A1

Find domain of \(f(x)=\sqrt{5-2x}\).

Solution

Require \(5-2x\ge0\Rightarrow x\le 2.5\). Domain: \((-\infty,2.5]\).

A2

If \(f(x)=3x-4\), \(g(x)=x^2+1\), find \(f\circ g\) and \(g\circ f\).

Solution

\(f(g(x))=3(x^2+1)-4=3x^2-1\). \(g(f(x))=(3x-4)^2+1=9x^2-24x+17\).

A3

Find inverse of \(f(x)=\frac{2x-5}{3}\).

Solution

\(y=\frac{2x-5}{3}\Rightarrow 3y=2x-5\Rightarrow x=\frac{3y+5}{2}\). So \(f^{-1}(x)=\frac{3x+5}{2}\).

A4

Solve \(2\sin x-1=0\) for \(0\le x<2\pi\).

Solution

\(\sin x=\frac12\). Solutions: \(x=\frac{\pi}{6},\frac{5\pi}{6}\).

A5

Solve \(\cos(3x)=0\) for \(0\le x\le \pi\).

Solution

\(3x=\frac{\pi}{2}+k\pi\Rightarrow x=\frac{\pi}{6}+\frac{k\pi}{3}\). In interval: \(\frac{\pi}{6},\frac{\pi}{2},\frac{5\pi}{6}\).

A6

Find amplitude and period of \(y=4\sin(5x-\pi)\).

Solution

Amplitude \(=4\). Period \(=\frac{2\pi}{5}\).

A7

Show whether \(f(x)=x^2-4x+1\) is one-to-one on \(\mathbb{R}\).

Solution

Quadratic opens up and has turning point at \(x=2\), so it fails horizontal line test on \(\mathbb{R}\). Not one-to-one.

A8

Solve \(\tan x=-\sqrt3\) for \(-\pi

Solution

Reference angle \(\pi/3\), tangent negative in QII and QIV. In interval: \(x=-\pi/3,\ 2\pi/3\).

A9

Given \(f(x)=\frac{1}{x-2}\), find \(f(f(x))\).

Solution

\(f(f(x))=\frac{1}{\frac{1}{x-2}-2}=\frac{1}{\frac{1-2x+4}{x-2}}=\frac{x-2}{5-2x}\).

A10

Solve \(2\cos^2 x-3\cos x+1=0\) for \(0\le x<2\pi\).

Solution

\((2\cos x-1)(\cos x-1)=0\). So \(\cos x=1\) or \(\cos x=\frac12\). Solutions: \(x=0,\frac{\pi}{3},\frac{5\pi}{3}\).

Log laws

\(\log_b(MN)=\log_b M+\log_b N\), \(\log_b(M/N)=\log_b M-\log_b N\), \(\log_b(M^k)=k\log_b M\), \(\log_b M=\frac{\ln M}{\ln b}\).

Worked example

Solve \(3^{2x-1}=7\).

$$ (2x-1)\ln(3)=\ln(7) \;\Rightarrow\; x=\frac{1}{2}\left(1+\frac{\ln(7)}{\ln(3)}\right)\approx 1.385. $$

B1

Expand \(\log_2\!\left(\frac{8x^3}{\sqrt{y}}\right)\).

Solution

\(\log_2 8+3\log_2 x-\frac12\log_2 y=3+3\log_2 x-\frac12\log_2 y\).

B2

Condense \(2\ln a-\frac12\ln b+\ln 5\) into one log.

Solution

\(\ln\!\left(\frac{5a^2}{\sqrt b}\right)\).

B3

Solve \(\ln(x-1)=2\).

Solution

\(x-1=e^2\Rightarrow x=1+e^2\), valid since \(x>1\).

B4

Solve \(\log_{10}(x+4)-\log_{10}(x-2)=1\).

Solution

\(\log_{10}\frac{x+4}{x-2}=1\Rightarrow \frac{x+4}{x-2}=10\Rightarrow x+4=10x-20\Rightarrow x=\frac{24}{9}=\frac83\). Domain \(x>2\), valid.

B5

Solve \(5e^{0.3t}=42\) for \(t\).

Solution

\(e^{0.3t}=8.4\Rightarrow 0.3t=\ln 8.4\Rightarrow t=\frac{\ln8.4}{0.3}\approx7.11\).

B6

Rewrite \(\log_5 17\) in terms of natural logs.

Solution

\(\log_5 17=\frac{\ln17}{\ln5}\).

B7

Solve \(2^{x+1}=7^{x-2}\).

Solution

\((x+1)\ln2=(x-2)\ln7\Rightarrow x(\ln2-\ln7)=-(2\ln7+\ln2)\). So \(x=\frac{2\ln7+\ln2}{\ln7-\ln2}\approx3.123\).

B8

Find domain of \(f(x)=\ln(3-2x)+\ln(x+1)\).

Solution

Need \(3-2x>0\Rightarrow x<1.5\), and \(x+1>0\Rightarrow x>-1\). Domain \((-1,1.5)\).

B9

Solve \(\ln x + \ln(x-3)=\ln 4\).

Solution

\(\ln(x(x-3))=\ln4\Rightarrow x^2-3x-4=0\Rightarrow x=4,-1\). Domain \(x>3\), so \(x=4\).

B10

Solve \(\log_3(x+5)=2\log_3 2\).

Solution

\(2\log_3 2=\log_3 4\), so \(x+5=4\Rightarrow x=-1\). Domain \(x>-5\), valid.

B11

Solve \(10^{2x}=50\).

Solution

\(2x=\log_{10}50\Rightarrow x=\frac12\log_{10}50\approx0.8495\).

B12

Simplify \(\frac{\ln a - \ln b}{\ln c}\).

Solution

\(\frac{\ln(a/b)}{\ln c}=\log_c(a/b)\).

B13

Solve \(\ln(2x+1)=\ln(7-x)\).

Solution

Equal logs imply \(2x+1=7-x\Rightarrow3x=6\Rightarrow x=2\). Domain checks pass.

B14

Given \(y=Ae^{kt}\), show that \(\ln y\) is linear in \(t\).

Solution

\(\ln y=\ln A+kt\), which is straight-line form \(Y=mt+c\) with \(Y=\ln y\), slope \(k\), intercept \(\ln A\).

B15

If \(\log_{10}y=1.8\), find \(y\).

Solution

\(y=10^{1.8}\approx63.10\).

High-value lecture insights (core ideas)

This is one of the most immediately useful parts of the course. A lot of real data modelling starts by converting a curved relation into a straight-line relation.

For a straight line \(y=mx+b\), slope is \(m\), intercept is \(b\), and from two points \((x_1,y_1)\), \((x_2,y_2)\): $$m=\frac{y_2-y_1}{x_2-x_1}.$$

Exponential model \(\;y=ce^{kx}\;\) (semi-log): taking logs gives $$\ln y=\ln c+kx.$$ If \(Y=\ln y\) and \(C=\ln c\), then $$Y=kx+C,$$ a straight line on a semi-log plot (vertical axis logged, horizontal axis raw).

Power model \(\;y=cx^p\;\) (log-log): taking logs gives $$\ln y=\ln c+p\ln x.$$ If \(Y=\ln y,\ X=\ln x,\ C=\ln c\), then $$Y=pX+C,$$ a straight line on a log-log plot (both axes logged).

From fitted straight-line form, estimate slope and intercept first, then recover parameters: $$k=\text{slope (semi-log)},\quad p=\text{slope (log-log)},\quad c=e^{C}\ \text{(or }10^{C}\text{ for base-10 logs)}.$$

Power model linearisation

If \(y=Cx^m\), then \(\log y=\log C + m\log x\). On a log-log plot, slope \(=m\), intercept \(=\log C\).

If using natural logs: \(\ln y=\ln C + m\ln x\), same slope \(m\), intercept \(\ln C\).

Why this matters beyond one exam

Many scientific scales are logarithmic, so log-law fluency is not optional. Common examples include:

- Richter scale (earthquake intensity),

- pH (acidity/alkalinity),

- decibels (sound level).

So the same straight-line thinking here transfers directly to real measurement systems.

Worked example

A log-log fit gives \(\ln y=1.2+1.75\ln x\).

Slope \(m=1.75\).

\(\ln C=1.2\Rightarrow C=e^{1.2}\approx3.320\).

Model: \(y\approx3.320\,x^{1.75}\).

C1

Linearise \(y=7x^{-2.5}\) using \(\ln\).

Solution

\(\ln y=\ln7-2.5\ln x\).

C2

On a log-log graph, slope is \(-1.2\), intercept (base-10) is \(0.48\). Find model \(y=Cx^m\).

Solution

\(m=-1.2\), \(\log_{10}C=0.48\Rightarrow C=10^{0.48}\approx3.02\). So \(y\approx3.02x^{-1.2}\).

C3

If \(y=5x^{0.4}\), what is the slope on a log-log plot?

Solution

Slope \(=0.4\).

C4

Given \(\ln y=-0.7+2.2\ln x\), express \(y\) in power-law form.

Solution

\(y=e^{-0.7}x^{2.2}\approx0.4966x^{2.2}\).

C5

A model \(y=Cx^m\) doubles when \(x\) is multiplied by 4. Find \(m\).

Solution

\(\frac{y_2}{y_1}=4^m=2\Rightarrow m=\frac{\ln2}{\ln4}=\frac12\).

C6

For \(y=12x^{-0.8}\), find ratio \(y(10)/y(2)\).

Solution

\(\left(\frac{10}{2}\right)^{-0.8}=5^{-0.8}\approx0.276\).

C7

If \(\log_{10}y=1.1-0.35\log_{10}x\), find \(y\) when \(x=20\).

Solution

\(\log_{10}y=1.1-0.35\log_{10}20\approx1.1-0.4554=0.6446\). So \(y\approx10^{0.6446}=4.41\).

C8

Two points on log-log line are \((\ln x,\ln y)=(0,1.5)\) and \((2,2.1)\). Find \(m\) and \(C\).

Solution

Slope \(m=\frac{2.1-1.5}{2-0}=0.3\). Intercept \(\ln C=1.5\Rightarrow C=e^{1.5}\approx4.48\). Model \(y\approx4.48x^{0.3}\).

C9

Explain what negative slope on a log-log plot means physically for \(y=Cx^m\).

Solution

Negative slope means \(m<0\): \(y\) decreases as \(x\) increases, with inverse-type scaling strength set by \(|m|\).

C10

Find \(m\) if increasing \(x\) by 10 scales \(y\) by factor 100 in \(y=Cx^m\).

Solution

\(10^m=100=10^2\Rightarrow m=2\).

C11

Convert \(\ln y=2.4-1.1\ln x\) to base-10 log form.

Solution

Divide by \(\ln10\): \(\log_{10}y=\frac{2.4}{\ln10}-1.1\log_{10}x\approx1.042-1.1\log_{10}x\).

C12

Given \(y=0.8x^{1.6}\), estimate factor change in \(y\) when \(x\) triples.

Solution

Factor \(=3^{1.6}\approx5.80\).

C13

Data fit gives \(\log_{10}y= -0.2+0.75\log_{10}x\). Predict \(y\) at \(x=50\).

Solution

\(\log_{10}y=-0.2+0.75\log_{10}50\approx-0.2+1.2742=1.0742\). \(y\approx10^{1.0742}=11.86\).

C14

Find \(C\) if \(y=Cx^{-1.4}\) passes through \((x,y)=(4,2.5)\).

Solution

\(2.5=C4^{-1.4}\Rightarrow C=2.5\cdot4^{1.4}\approx17.41\).

C15

In \(\ln y=\ln C+m\ln x\), what does intercept represent?

Solution

Intercept is \(\ln C\), so \(C=e^{\text{intercept}}\).

C16

Show whether model \(y=Ax^m\) can represent negative \(y\) values when \(A>0\) and \(x>0\).

Solution

No. For \(A>0\), \(x>0\), \(x^m>0\), so \(y>0\). Standard log-log modelling assumes positive variables.

C17

Given log-log slope \(m=0\), what model family does this imply?

Solution

\(y=Cx^0=C\): constant model.

C18

Line on \((\log x,\log y)\) axes has equation \(Y=2.3-0.9X\). Write \(y\) vs \(x\).

Solution

\(\log_{10}y=2.3-0.9\log_{10}x\Rightarrow y=10^{2.3}x^{-0.9}\approx199.53x^{-0.9}\).

C19

If \(y=Cx^m\) and two observations are \((2,9)\), \((8,36)\), find \(m\).

Solution

\(\frac{36}{9}=\left(\frac{8}{2}\right)^m\Rightarrow4=4^m\Rightarrow m=1\).

C20

Continue C19: find \(C\).

Solution

With \(m=1\), \(9=C\cdot2\Rightarrow C=4.5\). Model \(y=4.5x\).

C21

Why is log-log preferred over raw plotting for power laws?

Solution

It linearises multiplicative scaling into straight lines, making exponent extraction (slope) and coefficient extraction (intercept) robust and visually clear across wide ranges.

C22

Given \(\ln y=0.9+0.5\ln x\), estimate \(y\) at \(x=16\).

Solution

\(y=e^{0.9}16^{0.5}=e^{0.9}\cdot4\approx9.84\).

C23

For \(y=Cx^m\), derive \(m\) from two points \((x_1,y_1)\), \((x_2,y_2)\).

Solution

\(\frac{y_2}{y_1}=\left(\frac{x_2}{x_1}\right)^m\Rightarrow m=\frac{\ln(y_2/y_1)}{\ln(x_2/x_1)}\).

C24

A fit gives \(\log_{10}y=3.1-2.4\log_{10}x\). Predict \(x\) when \(y=5\).

Solution

\(\log_{10}5=3.1-2.4\log_{10}x\Rightarrow \log_{10}x=\frac{3.1-\log_{10}5}{2.4}\approx1.000\). So \(x\approx10.0\).

C25

Exam check: A student got slope \(m=1.3\) from log-log line but wrote model \(y=Cx^{-1.3}\). Identify error.

Solution

Sign error. In \(Y=\log y=\log C + m\log x\), slope equals \(m\) directly. Positive slope \(1.3\) means \(y=Cx^{1.3}\), not \(x^{-1.3}\).
