MATH141 Revision — Vectors Set 1 — Worked Answers

Full workings for each question

  1. \(|\mathbf{a}|=\sqrt{3^2+(-4)^2+12^2}=\sqrt{9+16+144}=\sqrt{169}=13\).

    Unit vector \(\hat{\mathbf{a}}=\dfrac{\mathbf{a}}{|\mathbf{a}|}=\dfrac{1}{13}(3,-4,12)\).

    \(|\mathbf{a}|=13\), \(\hat{\mathbf{a}}=\dfrac{1}{13}(3,-4,12)\)

  2. \(\mathbf{a}\cdot\mathbf{b}=2(1)+1(-2)+(-2)(2)=2-2-4=-4\).

    \(|\mathbf{a}|=\sqrt{4+1+4}=3\), \(|\mathbf{b}|=\sqrt{1+4+4}=3\).

    \(\cos\theta=\dfrac{-4}{3\cdot3}=-\dfrac{4}{9}\), so \(\theta=\arccos\!\left(-\dfrac{4}{9}\right)\).

    \(\theta=\arccos\!\left(-\dfrac{4}{9}\right)\)

  3. \(\mathbf{u}\cdot\mathbf{v}=3(1)+1(0)+2(-1)=1\), \(\mathbf{v}\cdot\mathbf{v}=1+0+1=2\).

    \(\operatorname{proj}_{\mathbf{v}}\mathbf{u}=\dfrac{1}{2}(1,0,-1)=\left(\dfrac12,0,-\dfrac12\right)\).

    Perpendicular component: \(\mathbf{u}-\operatorname{proj}=\left(3-\dfrac12,1,2+\dfrac12\right)=\left(\dfrac52,1,\dfrac52\right)\).

    proj \(=\left(\dfrac12,0,-\dfrac12\right)\); perp \(=\left(\dfrac52,1,\dfrac52\right)\)

  4. \(\mathbf{a}\times\mathbf{b}=\begin{vmatrix}\mathbf{i}&\mathbf{j}&\mathbf{k}\\2&0&-1\\1&3&2\end{vmatrix}=\mathbf{i}(0+3)-\mathbf{j}(4+1)+\mathbf{k}(6-0)=(3,-5,6)\).

    Area \(=|\mathbf{a}\times\mathbf{b}|=\sqrt{9+25+36}=\sqrt{70}\).

    \(\mathbf{a}\times\mathbf{b}=(3,-5,6)\), area \(=\sqrt{70}\)

  5. \(\overrightarrow{AB}\times\overrightarrow{AC}=\begin{vmatrix}\mathbf{i}&\mathbf{j}&\mathbf{k}\\1&2&2\\2&-1&1\end{vmatrix}=\mathbf{i}(2+2)-\mathbf{j}(1-4)+\mathbf{k}(-1-4)=(4,3,-5)\).

    Area \(=\dfrac12|(4,3,-5)|=\dfrac12\sqrt{16+9+25}=\dfrac12\sqrt{50}=\dfrac{5\sqrt2}{2}\).

    Area \(=\dfrac{5\sqrt2}{2}\)

  6. \(\mathbf{a}\cdot\mathbf{b}=1(2)+2(3)+(-1)(4)=2+6-4=4\neq0\), so not orthogonal.

    \(\mathbf{c}=(2,-4,2)=-2(1,2,-1)=-2\mathbf{a}\), so \(\mathbf{c}\) is parallel to \(\mathbf{a}\) (opposite direction).

    not orthogonal; \(\mathbf{c}\parallel\mathbf{a}\)

  7. \(|\mathbf{d}|=\sqrt{4+1+4}=3\), so \(\hat{\mathbf{d}}=\dfrac13(2,-1,2)\).

    Required vector: \(6\hat{\mathbf{d}}=2(2,-1,2)=(4,-2,4)\).

    \((4,-2,4)\)

  8. \(\mathbf{b}\times\mathbf{c}=\begin{vmatrix}\mathbf{i}&\mathbf{j}&\mathbf{k}\\2&1&0\\0&1&3\end{vmatrix}=(3,-6,2)\).

    \(\mathbf{a}\cdot(\mathbf{b}\times\mathbf{c})=1(3)+0(-6)+2(2)=3+4=7\).

    The parallelepiped spanned by \(\mathbf{a},\mathbf{b},\mathbf{c}\) has volume \(|7|=7\) (nonzero \(\Rightarrow\) not coplanar).

    triple product \(=7\); volume \(=7\)

  9. Parallelepiped volume \(=|\mathbf{p}\cdot(\mathbf{q}\times\mathbf{r})|=|\det\operatorname{diag}(2,3,4)|=24\).

    Tetrahedron volume \(=\dfrac16\times24=4\).

    \(V=4\)

  10. Solve \(\alpha(1,0,1)+\beta(2,1,0)=(5,1,-1)\): \(\alpha+2\beta=5\), \(\beta=1\), \(\alpha=-1\).

    Check third: \(\alpha=-\!1\) matches \(z=-1\). So \(\mathbf{w}=-\mathbf{u}+\mathbf{v}\).

    \(\mathbf{w}=-\mathbf{u}+\mathbf{v}\) (possible)

  11. \(\mathbf{a}\cdot\mathbf{b}=0\Rightarrow 1(2)+k(-1)+2(k)=0\Rightarrow 2-k+2k=0\Rightarrow k=-2\).

    \(k=-2\)

  12. \(\mathbf{a}+\mathbf{b}=(3,2,1)\), \(|\mathbf{a}+\mathbf{b}|=\sqrt{9+4+1}=\sqrt{14}\).

    \((\mathbf{a}+\mathbf{b})\cdot\mathbf{a}=3+4+2=9\), \(|\mathbf{a}|=3\).

    \(\cos\theta=\dfrac{9}{3\sqrt{14}}=\dfrac{3}{\sqrt{14}}\), so \(\theta=\arccos\!\left(\dfrac{3}{\sqrt{14}}\right)\).

    \(|\mathbf{a}+\mathbf{b}|=\sqrt{14}\), \(\theta=\arccos\!\left(\dfrac{3}{\sqrt{14}}\right)\)
