MATH141 Revision — Differentiation Set 4 — Worked Answers

Worked solutions — check method and restrictions, not only the final line.
  1. $(f^{-1})'(4)=1/f'(1)$. $f'=3x^2+2$, so $f'(1)=5$. $1/5$
  2. $y'=\dfrac{2}{\sqrt{1-4x^2}}$. $2/\sqrt{1-4x^2}$
  3. $y'=\dfrac{2x}{1+x^4}$. $2x/(1+x^4)$
  4. $\dfrac{3}{3x-1}$. $3/(3x-1)$
  5. $\ln y=\sin x\ln x$, so $y'/y=\cos x\ln x+\sin x/x$, hence $y'=x^{\sin x}\bigl(\cos x\ln x+\dfrac{\sin x}{x}\bigr)$. $x^{\sin x}(\cos x\ln x+\sin x/x)$
  6. $\ln|y|=2\ln|x+1|+\tfrac12\ln|x-2|-3\ln|x+3|$. Differentiating: $y'/y=\dfrac{2}{x+1}+\dfrac{1}{2(x-2)}-\dfrac{3}{x+3}$. Multiply by $y$. $y\bigl(\frac{2}{x+1}+\frac{1}{2(x-2)}-\frac{3}{x+3}\bigr)$
  7. $f(0)=1$, $f'=2e^{2x}+1$, $f'(0)=3$, so $(f^{-1})'(1)=1/3$. $1/3$
  8. Let $y=\cos^{-1}x$, so $\cos y=x$, $-\sin y\,y'=1$, $y'=-1/\sin y=-1/\sqrt{1-x^2}$. Shown
  9. $\ln y=x\ln\ln x$, $y'/y=\ln\ln x+x\cdot\dfrac{1}{\ln x}\cdot\dfrac{1}{x}=\ln\ln x+\dfrac{1}{\ln x}$. $(\ln x)^x\bigl(\ln\ln x+1/\ln x\bigr)$
  10. $y'=\cot x$. $\cot x$
  11. $\log_b x=\ln x/\ln b$, derivative $1/(x\ln b)$. Shown
  12. $\ln y=\tfrac12\ln(1-x)-\tfrac12\ln(1+x)$, so $y'/y=\tfrac12\bigl(-\dfrac{1}{1-x}-\dfrac{1}{1+x}\bigr)=-\dfrac{1}{1-x^2}$. Thus $y'=-\dfrac{1}{(1-x^2)}\sqrt{\dfrac{1-x}{1+x}}=-\dfrac{1}{(1+x)\sqrt{1-x^2}}$. $-1/((1+x)\sqrt{1-x^2})$
