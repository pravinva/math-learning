A 3D lines: forms, checks, and classification

Every 3D line should be readable in three ways: geometric point + direction, algebraic parametric equations, and symmetric form. Exam speed comes from moving between these forms quickly, then using dot and cross products to classify relationships.

Core toolkit

\(\mathbf{r}=\mathbf{a}+t\mathbf{d}\), parametric \(x=x_0+at,\ y=y_0+bt,\ z=z_0+ct\), symmetric \(\dfrac{x-x_0}{a}=\dfrac{y-y_0}{b}=\dfrac{z-z_0}{c}\).

Parallel lines: \(\mathbf{d}_1 \parallel \mathbf{d}_2\). Perpendicular directions: \(\mathbf{d}_1\cdot\mathbf{d}_2=0\). Intersecting lines: solve simultaneous parameters and get one consistent point.

Worked example

Line \(L_1:\mathbf{r}=(1,2,-1)+t(2,-1,3)\), line \(L_2:\mathbf{r}=(5,0,5)+s(-4,2,-6)\).

\((-4,2,-6)=-2(2,-1,3)\), so directions are parallel.

Check if same line: substitute point \((5,0,5)\) into \(L_1\). From \(1+2t=5\Rightarrow t=2\), then \(2-2=0\), and \(-1+6=5\), consistent. So they are coincident lines.

A1

Convert \(\mathbf{r}=(2,-1,4)+t(3,2,-5)\) into parametric equations.

Solution

\(x=2+3t,\ y=-1+2t,\ z=4-5t\).

A2

Write symmetric form of line through \((1,3,-2)\) with direction \((4,-1,2)\).

Solution

\(\dfrac{x-1}{4}=\dfrac{y-3}{-1}=\dfrac{z+2}{2}\).

A3

Find a direction vector for \(\dfrac{x-5}{2}=\dfrac{y+1}{-3}=\dfrac{z-4}{7}\).

Solution

Direction vector is \((2,-3,7)\).

A4

Classify the line pair: \((1,0,2)+t(2,1,-1)\) and \((3,1,1)+s(4,2,-2)\).

Solution

\((4,2,-2)=2(2,1,-1)\), so lines are parallel or coincident. Test point \((3,1,1)\) in first line: \(1+2t=3\Rightarrow t=1\), \(0+1=1\), \(2-1=1\), yes. Coincident.

A5

Classify: \((0,1,2)+t(1,2,0)\) and \((2,2,4)+s(-2,1,1)\).

Solution

Directions not parallel. Solve \(0+t=2-2s,\ 1+2t=2+s,\ 2=4+s\Rightarrow s=-2\). Then \(t=6\), second equation gives \(13\neq0\). No intersection. Skew.

A6

Find intersection (if any): \((1,2,3)+t(1,-1,2)\) and \((4,-1,1)+s(-1,2,1)\).

Solution

From \(x\): \(1+t=4-s\Rightarrow t+s=3\). From \(y\): \(2-t=-1+2s\Rightarrow t+2s=3\). So \(s=0,\ t=3\). Check \(z\): \(3+2(3)=9\), \(1+0=1\), inconsistent. Skew.

A7

Find a line through \((2,1,0)\) parallel to \((3,-2,4)\).

Solution

\(\mathbf{r}=(2,1,0)+t(3,-2,4)\).

A8

Find a line through \((1,-1,2)\) perpendicular to direction \((2,1,2)\) and using direction \((1,-2,0)\).

Solution

Check orthogonality: \((1,-2,0)\cdot(2,1,2)=2-2+0=0\). So line is \(\mathbf{r}=(1,-1,2)+t(1,-2,0)\).

A9

Point \(P(5,3,-1)\) on line \((1,-1,2)+t(2,4,-3)\)?

Solution

From \(x\): \(1+2t=5\Rightarrow t=2\). Then \(y=-1+8=7\neq3\). Not on the line.

A10

For line \(\mathbf{r}=(3,0,-2)+t(-2,1,2)\), find point at \(t=-3\).

Solution

\((x,y,z)=(3+6,\ 0-3,\ -2-6)=(9,-3,-8)\).

A11

Are \((1,2,3)+t(0,2,-1)\) and \((4,8,0)+s(0,4,-2)\) parallel, coincident, or distinct parallel?

Solution

Directions are multiples: \((0,4,-2)=2(0,2,-1)\). Check if second point on first: \(x=1\) always on first, but second has \(x=4\). So distinct parallel.

A12

Find direction cosines for direction vector \((2,-3,6)\).

Solution

\(|\mathbf{d}|=\sqrt{4+9+36}=7\). Direction cosines \((\cos\alpha,\cos\beta,\cos\gamma)=\left(\frac{2}{7},-\frac{3}{7},\frac{6}{7}\right)\).

B Planes: forms, normals, and angle relations

For planes, the normal vector is king. It controls equation form, parallel/perpendicular tests, and angle calculations with other planes and lines.

Core toolkit

General plane: \(ax+by+cz=d\), normal \(\mathbf{n}=(a,b,c)\). Through point \(P_0(x_0,y_0,z_0)\): \(a(x-x_0)+b(y-y_0)+c(z-z_0)=0\).

Angle between planes from normals: \(\cos\theta=\dfrac{|\mathbf{n}_1\cdot\mathbf{n}_2|}{|\mathbf{n}_1||\mathbf{n}_2|}\). Line parallel to plane iff \(\mathbf{d}\cdot\mathbf{n}=0\).

Worked example

Find plane through \(A(1,0,2)\) with normal \((2,-1,3)\).

Use point-normal form: \(2(x-1)-1(y-0)+3(z-2)=0\).

Simplify: \(2x-y+3z=8\).

B1

Write plane through \((2,-1,4)\) with normal \((1,3,-2)\).

Solution

\((x-2)+3(y+1)-2(z-4)=0\Rightarrow x+3y-2z+9=0\).

B2

Find normal vector of \(4x-5y+2z=11\).

Solution

\(\mathbf{n}=(4,-5,2)\).

B3

Plane through points \(A(1,0,0),B(0,1,0),C(0,0,1)\).

Solution

Intercept form is \(x+y+z=1\).

B4

Are planes \(2x-y+z=3\) and \(4x-2y+2z=9\) parallel, identical, or intersecting?

Solution

Normals are parallel (second is 2 times first). Constants not same ratio (\(3\times2=6\neq9\)). Distinct parallel planes.

B5

Angle between planes \(x+y+z=0\) and \(x-y+2z=0\).

Solution

\(\mathbf{n}_1=(1,1,1),\mathbf{n}_2=(1,-1,2)\). Dot \(=2\). Magnitudes \(\sqrt3,\sqrt6\). \(\cos\theta=\frac{2}{\sqrt{18}}=\frac{2}{3\sqrt2}\). \(\theta\approx61.9^\circ\).

B6

Line direction \((2,-1,3)\) and plane \(2x+4y-2z=7\): line parallel/perpendicular/neither to plane?

Solution

Plane normal \((2,4,-2)\). Dot with direction \(=4-4-6=-6\neq0\), so not parallel. Direction not scalar multiple of normal, so not perpendicular. Neither.

B7

Find plane parallel to \(3x-y+4z=10\) through \((2,1,-1)\).

Solution

Same normal: \(3x-y+4z=d\). Substitute point: \(6-1-4=1\). Plane: \(3x-y+4z=1\).

B8

Find plane perpendicular to \(x-2y+2z=5\) with normal parallel to line direction \((1,2,2)\), through origin.

Solution

Required normal \((1,2,2)\). Through origin gives \(x+2y+2z=0\).

B9

Check if point \(P(1,-2,3)\) lies on \(2x+y-z=-3\).

Solution

\(2(1)+(-2)-3=-3\). Yes, lies on the plane.

B10

Find intercepts of plane \(2x+3y+6z=12\).

Solution

\(x\)-intercept \(=6\), \(y\)-intercept \(=4\), \(z\)-intercept \(=2\). Points: \((6,0,0),(0,4,0),(0,0,2)\).

B11

If two planes are perpendicular, what relation must normals satisfy?

Solution

\(\mathbf{n}_1\cdot\mathbf{n}_2=0\).

B12

Find \(k\) so planes \(x+2y+kz=1\) and \(2x-y+3z=4\) are perpendicular.

Solution

Normals \((1,2,k)\), \((2,-1,3)\). Dot \(=2-2+3k=3k\). Set 0 gives \(k=0\).

C Intersections and systems in 3D

This is where line and plane algebra become one system: line-plane intersection, intersection line of two planes, and consistency tests using parameter equations.

Workflow

Line with plane: substitute parametric line into plane and solve one parameter.

Plane with plane: normals give direction of intersection line by cross product \(\mathbf{d}=\mathbf{n}_1\times\mathbf{n}_2\), then find one shared point.

C1

Intersect line \((1,0,2)+t(2,-1,1)\) with plane \(x+y+z=5\).

Solution

\((1+2t)+(0-t)+(2+t)=5\Rightarrow3+2t=5\Rightarrow t=1\). Intersection point \((3,-1,3)\).

C2

Determine if line \((2,1,-1)+t(1,2,3)\) is parallel to plane \(x-2y+z=4\).

Solution

Normal \((1,-2,1)\). Dot with direction \(1-4+3=0\). Direction parallel to plane. Check one point: \(2-2-1=-1\neq4\). So line is parallel and distinct (no intersection).

C3

Find intersection line of planes \(x+y+z=6\) and \(x-y+z=2\).

Solution

Subtract equations: \(2y=4\Rightarrow y=2\). Then \(x+z=4\Rightarrow x=4-z\). Let \(z=t\). Line: \((x,y,z)=(4-t,2,t)\) or \(\mathbf{r}=(4,2,0)+t(-1,0,1)\).

C4

Find intersection line of \(2x-y+z=1\) and \(x+3y-z=7\).

Solution

Add equations: \(3x+2y=8\Rightarrow x=\frac{8-2y}{3}\). Let \(y=t\). From first: \(z=1-2x+y=1-\frac{16-4t}{3}+t=\frac{-13+7t}{3}\). Line: \(\left(\frac{8}{3},0,-\frac{13}{3}\right)+t\left(-\frac{2}{3},1,\frac{7}{3}\right)\).

C5

Do planes \(x+2y-z=3\), \(2x+4y-2z=6\), \(3x-y+z=5\) intersect in one point?

Solution

First two are same plane (second is double first). Solve first and third jointly gives a line. So not a unique point; infinite points on their intersection line.

C6

Line through \(A(0,1,2)\) and \(B(3,-2,5)\): find line-plane intersection with \(x+y+z=4\).

Solution

Direction \(B-A=(3,-3,3)\). Line: \((0,1,2)+t(3,-3,3)\). Substitute: \(3t+(1-3t)+(2+3t)=4\Rightarrow3+3t=4\Rightarrow t=\frac13\). Point \((1,0,3)\).

C7

Find parameter \(k\) so line \((1,2,0)+t(1,k,2)\) lies in plane \(2x-y+z=0\).

Solution

All points must satisfy plane. Base point gives \(2(1)-2+0=0\), good. Direction must be orthogonal to normal \((2,-1,1)\): \(2(1)-k+2=0\Rightarrow k=4\).

C8

Do lines \((1,0,1)+t(2,1,-1)\) and \((3,1,0)+s(1,0,2)\) intersect?

Solution

From \(y\): \(t=1\). Then \(x=3\), so \(3=3+s\Rightarrow s=0\). Check \(z\): first \(=0\), second \(=0\). Yes, intersect at \((3,1,0)\).

C9

For planes \(x+y+z=1\) and \(2x-y+z=3\), find direction vector of their intersection line.

Solution

\(\mathbf{n}_1=(1,1,1)\), \(\mathbf{n}_2=(2,-1,1)\). Cross product \(\mathbf{d}=\mathbf{n}_1\times\mathbf{n}_2=(2,1,-3)\) (or any scalar multiple).

C10

Solve system: \(x+y+z=4,\ x-y+z=2,\ 2x+z=5\).

Solution

Subtract first two: \(2y=2\Rightarrow y=1\). First gives \(x+z=3\). Third gives \(2x+z=5\). Subtract: \(x=2\), hence \(z=1\). Point \((2,1,1)\).

C11

Line \((0,0,0)+t(1,2,3)\) with plane \(2x-4y+2z=8\): intersect, parallel, or in-plane?

Solution

Direction dot normal \((2,-4,2)\cdot(1,2,3)=2-8+6=0\), so line parallel to plane. Origin gives 0 not 8, so not in plane. Distinct parallel, no intersection.

C12

Find line through intersection of planes \(x+y=2\), \(y+z=1\), and passing through point with \(z=0\).

Solution

Let \(y=t\). Then \(x=2-t,\ z=1-t\). For \(z=0\), \(t=1\), point \((1,1,0)\). Direction from parametric form is \((-1,1,-1)\). Line: \((1,1,0)+s(-1,1,-1)\).

D Distances and angles in full 3D

This is where vector geometry becomes measurement: point-line distance, point-plane distance, line-plane angle, and shortest distance between skew lines.

Distance formulas

Point-plane distance from \((x_0,y_0,z_0)\) to \(ax+by+cz+d=0\): \(\dfrac{|ax_0+by_0+cz_0+d|}{\sqrt{a^2+b^2+c^2}}\).

Point-line distance for line through \(A\) direction \(\mathbf{d}\): \(\dfrac{\| \overrightarrow{AP}\times \mathbf{d}\|}{\|\mathbf{d}\|}\).

Skew-line distance: \(\dfrac{|(\overrightarrow{A_1A_2})\cdot(\mathbf{d}_1\times\mathbf{d}_2)|}{\|\mathbf{d}_1\times\mathbf{d}_2\|}\).

D1

Distance from \(P(2,-1,3)\) to plane \(x+2y+2z-5=0\).

Solution

\(\frac{|2+2(-1)+2(3)-5|}{\sqrt{1+4+4}}=\frac{|1|}{3}=\frac13\).

D2

Distance from \(Q(0,4,-2)\) to plane \(2x-y+2z+1=0\).

Solution

\(\frac{|0-4-4+1|}{\sqrt{4+1+4}}=\frac{7}{3}\).

D3

Distance from point \(P(3,2,1)\) to line \((1,0,2)+t(2,1,-1)\).

Solution

\(\overrightarrow{AP}=(2,2,-1)\), \(\mathbf{d}=(2,1,-1)\). Cross \(=( -1,0,-2)\), magnitude \(\sqrt5\). \(|\mathbf{d}|=\sqrt6\). Distance \(=\sqrt5/\sqrt6=\sqrt{30}/6\).

D4

Angle between line direction \((1,2,2)\) and plane \(2x-y+2z=4\).

Solution

Normal \((2,-1,2)\). \(\sin\phi=\dfrac{|d\cdot n|}{|d||n|}=\dfrac{|2-2+4|}{3\cdot3}=\frac49\). So \(\phi=\sin^{-1}(4/9)\approx26.4^\circ\).

D5

Angle between lines with directions \((2,1,-2)\) and \((1,-2,2)\).

Solution

Dot \(=2-2-4=-4\). Magnitudes \(3,3\). Acute angle uses absolute value: \(\cos\theta=4/9\), \(\theta\approx63.6^\circ\).

D6

Shortest distance between skew lines \(L_1:(0,0,0)+t(1,1,0)\), \(L_2:(1,0,2)+s(0,1,1)\).

Solution

\(\mathbf{d}_1\times\mathbf{d}_2=(1,-1,1)\), magnitude \(\sqrt3\). \(\overrightarrow{A_1A_2}=(1,0,2)\). Dot with cross \(=1+0+2=3\). Distance \(=|3|/\sqrt3=\sqrt3\).

D7

Distance between parallel planes \(3x-2y+6z=4\) and \(3x-2y+6z=-8\).

Solution

Write as \(3x-2y+6z-4=0\), \(3x-2y+6z+8=0\). Distance \(=\frac{|(-4)-(+8)|}{\sqrt{9+4+36}}=\frac{12}{7}\).

D8

Find point-plane distance from origin to \(4x+4y+7z=14\).

Solution

\(\frac{|0+0+0-14|}{\sqrt{16+16+49}}=\frac{14}{9}\).

D9

Distance from \(P(2,1,0)\) to line through \(A(1,1,1)\) and \(B(4,3,2)\).

Solution

\(\mathbf{d}=B-A=(3,2,1)\), \(\overrightarrow{AP}=(1,0,-1)\). Cross \((2,-4,2)\), magnitude \(2\sqrt6\). \(|d|=\sqrt{14}\). Distance \(=2\sqrt6/\sqrt{14}=2\sqrt{21}/7\).

D10

Find angle between planes \(x+z=0\) and \(x+y=0\).

Solution

Normals \((1,0,1)\), \((1,1,0)\). Dot \(=1\). Magnitudes \(\sqrt2,\sqrt2\). \(\cos\theta=1/2\Rightarrow\theta=60^\circ\).

D11

Line direction \((1,1,1)\) with plane \(x+y+z=7\): angle between line and plane?

Solution

Plane normal \((1,1,1)\) is parallel to line direction. Line is perpendicular to plane, so line-plane angle is \(90^\circ\).

D12

For point \(P(4,-2,1)\), find foot of perpendicular to plane \(x-y+2z=3\).

Solution

Normal \((1,-1,2)\). Foot is \(P-\lambda n\). Enforce plane:

\((4-\lambda)-(-2+\lambda)+2(1-2\lambda)=3\Rightarrow8-6\lambda=3\Rightarrow\lambda=5/6\).

Foot \(=\left(4-\frac56,\ -2+\frac56,\ 1-\frac{10}{6}\right)=\left(\frac{19}{6},-\frac{7}{6},-\frac{2}{3}\right)\).
