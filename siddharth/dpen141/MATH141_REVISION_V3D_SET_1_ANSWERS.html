V3D Set 1 — Answers

  1. \(2\mathbf{a}-\mathbf{b}=(7,-7,7)\), magnitude \(=7\sqrt3\). \(\cos\theta=\frac{\mathbf{a}\cdot\mathbf{b}}{|\mathbf{a}||\mathbf{b}|}=\frac{-7}{\sqrt{21}\sqrt{35}}=-\frac{1}{\sqrt{15}}\).
  2. \(\text{proj}_{\mathbf{v}}\mathbf{u}=\frac{\mathbf{u}\cdot\mathbf{v}}{\mathbf{v}\cdot\mathbf{v}}\mathbf{v}=\frac{-4}{9}(1,-2,2)\). Perpendicular component \(=\mathbf{u}-\text{proj}\).
  3. \(\mathbf{a}\times\mathbf{b}=(10,-8,-7)\). Triangle area \(=\frac12|\mathbf{a}\times\mathbf{b}|=\frac12\sqrt{213}\).
  4. \(\overrightarrow{AB}=(2,-3,4)\), \(\overrightarrow{BC}=(2,-3,4)\) so collinear.
  5. \(\mathbf{r}=(2,-1,3)+\lambda(3,4,-6)\), symmetric: \(\frac{x-2}{3}=\frac{y+1}{4}=\frac{z-3}{-6}\).
  6. Normal \(=(B-A)\times(C-A)=(-2,1,1)\). Plane: \(-2(x-1)+(y-0)+(z-2)=0\Rightarrow 2x-y-z=0\).
  7. Angle between normals \(\mathbf{n}_1=(2,-1,2)\), \(\mathbf{n}_2=(1,2,-2)\): \(\cos\phi=\frac{|\mathbf{n}_1\cdot\mathbf{n}_2|}{|\mathbf{n}_1||\mathbf{n}_2|}=\frac{4}{3\sqrt6}\).
  8. Substitute line into plane: \((1+2t)+(2-t)+(3+t)=7\Rightarrow t=\frac12\). Point \((2,\frac32,\frac72)\).
  9. \(d=\frac{|3(4)-2(-1)+6(2)-5|}{\sqrt{3^2+(-2)^2+6^2}}=\frac{21}{7}=3\).
  10. Direction vectors are proportional, \((4,2,-2)=2(2,1,-1)\), so parallel; not same line since second point not on first.
  11. Line direction \(\mathbf{d}=(2,-1,3)\), vector from line point to \(S\): \((-1,3,2)\). Normal \(\mathbf{n}=\mathbf{d}\times(-1,3,2)=(-11,-7,5)\). Plane through \(S\): \(-11x-7(y-1)+5(z-2)=0\Rightarrow 11x+7y-5z+3=0\).
  12. Volume \(=\frac16|\mathbf{p}\cdot(\mathbf{q}\times\mathbf{r})|=\frac16|1\cdot(-13)+2\cdot(-2)+0\cdot8|=\frac{17}{6}\).
