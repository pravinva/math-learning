MATH141 Revision — Differentiation Set 5 — Worked Answers

Worked solutions — check method and restrictions, not only the final line.
  1. Direct expansion: $\bigl(\frac{e^x+e^{-x}}{2}\bigr)^2-\bigl(\frac{e^x-e^{-x}}{2}\bigr)^2=\frac{4}{4}=1$. Shown
  2. $y'=3\cosh(3x)$. $3\cosh(3x)$
  3. $y'=2x\sinh(x^2)$. $2x\sinh(x^2)$
  4. $\dfrac{d}{dx}\tanh x=\operatorname{sech}^2x$. $\operatorname{sech}^2x$
  5. Let $y=\sinh^{-1}x$, so $\sinh y=x$, $\cosh y\,y'=1$, $y'=1/\cosh y=1/\sqrt{1+\sinh^2y}=1/\sqrt{1+x^2}$. Shown
  6. $y'=\tanh x$. $\tanh x$
  7. $\sinh x=0\Rightarrow x=0$; $\cosh x=1\Rightarrow x=0$. both only at $x=0$
  8. $y'(x)=\sinh x$, so $y'(0)=0$, $y(0)=1$. Tangent: $y=1$. $y=1$
  9. $y'=\sinh x+x\cosh x$. $\sinh x+x\cosh x$
  10. RHS: $2\cdot\frac{e^x-e^{-x}}{2}\cdot\frac{e^x+e^{-x}}{2}=\frac{e^{2x}-e^{-2x}}{2}=\sinh(2x)$. Shown
  11. $y'= \cosh x+\sinh x=y$, so $y''=y$. $y''=y$
  12. $y'=\dfrac{1}{1-(x/2)^2}\cdot\dfrac{1}{2}=\dfrac{2}{4-x^2}$. $2/(4-x^2)$
