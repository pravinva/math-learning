TLP Set 2 — Answers

  1. \(\cos(3x+\pi/4)=-1/2\Rightarrow 3x+\pi/4=2\pi/3,4\pi/3+2k\pi\). Solve and list values in range.
  2. Amplitude 2, midline \(y=1\), period \(2\pi\), max 3, min -1, shift right \(\pi/2\).
  3. \(x=1+\ln9\). Also \(2x+5=e^3\Rightarrow x=(e^3-5)/2\).
  4. Set \(Y=\ln y\), \(X=\ln x\): \(Y=\ln k+nX\) (linear form).
  5. \(y=e^{1.8}x^{0.42}\Rightarrow y=e^{1.8}\cdot50^{0.42}\approx25.4\).
  6. Exponent is \(-0.63\), so inverse/decay with increasing \(x\).
  7. \((x+1)\ln5=2x\ln2\Rightarrow x=\frac{\ln5}{2\ln2-\ln5}\).
  8. \(\frac{d}{dx}\ln(\sin x)=\frac{\cos x}{\sin x}=\cot x\).
  9. \(\sqrt2\sin(x+\pi/4)=1\Rightarrow \sin(x+\pi/4)=1/\sqrt2\), so \(x=0,\pi/2\).
  10. \(y\propto x^b\), \(2^b=3\Rightarrow b=\log_2 3\).
  11. Elasticity \(=-0.35\). 10% increase in \(Q\) gives about \(3.5\%\) decrease in \(C\).
  12. \(\int_0^{\pi/3}\cos x\,dx=\sin x\big|_0^{\pi/3}=\sqrt3/2\).
