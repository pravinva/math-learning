MATH141 Revision — 3D Analytic Geometry Set 2 — Worked Answers

Full workings for each question

  1. \(x=2+t\), \(y=3-2t\), \(z=-1+4t\).

    \(x=2+t,\ y=3-2t,\ z=-1+4t\)

  2. \(3(x-0)-1(y-1)+2(z-2)=0\Rightarrow 3x-y+2z-3=0\).

    \(3x-y+2z=3\)

  3. \(\mathbf{d}=(1,1,1)\), \(\mathbf{n}=(1,-1,0)\).

    \(\sin\alpha=\dfrac{|\mathbf{d}\cdot\mathbf{n}|}{|\mathbf{d}||\mathbf{n}|}=\dfrac{|1-1|}{\sqrt3\cdot\sqrt2}=0\Rightarrow\alpha=0\).

    Line is parallel to the plane (direction perpendicular to normal).

    \(\alpha=0\) (parallel to plane)

  4. Line: through \((2,3,0)\) with \(\mathbf{d}=(1,2,-1)\). Set \(2+t=1\Rightarrow t=-1\). Then \(y=3+2(-1)=1\), \(z=0+(-1)(-1)=1\).

    Gives \((1,1,1)\), so yes \(Q\) lies on the line.

    yes

  5. Line direction \(\mathbf{d}=(1,1,0)\), \(\overrightarrow{AP}=(1,2,3)\).

    \(d=\dfrac{|\overrightarrow{AP}\times\mathbf{d}|}{|\mathbf{d}|}\). Cross: \((1,2,3)\times(1,1,0)=(-3,3,-1)\).

    \(|\text{cross}|=\sqrt{9+9+1}=\sqrt{19}\), \(|\mathbf{d}|=\sqrt2\), so distance \(=\sqrt{\dfrac{19}{2}}=\dfrac{\sqrt{38}}{2}\).

    \(\dfrac{\sqrt{38}}{2}\)

  6. \(\mathbf{n}_1\times\mathbf{n}_2=(2,-1,1)\times(1,1,-1)=(0,3,3)\), simplify to \((0,1,1)\).

    Add the planes: \(3x=4\Rightarrow x=\dfrac43\). Set \(z=\lambda\): from second, \(y=\lambda+1-\dfrac43=\lambda-\dfrac13\).

    Point when \(\lambda=0\): \(\left(\dfrac43,-\dfrac13,0\right)\). Line: \(\mathbf{r}=\left(\dfrac43,-\dfrac13,0\right)+\lambda(0,1,1)\).

    \(\mathbf{r}=\left(\dfrac43,-\dfrac13,0\right)+\lambda(0,1,1)\)

  7. \(\mathbf{d}_2=(4,2,0)=2\mathbf{d}_1\), so parallel.

    Is \((3,3,3)\) on \(L_1\)? \(1+2s=3\Rightarrow s=1\); \(2+s=3\Rightarrow s=1\); \(z=3\) matches. Same line (coincident).

    coincident (same line)

  8. \(\overrightarrow{AB}=(1,-1,0)\), \(\overrightarrow{AC}=(0,-1,-2)\).

    \(\mathbf{n}=(1,-1,0)\times(0,-1,-2)=(2,2,-1)\).

    Through \(A\): \(2(x-1)+2(y-1)-(z-1)=0\Rightarrow 2x+2y-z=3\).

    \(2x+2y-z=3\)

  9. Reflection in \(x=0\) negates the \(x\)-coordinate: \(B'=(-2,0,1)\).

    \((-2,0,1)\)

  10. Point \(t(1,2,2)\) has distance \(|t|\sqrt{1+4+4}=3|t|=3\Rightarrow |t|=1\).

    Points: \(\pm(1,2,2)\).

    \((1,2,2)\) and \((-1,-2,-2)\)

  11. Plane \(3x-6y+6z=9\), or divide by \(3\): \(x-2y+2z=3\).

    Distance \(=\dfrac{|0-0+0-3|}{\sqrt{1+4+4}}\) wait using original: \(\dfrac{|-9|}{\sqrt{9+36+36}}=\dfrac{9}{9}=1\).

    Unit normal: \(\dfrac{(3,-6,6)}{9}=\left(\dfrac13,-\dfrac23,\dfrac23\right)\) (or opposite).

    distance \(1\); unit normal \(\left(\dfrac13,-\dfrac23,\dfrac23\right)\)

  12. Directions \((1,1,0)\), \((0,1,1)\) not parallel. From Set 1 Q8 style: solving equality gave an intersection earlier with different points — here \(L_1\) through \((1,0,0)\), \(L_2\) through \((0,1,1)\).

    Set \((1+s,s,0)=(t,1+t,1+t)\). From \(z\): \(0=1+t\Rightarrow t=-1\). From \(x\): \(1+s=-1\Rightarrow s=-2\). \(y\): left \(s=-2\), right \(1-1=0\) — contradiction. So no intersection, not parallel \(\Rightarrow\) skew.

    Shortest distance: \(d=\dfrac{|(\mathbf{P}_2-\mathbf{P}_1)\cdot(\mathbf{d}_1\times\mathbf{d}_2)|}{|\mathbf{d}_1\times\mathbf{d}_2|}\).

    \(\mathbf{d}_1\times\mathbf{d}_2=(1,-1,1)\), \(\mathbf{P}_2-\mathbf{P}_1=(-1,1,1)\).

    Numerator \(|-1-1+1|=1\), denominator \(\sqrt3\), so \(d=\dfrac{1}{\sqrt3}=\dfrac{\sqrt3}{3}\).

    skew; distance \(\dfrac{\sqrt3}{3}\)
