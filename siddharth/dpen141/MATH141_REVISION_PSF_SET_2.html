MATH141 Revision — Parametric + Special Functions Set 2

12 exam-style questions · Intermediate
Focus: parameter restrictions, repeated points, smooth joins, absolute-value structure, subtle limits, and parametric derivatives.
  1. For $x=1+2\cos t$, $y=-2+3\sin t$, $-\pi/2\le t\le\pi/2$, find the Cartesian equation and describe exactly which half is traced, including direction.
  2. The semicubical parabola is parametrised by $x=t^2$, $y=t^3$, $-2\le t\le2$. Eliminate $t$, state all Cartesian restrictions, and describe the motion as $t$ increases.
  3. Let $x=t+\dfrac1t$ and $y=t^2+\dfrac1{t^2}$ for $t\ne0$. Eliminate $t$ and identify the exact set of $x$-values attained.
  4. For $x=t^2-2$, $y=t^3-4t$, find the nonzero parameter values that produce the same point. Find both tangent gradients there and explain the geometry.
  5. Determine $a$ and $b$ so that $f(x)=\begin{cases}ax+b,&x<1\\x^2,&x\ge1\end{cases}$ is differentiable at $x=1$.
  6. Write $f(x)=|x^2-4|$ piecewise. Find every point where $f$ is not differentiable and justify each using one-sided gradients.
  7. Solve $\operatorname{sgn}(x-1)+\operatorname{sgn}(x+2)=0$, taking $\operatorname{sgn}(0)=0$. Treat the breakpoints explicitly.
  8. Prove directly from the definition of signum that $|x|\operatorname{sgn}(x)=x$ for every real $x$, including $x=0$. Hence simplify $|x-3|\operatorname{sgn}(x-3)+2$.
  9. Use the limit definition and rationalisation to find the derivative of $f(x)=\sqrt{x}$ at an arbitrary $x>0$.
  10. Define $f(0)=0$ and $f(x)=x^2\sin(1/x)$ for $x\ne0$. Prove that $f$ is differentiable at $0$ from first principles and find $f'(0)$.
  11. Define $g(0)=0$ and $g(x)=x\sin(1/x)$ for $x\ne0$. Determine whether $g$ is (i) continuous and (ii) differentiable at $0$, with limit-based justification.
  12. For $x=t^2+1$, $y=t^3-t$, find the tangent line and $\dfrac{d^2y}{dx^2}$ at $t=2$.
