MATH141 Revision — Trig + Log-Log + Power Models Set 2

12 exam-style questions
  1. Solve \(4\cos(3x+\pi/4)=-2\) for \(0\le x<2\pi\).
  2. Sketch key features of \(y=2\sin(x-\pi/2)+1\): intercepts, max/min, one period.
  3. Solve \(e^{x-1}=9\) and \(\ln(2x+5)=3\).
  4. Derive linear regression variables for power law \(y=kx^n\) using natural logs.
  5. For \(\ln y=1.8+0.42\ln x\), estimate \(y\) at \(x=50\).
  6. Given data fits \(\log y=2.1-0.63\log x\), determine if model grows or decays with \(x\).
  7. Solve \(5^{x+1}=2^{2x}\) exactly in log form.
  8. Differentiate \(y=\ln(\sin x)\) for \(0<x<\pi\).
  9. Find all \(x\in[0,2\pi)\) where \(\sin x+\cos x=1\).
  10. If \(y=Ax^b\) and doubling \(x\) triples \(y\), find \(b\).
  11. For \(C=120Q^{-0.35}\), find percentage change in \(C\) when \(Q\) increases by 10% (use elasticity approximation).
  12. Find exact area under \(y=\cos x\) from \(0\) to \(\pi/3\).
