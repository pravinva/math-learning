MATH141 Revision — Differentiation Set 4

12 exam-style questions · Week 9: inverse derivatives + logarithmic differentiation
Scope: Use inverse-function derivatives and logarithmic differentiation for awkward products/powers.
  1. If $f(x)=x^3+2x+1$, find $(f^{-1})'(4)$. (Note $f(1)=4$.)
  2. Differentiate $y=\sin^{-1}(2x)$ for $|2x|<1$.
  3. Differentiate $y=\tan^{-1}(x^2)$.
  4. Find $\dfrac{d}{dx}\ln|3x-1|$.
  5. Use logarithmic differentiation to find $y'$ if $y=x^{\sin x}$ for $x>0$.
  6. Differentiate $y=\dfrac{(x+1)^2\sqrt{x-2}}{(x+3)^3}$ for $x>2$ by logarithmic differentiation.
  7. If $f(x)=e^{2x}+x$, find $(f^{-1})'(1)$.
  8. Differentiate $y=\cos^{-1}(x)$ and verify that $\dfrac{d}{dx}\cos^{-1}x=-\dfrac{1}{\sqrt{1-x^2}}$.
  9. Find $y'$ if $y=(\ln x)^x$ for $x>1$.
  10. Differentiate $y=\ln(\sin x)$ for $0<x<\pi$.
  11. Show that $\dfrac{d}{dx}\log_b x=\dfrac{1}{x\ln b}$ for $b>0$, $b\neq1$.
  12. If $y=\sqrt{\dfrac{1-x}{1+x}}$ for $|x|<1$, find $y'$ by logarithmic differentiation and simplify.
