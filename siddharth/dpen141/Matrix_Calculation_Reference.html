1 Determinant — 2×2
Formula $$\det\begin{pmatrix}a&b\\c&d\end{pmatrix}=ad-bc.$$ Singular (no inverse) iff $\det=0$.
Worked example

Compute $\det\begin{pmatrix}3&5\\2&7\end{pmatrix}$.

01$ad-bc=3\cdot7-5\cdot2=21-10=11$.

Answer: $11$
Practice — try first

Compute $\det\begin{pmatrix}4&-1\\6&2\end{pmatrix}$.

$4\cdot2-(-1)\cdot6=8+6=14$.

Answer: $14$
2 Determinant — 3×3 (cofactor)
Method Expand along row 1: $$\det A=a_{11}C_{11}+a_{12}C_{12}+a_{13}C_{13},\quad C_{ij}=(-1)^{i+j}M_{ij}.$$ Signs: $\begin{pmatrix}+&-&+\\-&+&-\\+&-&+\end{pmatrix}$. Pick a row/column with zeros if you can.
Worked example

$\det\begin{pmatrix}1&2&3\\0&4&5\\1&0&6\end{pmatrix}$.

01Expand row 1: $1\cdot\det\begin{pmatrix}4&5\\0&6\end{pmatrix}-2\cdot\det\begin{pmatrix}0&5\\1&6\end{pmatrix}+3\cdot\det\begin{pmatrix}0&4\\1&0\end{pmatrix}$.

02$1(24-0)-2(0-5)+3(0-4)=24+10-12=22$.

Answer: $22$
Practice — try first

$\det\begin{pmatrix}2&0&1\\1&3&0\\0&2&4\end{pmatrix}$.

Expand row 1: $2\det\begin{pmatrix}3&0\\2&4\end{pmatrix}-0+1\det\begin{pmatrix}1&3\\0&2\end{pmatrix}=2(12-0)+(2-0)=24+2=26$.

Answer: $26$
3 Gaussian elimination (solve $A\mathbf{x}=\mathbf{b}$)
Method Form augmented matrix $[A|\mathbf{b}]$. Allowed ops: swap rows; scale a row by $k\neq0$; add multiple of one row to another. Get to upper triangular (REF), then back-substitute. Or continue to RREF $[I|\mathbf{x}]$ and read $\mathbf{x}$ off.
Worked example

Solve $\begin{cases}x+y=5\\2x-y=1\end{cases}$.

01$\begin{bmatrix}1&1&|&5\\2&-1&|&1\end{bmatrix}$. $R_2\leftarrow R_2-2R_1$: $\begin{bmatrix}1&1&|&5\\0&-3&|&-9\end{bmatrix}$.

02$R_2\leftarrow R_2/(-3)$: $\begin{bmatrix}1&1&|&5\\0&1&|&3\end{bmatrix}$. Then $R_1\leftarrow R_1-R_2$: $\begin{bmatrix}1&0&|&2\\0&1&|&3\end{bmatrix}$.

Answer: $x=2,\ y=3$
Practice — try first

Solve $\begin{cases}2x+y=7\\x-y=2\end{cases}$ by Gauss.

$\begin{bmatrix}2&1&|&7\\1&-1&|&2\end{bmatrix}$. Swap for pivot ease: $\begin{bmatrix}1&-1&|&2\\2&1&|&7\end{bmatrix}$. $R_2\leftarrow R_2-2R_1$: $\begin{bmatrix}1&-1&|&2\\0&3&|&3\end{bmatrix}$. $R_2\leftarrow R_2/3$: $y=1$. Back-sub: $x-1=2\Rightarrow x=3$.

Answer: $x=3,\ y=1$
4 Matrix inverse
Formulas / method

2×2: if $\det A=ad-bc\neq0$, then $$A^{-1}=\dfrac{1}{ad-bc}\begin{pmatrix}d&-b\\-c&a\end{pmatrix}.$$

Any $n$: row-reduce $[A|I]$ to $[I|A^{-1}]$. (Fails iff a zero row appears in the left block — singular.)

Worked example (2×2 formula)

$A=\begin{pmatrix}2&1\\5&3\end{pmatrix}$. $\det=6-5=1$.

01$A^{-1}=\dfrac{1}{1}\begin{pmatrix}3&-1\\-5&2\end{pmatrix}=\begin{pmatrix}3&-1\\-5&2\end{pmatrix}$.

02Check: $A A^{-1}=\begin{pmatrix}2&1\\5&3\end{pmatrix}\begin{pmatrix}3&-1\\-5&2\end{pmatrix}=\begin{pmatrix}1&0\\0&1\end{pmatrix}$.

Answer: $\begin{pmatrix}3&-1\\-5&2\end{pmatrix}$
Practice — try first

Find $A^{-1}$ for $A=\begin{pmatrix}1&2\\3&5\end{pmatrix}$.

$\det=5-6=-1$. $A^{-1}=\dfrac{1}{-1}\begin{pmatrix}5&-2\\-3&1\end{pmatrix}=\begin{pmatrix}-5&2\\3&-1\end{pmatrix}$.

Answer: $\begin{pmatrix}-5&2\\3&-1\end{pmatrix}$
5 Cramer's rule
Formula For $A\mathbf{x}=\mathbf{b}$ with $\det A\neq0$: $$x_i=\dfrac{\det A_i}{\det A},$$ where $A_i$ is $A$ with column $i$ replaced by $\mathbf{b}$. Best for $2\times2$ / small $3\times3$ exam questions.
Worked example

$\begin{pmatrix}2&1\\1&3\end{pmatrix}\begin{pmatrix}x\\y\end{pmatrix}=\begin{pmatrix}5\\5\end{pmatrix}$.

01$\det A=6-1=5$.

02$A_x=\begin{pmatrix}5&1\\5&3\end{pmatrix}$, $\det=15-5=10$ $\Rightarrow x=10/5=2$.

03$A_y=\begin{pmatrix}2&5\\1&5\end{pmatrix}$, $\det=10-5=5$ $\Rightarrow y=5/5=1$.

Answer: $x=2,\ y=1$
Practice — try first

Use Cramer on $\begin{pmatrix}3&1\\2&4\end{pmatrix}\begin{pmatrix}x\\y\end{pmatrix}=\begin{pmatrix}7\\10\end{pmatrix}$.

$\det A=12-2=10$. $A_x=\begin{pmatrix}7&1\\10&4\end{pmatrix}$, $\det=28-10=18$ $\Rightarrow x=1.8=\tfrac{9}{5}$. $A_y=\begin{pmatrix}3&7\\2&10\end{pmatrix}$, $\det=30-14=16$ $\Rightarrow y=1.6=\tfrac{8}{5}$.

Answer: $x=\dfrac{9}{5},\ y=\dfrac{8}{5}$
6 Eigenvalues
Method Solve the characteristic equation $$\det(A-\lambda I)=0.$$ Roots $\lambda$ are the eigenvalues. For $2\times2$, expand to a quadratic; factor or use quadratic formula.
Worked example

$A=\begin{pmatrix}4&1\\2&3\end{pmatrix}$.

01$A-\lambda I=\begin{pmatrix}4-\lambda&1\\2&3-\lambda\end{pmatrix}$.

02$\det=(4-\lambda)(3-\lambda)-2=\lambda^2-7\lambda+10=(\lambda-5)(\lambda-2)$.

Answer: $\lambda=5,\ \lambda=2$
Practice — try first

Find eigenvalues of $A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$.

$\det\begin{pmatrix}2-\lambda&1\\1&2-\lambda\end{pmatrix}=(2-\lambda)^2-1=\lambda^2-4\lambda+3=(\lambda-3)(\lambda-1)$.

Answer: $\lambda=3,\ \lambda=1$
7 Eigenvectors
Method For each $\lambda$, solve $(A-\lambda I)\mathbf{v}=\mathbf{0}$. Row-reduce; find a nonzero nullspace vector. Scale to a clean integer vector if possible. (Any nonzero multiple is also an eigenvector.)
Worked example

Continue $A=\begin{pmatrix}4&1\\2&3\end{pmatrix}$ with $\lambda=5$ and $\lambda=2$.

01$\lambda=5$: $A-5I=\begin{pmatrix}-1&1\\2&-2\end{pmatrix}$. Row 2 $= -2\times$ row 1. Equation: $-x+y=0\Rightarrow y=x$. Take $\mathbf{v}_1=\begin{pmatrix}1\\1\end{pmatrix}$.

02$\lambda=2$: $A-2I=\begin{pmatrix}2&1\\2&1\end{pmatrix}$. Equation: $2x+y=0\Rightarrow y=-2x$. Take $\mathbf{v}_2=\begin{pmatrix}1\\-2\end{pmatrix}$.

Answer: $\mathbf{v}_5=\begin{pmatrix}1\\1\end{pmatrix}$, $\mathbf{v}_2=\begin{pmatrix}1\\-2\end{pmatrix}$
Practice — try first

For $A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$, find eigenvectors for $\lambda=3$ and $\lambda=1$.

$\lambda=3$: $A-3I=\begin{pmatrix}-1&1\\1&-1\end{pmatrix}\Rightarrow -x+y=0\Rightarrow \mathbf{v}_3=\begin{pmatrix}1\\1\end{pmatrix}$.

$\lambda=1$: $A-I=\begin{pmatrix}1&1\\1&1\end{pmatrix}\Rightarrow x+y=0\Rightarrow \mathbf{v}_1=\begin{pmatrix}1\\-1\end{pmatrix}$.

Answer: $\mathbf{v}_3=\begin{pmatrix}1\\1\end{pmatrix}$, $\mathbf{v}_1=\begin{pmatrix}1\\-1\end{pmatrix}$
8 Diagonalisation
Method If $A$ has $n$ linearly independent eigenvectors $\mathbf{v}_1,\ldots,\mathbf{v}_n$ with eigenvalues $\lambda_1,\ldots,\lambda_n$: $$P=\begin{bmatrix}\mathbf{v}_1&\cdots&\mathbf{v}_n\end{bmatrix},\quad D=\mathrm{diag}(\lambda_1,\ldots,\lambda_n),\quad A=PDP^{-1}.$$ Check: $AP=PD$ (or compute $P^{-1}$ and verify $P^{-1}AP=D$).
Worked example

Diagonalise $A=\begin{pmatrix}4&1\\2&3\end{pmatrix}$ using the eigenpairs above.

01$P=\begin{pmatrix}1&1\\1&-2\end{pmatrix}$, $D=\begin{pmatrix}5&0\\0&2\end{pmatrix}$ (order must match columns).

02$\det P=-2-1=-3$. $P^{-1}=\dfrac{1}{-3}\begin{pmatrix}-2&-1\\-1&1\end{pmatrix}=\begin{pmatrix}\tfrac{2}{3}&\tfrac{1}{3}\\\tfrac{1}{3}&-\tfrac{1}{3}\end{pmatrix}$.

03Optional check: $PDP^{-1}$ recovers $A$, or verify $AP=PD$.

Answer: $P=\begin{pmatrix}1&1\\1&-2\end{pmatrix}$, $D=\begin{pmatrix}5&0\\0&2\end{pmatrix}$
Practice — try first

Write $P$ and $D$ for $A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$ (use your eigenvectors from §7).

With columns $\mathbf{v}_3,\mathbf{v}_1$: $P=\begin{pmatrix}1&1\\1&-1\end{pmatrix}$, $D=\begin{pmatrix}3&0\\0&1\end{pmatrix}$. ($\det P=-2\neq0$, so diagonalisable.)

Answer: $P=\begin{pmatrix}1&1\\1&-1\end{pmatrix}$, $D=\begin{pmatrix}3&0\\0&1\end{pmatrix}$
