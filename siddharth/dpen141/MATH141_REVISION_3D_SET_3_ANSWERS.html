MATH141 Revision — 3D Analytic Geometry Set 3 — Worked Answers

Full workings for each question

  1. Direction: \((1,1,1)\times(1,-1,0)=(1,1,-2)\).

    Point: set \(z=0\), then \(x+y=0\), \(x-y=1\Rightarrow x=\tfrac12\), \(y=-\tfrac12\). Point \(\left(\tfrac12,-\tfrac12,0\right)\).

    Symmetric: \(\dfrac{x-1/2}{1}=\dfrac{y+1/2}{1}=\dfrac{z}{-2}\).

    \(\dfrac{x-\frac12}{1}=\dfrac{y+\frac12}{1}=\dfrac{z}{-2}\)

  2. \(\overrightarrow{AB}=(-2,2,0)\), \(\overrightarrow{AC}=(-2,0,2)\).

    \(\mathbf{n}=(-2,2,0)\times(-2,0,2)=(4,4,4)\), simplify to \((1,1,1)\).

    Through \(A\): \(x+y+z=2\).

    \(x+y+z=2\)

  3. Normals \(\mathbf{n}_1=(1,0,0)\), \(\mathbf{n}_2=(1,1,1)\).

    \(\cos\phi=\dfrac{|1|}{1\cdot\sqrt3}=\dfrac{1}{\sqrt3}\).

    \(\phi=\arccos\dfrac{1}{\sqrt3}\)

  4. Parametrize: \(x=t\), \(y=1+2t\), \(z=-1-t\). Set \(z=0\): \(-1-t=0\Rightarrow t=-1\).

    Point: \((-1,-1,0)\).

    \((-1,-1,0)\)

  5. \(d=\dfrac{|8+0+2-5|}{\sqrt{4+1+4}}=\dfrac{5}{3}\).

    \(\dfrac{5}{3}\)

  6. Intersection direction of those planes: \((1,1,0)\times(0,1,1)=(1,-1,1)\).

    Line: \(\mathbf{r}=(1,1,1)+\lambda(1,-1,1)\).

    \(\mathbf{r}=(1,1,1)+\lambda(1,-1,1)\)

  7. Second normal \(=(-4,2,-2)=-2(2,-1,1)\), so normals parallel \(\Rightarrow\) planes parallel.

    Constants: if coincident, \(-4x+2y-2z\) should equal \(-2(2x-y+z)=-2\) when first equals \(1\), but right side is \(3\neq-2\). Distinct parallel planes.

    parallel (distinct)

  8. Closest point is along the normal from the origin: \(\mathbf{r}=t(1,1,1)\), with \(t+t+t=3\Rightarrow t=1\).

    Point \((1,1,1)\). Distance \(=\sqrt3\).

    \((1,1,1)\)

  9. Midpoint \(M_{AB}=(1,0,0)\), midpoint \(M_{CD}=(0,1,1)\).

    Direction \((-1,1,1)\). Parametric: \(x=1-t\), \(y=t\), \(z=t\).

    \(x=1-t,\ y=t,\ z=t\)

  10. Plane perpendicular to both given planes has normal parallel to \(\mathbf{n}_1\times\mathbf{n}_2=(1,1,0)\times(0,1,1)=(1,-1,1)\).

    Through \(P\): \(1(x-1)-1(y-2)+1(z-3)=0\Rightarrow x-y+z=2\).

    \(x-y+z=2\)

  11. Directions \(\mathbf{d}_1=(1,0,1)\), \(\mathbf{d}_2=(1,1,0)\).

    \(\cos\theta=\dfrac{|\mathbf{d}_1\cdot\mathbf{d}_2|}{|\mathbf{d}_1||\mathbf{d}_2|}=\dfrac{1}{\sqrt2\cdot\sqrt2}=\dfrac12\Rightarrow\theta=60^\circ=\dfrac{\pi}{3}\).

    \(\dfrac{\pi}{3}\)

  12. Directions \((1,0,0)\), \((0,0,1)\) not parallel. Set \((s,0,1)=(0,1,t)\): \(y\)-coords \(0=1\) impossible \(\Rightarrow\) no intersection \(\Rightarrow\) skew.

    \(\mathbf{d}_1\times\mathbf{d}_2=(0,-1,0)\), \(\mathbf{P}_2-\mathbf{P}_1=(0,1,-1)\).

    \(d=\dfrac{|(0,1,-1)\cdot(0,-1,0)|}{1}=\dfrac{|-1|}{1}=1\).

    skew; distance \(1\)
