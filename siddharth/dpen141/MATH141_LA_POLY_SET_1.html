Set 1 — Block A

Row ops, transpose, determinants, identity · 12 questions (Q10-Q12 polynomial)
  1. Solve by row operations: \(x+y+z=6,\ 2x-y+3z=14,\ 3x+2y-z=2\).
  2. Find RREF and rank of \(\begin{bmatrix}1&2&1\\2&4&0\\1&3&2\end{bmatrix}\).
  3. For \(A=\begin{bmatrix}1&-2&0\\3&4&5\end{bmatrix}\), compute \(A^T\) and \((A^T)^T\).
  4. Verify \((AB)^T=B^TA^T\) for \(A=\begin{bmatrix}1&2\\0&1\end{bmatrix},B=\begin{bmatrix}2&-1\\3&4\end{bmatrix}\).
  5. Compute \(\det\begin{bmatrix}2&1&3\\0&-1&4\\5&2&0\end{bmatrix}\).
  6. Find \(k\) such that \(\det\begin{bmatrix}k&1&0\\2&k&3\\1&0&k\end{bmatrix}=0\).
  7. If \(A=\begin{bmatrix}2&1\\-1&3\end{bmatrix}\), compute \(AI,IA,A^2-5A+6I\).
  8. Prove/disprove: if \(AB=I\) for square matrices, then \(BA=I\).
  9. A matrix has one row multiplied by 4. How does determinant change?
  10. Find remainder when \(P(x)=x^4-3x^3+2x-7\) is divided by \(x-2\).
  11. Determine whether \(x+1\) is a factor of \(Q(x)=x^3+x^2-4x-4\), then factorise \(Q(x)\).
  12. Find \(a,b\) if \(f(x)=x^3+ax^2+bx+12\) has factors \((x-2)\) and \((x+3)\).
