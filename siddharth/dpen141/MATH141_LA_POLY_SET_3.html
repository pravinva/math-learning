Set 3 — Block A

Row ops, transpose, determinants, identity · 12 questions (Q10-Q12 polynomial)
  1. Solve by row ops: \(x+2y+z=3,\ 2x-y+z=0,\ 3x+y-2z=5\).
  2. Find rank of \(\begin{bmatrix}1&0&2&1\\2&1&5&3\\-1&1&-1&0\end{bmatrix}\).
  3. For \(A=\begin{bmatrix}1&2&3\\0&-1&4\end{bmatrix}\), compute \(A^T A\).
  4. Given \(M=\begin{bmatrix}2&1\\1&2\end{bmatrix}\), find \(M^T\) and verify symmetry.
  5. Compute \(\det\begin{bmatrix}4&2&1\\1&3&2\\0&5&-1\end{bmatrix}\).
  6. Find \(k\) where \(\det\begin{bmatrix}1&k&2\\0&3&1\\2&1&k\end{bmatrix}=0\).
  7. If \(A=\begin{bmatrix}1&0\\0&-1\end{bmatrix}\), compute \(A^n\) for odd/even \(n\).
  8. Show \(I\) is the unique identity matrix of order \(n\).
  9. If one row is replaced by row + 3(other row), what happens to determinant?
  10. Find remainder when \(P(x)=x^6-2x^2+3x-5\) divided by \(x-1\).
  11. Test whether \(x+2\) is factor of \(R(x)=x^3-4x^2-x+4\); factorise if possible.
  12. Find \(a,b\) such that \(f(x)=x^3+ax^2+bx+8\) has factors \((x+1)\), \((x-4)\).
