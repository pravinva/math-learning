HSC Extension 2 Integration

Ten HTML lessons covering Howard Ext2 Textbook Chapter 4 (printed pages 264–383): standard forms through definite-integral tricks, each with expanded explanations and a 20-question problem set with worked solutions.

How to use: Work in order. Read the lesson boxes and worked examples first, then attempt every practice card on paper before revealing solutions. Source chapter: HSC Mathematics Extension 2 (Howard), Chapter 4 Integration.
Videos: Each lesson embeds the matching McGrathmatics Ext2 integration video (completing the square → recurrence, plus HSC revision).
