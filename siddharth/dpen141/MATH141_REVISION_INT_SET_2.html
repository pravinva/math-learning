MATH141 Revision — Integration Set 2

12 exam-style questions · Week 11: definite integrals & FTC
Scope: Evaluate definite integrals and use the Fundamental Theorem of Calculus.
  1. Evaluate $\displaystyle\int_0^2(3x^2-1)\,dx$.
  2. Evaluate $\displaystyle\int_1^e\dfrac{1}{x}\,dx$.
  3. Evaluate $\displaystyle\int_0^{\pi/2}\sin x\,dx$.
  4. Evaluate $\displaystyle\int_{-1}^1(x^3+2x)\,dx$ and comment on odd/even structure.
  5. If $F(x)=\displaystyle\int_0^x(t^2+1)\,dt$, find $F'(x)$ and $F'(2)$.
  6. If $G(x)=\displaystyle\int_1^{x^2}\sqrt{t}\,dt$, find $G'(x)$ for $x>0$.
  7. Evaluate $\displaystyle\int_0^1 e^{2x}\,dx$.
  8. Evaluate $\displaystyle\int_0^{\pi/4}\sec^2 x\,dx$.
  9. Find the average value of $f(x)=x^2$ on $[0,3]$.
  10. Evaluate $\displaystyle\int_1^4\dfrac{1}{2\sqrt{x}}\,dx$.
  11. If $\displaystyle\int_a^b f=7$ and $\displaystyle\int_a^c f=2$, find $\displaystyle\int_b^c f$.
  12. Evaluate $\displaystyle\int_0^2|x-1|\,dx$ by splitting at $x=1$.
