40-DAY PLAN

Hands-on MATLAB plan (40 days × 2 h)

Built for Siddharth: programming practice is the priority. Projectile / kinematics physics is already known — skim theory, spend the time writing and running MATLAB scripts in your GitHub repo.

Mining skill path (preferred) 40-day exam plan GitHub setup Practicals Projects Tutorials Tests DPEN100 home
Budget: 40 days × 2 hours = 80 hours.
Treat DPEN100 as a MATLAB programming course with kinematics as coding applications — not another physics course.

Priority order

  1. Code every day — scripts saved in your GitHub repo (dpen100-matlab).
  2. Guides only as needed to unlock that day’s coding.
  3. Skim Guide 4 / dynamics theory — jump to MATLAB of motion graphs.
  4. Skip Excel + long reference pages unless needed for an assessment.

40-day schedule

DaysFocusWhat to do (hands-on)
1 GitHub + MATLAB folder Set up the repo, save the first .m file, commit and push. Follow the GitHub setup guide.

15–20 Guide 3 + plotting Plots, subplots, file I/O. Re-do Lab 6 plots cleanly. Light Python only if it appears in the exam.
21–28 Projects (main effort) Project 1 on days 21–24, Project 2 on days 25–28. Full .m + figures in the repo. Physics: use what you know; spend time on code and plots.
29–30 P8 kinematics coding Translate SUVAT / projectile into MATLAB plots (you already know the physics).
31–36 Tutorials TUT 1–6 Do problems before peeking answers. Skip pure-physics wordings; do every coding / plot question.
37–38 Programming theory test Timed; mark; redo wrong MATLAB / Python questions as scripts.
39–40 Mock final Day 39: sit once timed. Day 40: fix weak coding topics only.

Cut ruthlessly

  • Don’t re-study projectile formulas — code them.
  • Don’t watch all ~40 videos; use 1 short clip per stuck syntax.
  • Excel lessons: skip unless marked assessment.
  • Guide 4 theory: 30–60 minutes total, then coding.

Success check by day 40

Your GitHub repo should contain:

  • Practical scripts (P3–P5, Lab 6, P8)
  • Both projects with exported plots
  • ~20+ small practice .m files
  • One timed mock exam completed (and marked)
Hours fit: ~55–60 h coding + ~15–20 h reading/tests ≈ 80 h, with a little buffer for stuck days.
