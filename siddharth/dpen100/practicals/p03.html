Before you start — key ideas & MATLAB

Concepts & ideas

  • Script vs Command Window: a script (.m) stores a reusable sequence of commands; the Editor lets you edit, comment, and re-run.
  • Structure plan / flowchart: top-down design in pseudo-code before coding — label Input, Operations, Output.
  • Array arithmetic: vectors of time values let you evaluate \(s(t)\) for every \(t\) at once (element-wise .^).
  • Program design process: seven steps from problem statement through testing and documentation.
  • Decision structure: the quadratic solver needs nested decisions for linear / complex / equal / two-real cases.

Q3. Vertical motion under gravity

A stone is thrown vertically upward. Follow the book’s structure plan and produce a script that plots displacement \(s\) against time \(t\).

Use \(g=9.81\,\mathrm{m/s^2}\), \(u=60\,\mathrm{m/s}\), and \(t=0:0.01:12.3\), with \[s = ut - \tfrac12 g t^2.\]

g = 9.81; u = 60;
t = 0:0.01:12.3;
s = u*t - g/2*t.^2;
plot(t,s,'k','LineWidth',3), grid
title('Vertical motion under gravity')
xlabel('time'), ylabel('vertical displacement')
Do. Draw the flowchart for the structure plan, then generate the program from it with plenty of comments. Save as throw.m.

  • \(v_0=0\): trajectory stays at the launch point (range \(=0\)).
