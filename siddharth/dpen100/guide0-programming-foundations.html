Programming Foundations Before MATLAB

Seven short lessons that begin with ordinary calculations and gradually introduce variables, output, scripts, memory and data types. Every lesson ends with a small MATLAB file to run, explain, commit and push to your existing GitHub repository.

Siddharth, you are not “behind” or bad at programming. MATLAB lessons often assume that words such as variable, memory, data type and execute are already familiar. These lessons build that missing bridge carefully. There is no need to understand everything on the first reading. Run each example, change one value, and explain what you observed.

How to explain the answer

The script stores its starting information in meaningfully named variables. MATLAB stores the ordinary numeric values as double, the report title as string, and the approval value as logical. The whole-valued traveller count is also a double by default; a number does not need a visible fractional part to belong to the floating-point double class.

Each assignment statement evaluates the expression on the right of = and assigns its result to the variable on the left. For example, the multiplication expression that calculates the fuel cost uses the stored fuel quantity and price as its operands. The final function calls receive a format string and calculated values as arguments, then display labelled output in the Command Window.

In whos, each ordinary scalar numeric variable is 1 × 1 and normally uses 8 bytes for its stored numeric data. The logical value normally uses 1 byte. The exact byte count reported for text should be read from MATLAB because a string includes internal information as well as its visible characters. Calling class or whos inspects a value; it does not change that value.

Lesson 1 · First contact with code

Calculate and Observe

Begin with something familiar: arithmetic. The aim is not to memorise commands. It is to notice that MATLAB receives an instruction, performs it and shows a result.

By the end: you can enter an arithmetic expression, identify its operators and operands, explain where an unnamed result goes, and describe what a semicolon changes.

A computer does not guess what you intended. It follows instructions. A small engineering program usually follows this pattern:

Inputstarting information
Storekeep useful values
Processperform operations
Outputshow the result

For now, MATLAB will receive a calculation as its input, process the arithmetic and display the output.

Click after the >> prompt in MATLAB's Command Window. Type each line and press Enter.

2 + 3 10 - 4 6 * 7 20 / 5 3^2

An expression is code that MATLAB can evaluate to produce a value. In 6 * 7, the values 6 and 7 are the operands, and * is the multiplication operator. The value 42 is the result.

Say it precisely: “MATLAB evaluates the arithmetic expression 6 * 7 and displays the resulting value, 42.”

If you do not give a result a name, MATLAB places the latest unnamed result in a special variable called ans.

10 / 4 % MATLAB displays: ans = 2.5000

Now compare these two lines:

5 + 3 5 + 3;

Both calculations run. The semicolon only suppresses automatic output. It does not cancel the calculation.

Common misunderstanding: “Nothing appeared” does not mean “nothing happened.” A semicolon tells MATLAB not to display the result automatically.

A vehicle travels 120 km in 2.5 hours. Average speed is distance divided by time.

120 / 2.5

Before pressing Enter, predict whether the answer should be greater or less than 120. Then run it. MATLAB returns 48.

Explain: “The expression divides the distance value by the time value. MATLAB evaluates the expression and displays an average speed of 48 kilometres per hour.”

Change 120 to 150. Predict first, then run the changed expression.

Lesson 2 · Giving information useful names

Values, Variables and Assignment

A calculation becomes reusable when its important values have names. This lesson separates four words that beginners often mix together: literal, value, variable and assignment.

By the end: you can explain an assignment statement from right to left and predict how changing one variable changes a later calculation.
distance = 120;

This line contains several different ideas:

PartCorrect termMeaning here
distanceVariable nameThe name the program will use to refer to the stored value.
120Numeric literalA value written directly in the source code.
=Assignment operatorAssigns the result on the right to the name on the left.
Whole lineAssignment statementOne complete instruction to MATLAB.
Say: “This statement assigns the numeric value 120 to the variable named distance.”

In beginner language, it is acceptable to imagine a labelled container. Just remember that the variable name and its current value are not the same thing.

distance = 120; time = 2.5; averageSpeed = distance / time;

MATLAB handles the final line in this order:

  1. Find the current values of distance and time.
  2. Evaluate the expression distance / time.
  3. Obtain the result 48.
  4. Assign 48 to the variable averageSpeed.
Say: “MATLAB evaluates the expression on the right-hand side first, then assigns the resulting value to the variable on the left-hand side.”
count = 5; count = count + 1;

This would look impossible as an algebraic equation, but it is not an equation. It is an assignment instruction.

  1. Read the current value of count, which is 5.
  2. Evaluate count + 1, producing 6.
  3. Assign the new value 6 back to count.

The old value is replaced. The variable now refers to 6.

lengthMetres = 8; widthMetres = 5; areaSquareMetres = lengthMetres * widthMetres;

Meaningful names make the calculation easier to read. Variable names must begin with a letter, cannot contain spaces and are case-sensitive.

Good names communicate purpose: timeSeconds is clearer than t when a beginner is learning. Short mathematical names become useful later when their meaning is already clear.

Change widthMetres to 6. Predict the new area, run all three statements and observe the Workspace.

Check your understandingUse complete sentences
“The statement assigns the numeric value 10 to the variable named mass.”
x contains 12. MATLAB reads the old value 4, evaluates 4 × 3, then assigns the result 12 back to x.
accelerationMetresPerSecond2 is clearer because it communicates both the quantity and its units. In a familiar formula, a may later be reasonable, but its meaning should be documented.
Variable names cannot contain spaces. Use a valid name such as totalCost or total_cost.

Lesson 3 · Communicating a result

Displaying Results Clearly

A useful program should communicate what its answer means. Begin with disp; then use fprintf when you need text, units and controlled decimal places.

By the end: you can distinguish storing a value from displaying it, use disp, explain MATLAB classes, floating-point values and newlines, and describe the important parts of one fprintf statement.
area = 40; disp(area)

The first statement stores a value under the name area. The second statement calls the disp function and asks it to display that value.

A function is a named piece of code that performs a task. Information supplied inside parentheses is called an input argument. Here, area is the input argument passed to disp.

Say: “The disp function receives the value stored in area and displays it in the Command Window.”
disp("The calculated area is:") disp(area)

Text inside double quotation marks is a MATLAB string. The quotation marks mark where the text begins and ends; they are not displayed as part of the message.

Use disp first. It is simple and keeps attention on the calculation. Introduce formatted output only after storing and displaying values feel comfortable.

MATLAB stores different kinds of information in different ways. A number, some text and a true/false value do not all have the same representation or allow exactly the same operations.

A value's class is MATLAB's precise name for its data type or category. The class tells MATLAB what kind of value it is working with and therefore how that value should be stored and used.

Ask MATLAB for a value's class
temperature = 23.6; class(temperature)

MATLAB displays:

ans = 'double'

class is a built-in MATLAB function. The variable temperature is its input argument. The function examines the value and returns the class name 'double'.

Calling class(temperature) does not convert, round or otherwise change temperature. It only asks MATLAB to report information about the value.

MATLAB classKind of valueSmall example
doubleMATLAB's ordinary numeric class23.6
stringText written with double quotes"Hello"
logicalA true or false valuetrue
For these beginner lessons, read “class” as “MATLAB data type.” Advanced programming gives the word class a broader object-oriented meaning, but that is not needed here.
Say: “The class function reports how MATLAB categorises the value. It returns 'double' for the variable temperature.”

Some quantities are not whole numbers. A temperature might be 23.6°C, a journey might take 2.5 hours, and a calculated area might be 12.75 square metres. A computer needs a way to represent both the whole part and the fractional part of these values.

A floating-point value is a computer's practical representation of a number that may contain a fractional part and may be very large or very small. The name “floating point” refers to the way the number's point can effectively move as the size of the number changes. You do not need to understand its internal bits yet.

temperature = 23.6; class(temperature) % MATLAB reports 'double' area = 40; class(area) % MATLAB also reports 'double'

MATLAB normally stores numbers you type as the floating-point class double. Therefore, temperature is a floating-point value. Surprisingly, area is also stored as a double, even though its current value, 40, happens to be a whole number.

A concrete example

Suppose a vehicle travels 120 km in 2.5 hours:

averageSpeed = 120 / 2.5; % result: 48 class(averageSpeed) % 'double'

The calculated value is 48, but MATLAB still stores it using its ordinary floating-point class, double. “Floating point” describes the computer representation, not whether MATLAB happens to display a decimal point.

Terminology: “floating point” is the general kind of numeric representation. MATLAB calls its usual 64-bit floating-point class double and its smaller 32-bit class single. MATLAB does not normally use a numeric class literally named float.
Say: “The value 23.6 is stored as a double, MATLAB's default floating-point numeric class.”

Text output is arranged in horizontal lines. A newline is an invisible control instruction that ends the current line and makes the next output begin at the left side of the following line. It is similar to pressing Enter while typing a document.

Inside an fprintf format string, MATLAB represents this instruction using \n. The backslash tells MATLAB that the following letter has a special meaning. Together, \n is called an escape sequence. MATLAB performs the newline instruction; it does not normally print a backslash followed by the letter n.

Without newlines
fprintf('Speed = 48 km/h'); fprintf('Calculation complete');

The second message starts immediately after the first:

Speed = 48 km/hCalculation complete
With newlines
fprintf('Speed = 48 km/h\n'); fprintf('Calculation complete\n');

Each \n ends its line, so the output is easier to read:

Speed = 48 km/h Calculation complete

Placing \n at the end of the final message also ensures that MATLAB's next output or command prompt begins on a fresh line.

Do not confuse \n with a semicolon. A semicolon after a MATLAB statement suppresses automatic output. A \n inside an fprintf format string deliberately creates a line break in the text that you are printing.
Say: “The escape sequence \n inserts a newline, ending the current output line so later output begins on the next line.”
fprintf('The area is %.2f square metres.\n', area);

Now the f in %.2f has a meaning: it tells fprintf to insert a floating-point numeric value and show it in ordinary decimal notation.

The \n also has a known purpose: after the area message is displayed, it ends that output line.

Read the statement in parts:

  • fprintf is the function being called.
  • The quoted text is the format string.
  • %.2f is a placeholder for a floating-point value displayed with two digits after the decimal point.
  • \n moves the cursor to a new line after the message.
  • area supplies the value for the placeholder.

If area contains 40, the output is:

The area is 40.00 square metres.
Formatting is not storage. %.2f controls how the value appears in this output. It does not change the variable's data type or permanently round the stored value.
distanceKm = 120; timeHours = 2.5; averageSpeed = distanceKm / timeHours; fprintf('Average speed = %.1f km/h\n', averageSpeed);

Run the four statements. Change the distance to 150 km and predict the output before running them again.

Explain: “The final statement calls fprintf. The format string contains a placeholder requesting one decimal place, and averageSpeed provides the value inserted at that position.”

Lesson 4 · Saving and running instructions

Scripts, Execution and Errors

The Command Window is useful for experiments. A script lets you save a sequence of instructions, run it again and improve it without retyping every line.

By the end: you can create and run an .m script, explain top-to-bottom execution, describe MATLAB's beginner-level execution process, and distinguish three kinds of errors.

An .m file is a text file containing MATLAB source code. Source code is the human-readable set of instructions written by the programmer.

  1. Open MATLAB's Editor.
  2. Create a new script.
  3. Type the code below.
  4. Save it as average_speed.m.
  5. Press Run.
average_speed.m
% Calculate and display average speed distanceKm = 120; timeHours = 2.5; averageSpeed = distanceKm / timeHours; fprintf('Average speed = %.1f km/h\n', averageSpeed);

MATLAB normally executes a script from the first statement to the last statement. A line beginning with % is a comment for the human reader; MATLAB does not execute it as an instruction.

WordMeaning
WriteCreate or edit the source-code instructions.
SaveStore the .m file on the computer's drive.
RunAsk MATLAB to perform the script's instructions.
ExecutePerform an instruction. “Run” and “execute” are closely related in this context.
OutputInformation the program displays, returns or writes.
Say: “I saved the source code in an .m file. When I run the script, MATLAB executes its statements from top to bottom.”

You do not need a separate compile button for an ordinary MATLAB script. When you press Run, MATLAB first parses the code: it examines the structure and identifies names, operators and function calls. It then executes the statements.

MATLAB may automatically compile frequently used operations internally using just-in-time compilation. That is an implementation detail; MATLAB manages it for you.

The useful beginner sequence is: write → save → run → observe → debug. Detailed compiler theory can wait.

Lesson 5 · Only after using variables

Memory, Bits and Bytes

Now that variables are visible in the Workspace, “memory” can refer to something concrete. Binary is introduced only far enough to explain why computers count storage in bits and bytes.

By the end: you can distinguish a saved file from a Workspace variable, use whos, explain bit and byte, and convert a few small binary numbers.

A computer needs somewhere to keep files even when it is turned off. This is called long-term storage. Your photographs, documents, installed programs and saved MATLAB .m files all live on a storage device.

What does SSD mean?

SSD stands for solid-state drive. It is a storage device inside most modern computers. It stores files electronically and has no moving mechanical parts. A saved file remains on the SSD when MATLAB closes or the computer is switched off.

An older kind of storage device is an HDD, or hard disk drive. It stores information on spinning magnetic disks. Both SSDs and HDDs perform the same important beginner-level job: they keep files for later.

You do not need to know which model is inside your computer. In Windows, the main storage device often appears as the C: drive. A folder in that drive can contain your MATLAB repository and files such as average_speed.m.

Your average_speed.m file is therefore saved on long-term storage—usually an SSD in a modern computer. It remains there after MATLAB closes.

When the script runs, MATLAB also needs a fast temporary working area. This is RAM, which stands for random-access memory. MATLAB creates current values such as distanceKm and averageSpeed in RAM and shows them in the Workspace. These temporary Workspace values normally disappear when MATLAB closes unless you deliberately save them.

Helpful first analogy

The SSD or HDD is like a filing cabinet. Files remain there for later, even after the working day ends.

RAM is like the working desk. It holds information being used right now and is cleared when the computer session ends.

Say: “The .m source file is kept on long-term storage, usually an SSD. Running it creates temporary variables in MATLAB's Workspace, which uses RAM.”
distanceKm = 120; timeHours = 2.5; averageSpeed = distanceKm / timeHours; whos

whos reports information such as:

  • Name: the variable name.
  • Size: its dimensions, such as 1 × 1 for one scalar value.
  • Bytes: approximately how much memory its stored data occupies.
  • Class: MATLAB's name for its data type.

Try clear timeHours, then run whos again. clear removes the variable from the Workspace; it does not delete your saved script.

Electronic circuits can reliably distinguish between two states. We represent those states using the symbols 0 and 1.

  • One binary digit is one bit.
  • Eight bits form one byte.
  • n bits can form 2n different patterns.

Binary place values grow by powers of 2:

Binary place8421
11011101

Therefore:

1101 in binary means 1(8) + 1(4) + 0(2) + 1(1) = 13 in decimal.
This is enough for now. You do not need binary multiplication, two's complement or manual floating-point encoding before learning ordinary MATLAB programming.

One bit has two patterns: 0 and 1. Two bits have four patterns: 00, 01, 10 and 11. Eight bits have 28 = 256 patterns.

A pattern has no meaning by itself. A data type supplies the interpretation. A pattern might represent a number, a letter, part of an image or something else.

For a few scalar variables, memory usage is not an important practical concern. It becomes meaningful for large arrays. One million values stored with 8 bytes each require about 8 million bytes of data.

Lesson 6 · Meaning before numeric limits

Data Types—Gently

A data type first answers a practical question: “What kind of information is this value?” It is not necessary to memorise enormous ranges before using ordinary numbers.

By the end: you can use class, recognise ordinary numeric, text and logical values, and explain why %d is not itself a data type.

A data type influences how information is represented, what operations make sense, how much memory is used, and what range or precision is available.

age = 18; temperature = 23.6; studentName = "Siddharth"; labCompleted = true;

x = 25; class(x) % returns 'double' y = int64(25); class(y) % returns 'int64'

The value 25 has no fractional part, but MATLAB still uses its default numeric type, double, unless you deliberately request another class.

int64 is a signed 64-bit integer type for whole numbers. A beginner does not need to memorise its enormous exact limits. Use it only when the task or data specifically requires that type.

Say: “The variable contains an integer-valued number, but MATLAB stores it as a double by default.”

Floating point is a general method for representing numbers over a very wide range, including values with fractional parts. Some programming languages have a type literally named float.

MATLAB's ordinary floating-point classes are:

  • double: 64-bit floating point and MATLAB's default numeric class.
  • single: 32-bit floating point, using less memory but providing less precision.

For normal beginner calculations, use MATLAB's default double. The detailed sign, exponent and fraction fields are explained later in Guide 1 and are not required to complete this lesson.

score = 95; fprintf('Score: %d\n', score);

%d is an output-format instruction inside the format string. It tells fprintf how to present a compatible integer-valued result. It does not declare score to be an int64 variable.

Use class(score) to ask about the stored type. Use the placeholders inside fprintf to control the displayed output.

Do not learn by forcing extreme failures. Assigning a number beyond the largest finite double normally produces Inf, but this boundary case is not useful preparation for ordinary beginner scripts.

“This script calculates and displays the area of a rectangle. The first comment describes the purpose of the script. The next two assignment statements store the rectangle's length and width in meaningfully named variables. MATLAB stores these ordinary numeric values as doubles by default.

The expression lengthMetres * widthMetres multiplies the two values. MATLAB assigns the result to areaSquareMetres. Finally, the script calls fprintf to display a message containing the result and its units. The %.2f placeholder displays the value with two digits after the decimal point.”

  2. Inputs: What starting information does it use?
  3. Variables: What names store the important values?
  4. Processing: Which expressions or functions produce new values?
  5. Order: In what sequence do the statements execute?
  6. Output: What result is displayed, returned or saved?
  7. Assumptions or errors: What input is expected, and what could go wrong?
