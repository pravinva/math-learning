MATLAB Text, Formatting & Data Types — Quick Summary

Use this reference when displaying results, choosing an fprintf formatting operator, or selecting a numeric type.

Category Concept Core rule / purpose Quick example
Output disp(x) Simple, fast viewing. It always finishes the output with a newline. disp('Hi') → Hi
fprintf(...) Precise formatting and mixed text/data output. Include \n when a newline is required. fprintf('Score: %d\n', 95)
Formatting %d or %i Formats a signed integer. Supply integer-valued data or convert it deliberately first. fprintf('%d', 12) → 12
%f Formats a decimal floating-point value. A precision such as %.1f controls decimal places. fprintf('%.1f', 95.67) → 95.7
%e or %E Formats a value using scientific notation. fprintf('%e', 150000) → 1.500000e+05
%% Escapes the formatting operator so fprintf prints a literal percent symbol. fprintf('100%%') → 100%
Data types Signed integer Stores whole numbers that may be positive or negative. int8 range: −128 to 127
Unsigned integer Stores non-negative whole numbers, providing additional positive range. uint8 range: 0 to 255
double MATLAB’s default numeric type for general calculations, including decimal and fractional values. 0.00045 is stored as a double by default
int64 Stores very large positive or negative whole numbers without a fractional part. Minimum: −9,223,372,036,854,775,808
