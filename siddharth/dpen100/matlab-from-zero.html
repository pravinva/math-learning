    Lesson 1 of 13

    What a program is

    A program is a list of instructions the computer follows from top to bottom, one line at a time. MATLAB is a calculator that can also remember results, repeat steps, and make decisions.

    Almost everything in ENGG100 comes down to three ideas:

    Store values so you can use them later. Lessons 2 and 3 cover this: variables and data types.

    Organise many values together. Lesson 4: vectors and matrices.

    Control which instructions run and how often. Lessons 5 and 6: decisions, and loops that repeat lines.

    Functions (named commands that do a job, such as sqrt for square root; Lesson 7) and plotting are tools built on top of those three. When a new term appears, ask which of the three it belongs to. That gives it a place to sit in your head.

    Two places to type

    Command Window. Type one line, press Enter, get an answer immediately. Use it like a calculator and for experimenting.

    Editor (a script, saved as a .m file). A saved list of instructions. Press Run and MATLAB runs every line in order. Lab tasks and assessments go here.

    A built-in is a tool that comes with MATLAB. The function sqrt(number) returns a square root, and the built-in constant pi stores MATLAB's value of π. You can use both without writing them yourself.

    3 + 4 * 2          % MATLAB follows normal maths order: * before +
sqrt(81)           % square root
pi                 % MATLAB already knows pi

    These expressions were not assigned to named variables, so MATLAB placed each latest result in its automatic variable ans:

    ans = 11
ans = 9
ans = 3.1416

    Comments. Anything after a % on a line is a comment: a note for people reading the code. MATLAB ignores it. The grey text in the code boxes on this page is comments. Use them in your own scripts to say what each step does.

    Housekeeping commands

    CommandWhat it does
    clcClears the Command Window text. Variables are untouched.
    clearDeletes every variable. clear x deletes only x.
    close allCloses every plot window. MATLAB calls a plot window a figure; figures are introduced in Lesson 8.
    help nameShort explanation in the Command Window: help sqrt.
    doc nameFull documentation page with examples.

    Start every script with this line, so leftover variables from a previous run cannot affect the new one:

    clc; clear; close all;

    Errors are information

    Red text does not mean you broke anything. It is MATLAB telling you which line it could not understand and why. Read the last line of the message first.

    y * 2
    Unrecognized function or variable 'y'.

    Translation: you used the name y before storing anything in it.

    Two words you will hear often. Syntax is MATLAB's rules for spelling and punctuation, like grammar for code. A syntax error means a rule was broken: a missing bracket, a misspelled name, or—after you learn blocks in Lesson 6—a missing end. A bug is any mistake in a program, and debugging means finding and fixing it.

    Type this in the Command Window. What does MATLAB show?

    (3 + 4) * 2
    ans = 14. Brackets force the addition to happen first, exactly as in maths.
    Lesson 2 of 13 / Store

    Variables: labelled boxes

    A variable is a labelled box that holds a value. You make one by writing a name, an equals sign, and a value.

    x = 5              % put 5 into a box labelled x
speed = 12.5       % names can be words
area = speed * 2   % use boxes to fill other boxes

    In MATLAB, = means store. It does not mean "is equal to". The right side is worked out first, then the result is put in the box on the left.

    Storing a value in a variable this way is called assignment.

    That is why this line, which is nonsense in maths, makes perfect sense in a program:

    x = x + 1          % take what is in x, add 1, put the result back in x

    The semicolon

    A semicolon at the end of a line stops MATLAB from printing the result. The value is still stored.

    a = 10;            % stored, nothing printed
a                  % typing just the name shows the contents

    Semicolons (or commas) also let you put several short commands on one line. Each one still runs in order, left to right:

    x = 2; y = 3; z = x + y

    Naming rules

    • Start with a letter. Letters, digits and underscores only: v_max, t2.
    • Case matters: Speed and speed are two different boxes.
    • Do not reuse names MATLAB already uses. For example, sum and max are built-in functions introduced in Lesson 4; using either as a variable name would hide that tool.

    The Workspace panel lists every box that currently exists and what is in it. ans is the automatic box for results you did not name.

    Seeing what is in the boxes

    The built-in function disp(value) displays a value without its variable name. Text written inside single quotes is a char value; Lesson 3 explains text types. The commands who and whos inspect the Workspace: who lists variable names, while whos also reports size and type.

    disp(x)            % shows only the value, without "x ="
disp('Done')       % shows text
who                % lists the names of all variables
whos               % names plus size and type of each

    disp is the simplest way to show results from a script. Lesson 3 introduces fprintf for formatted output.

    What is in b at the end?

    a = 3;
b = a * 2;
a = 10;
    b = 6. When line 2 ran, a held 3, so 6 went into b. Changing a afterwards does not go back and update b. Lines run once, in order.

    What is in x at the end?

    x = 4;
x = x + 1;
x = x * 2;
    x = 10. 4, then 5, then 10.
    Lesson 3 of 13 / Store

    Data types: why they exist

    Inside the computer, every value is stored as a pattern of 1s and 0s. The same pattern could mean a number, a letter, or a yes/no. The data type is the label that tells MATLAB how to read the pattern and which operations make sense.

    Think of 1/2 written on paper. It could be a fraction or a date. You need to know which before you can do anything with it. Types settle that question.

    The comparison operators > and == ask yes/no questions. For example, 5 > 3 and 7 == 7 both produce the logical value true. Lesson 5 introduces the complete set of comparison and logical operators.

    The types you need now

    TypeWhat it holdsExample
    doubleNumbers. The default for anything numeric.x = 9.81
    charText in single quotes. A row of individual characters.name = 'beam'
    stringText in double quotes. Treated as one piece of text.name = "beam"
    logicalYes/no answers: true (1) or false (0).ok = 5 > 3
    cellA container holding mixed types together.c = {5, 'hi'}

    A cell array uses curly braces because its items may have different types. After c = {5, 'hi'}, the expression c{2} retrieves the second item, 'hi'. Cells are included here only so you can recognise them; the early exercises do not require them.

    Ask MATLAB what type something is with class:

    class(42)          % 'double'
class('42')        % 'char'
class(42 > 10)     % 'logical'

    What goes wrong without types

    '5' + 1
    ans = 54

    Not 6. The text '5' is stored as character code 53, so MATLAB added 1 to 53. This is the reason types matter: the value looks like a number to you, but MATLAB sees a character. Convert explicitly when you need to:

    str2double('5') + 1    % text to number: 6
num2str(6)             % number to text: '6'

    fprintf prints text with values slotted in. Each format specifier marks a slot and says which type goes there, which is why it sits in the data types lesson.

    sprintf and input

    The function sprintf uses the same formatting rules as fprintf, but returns the completed text instead of displaying it. The function input pauses a script and waits for the user to type a value; adding 's' requests text instead of a number.

    msg = sprintf('Area = %.1f', 12.566)   % same as fprintf, but stores the text instead of printing it
r = input('Enter radius: ');           % waits for a number to be typed
name = input('Your name: ', 's');      % the 's' makes it accept text

    Give the type of each:

    class(7)

class(7 == 7)
    'double', 'char', 'logical'. A comparison always produces a logical.

    Square brackets join pieces of text. What does this produce?

    v = 12;
msg = ['Speed: ' num2str(v) ' m/s']
    msg = 'Speed: 12 m/s'. num2str turned 12 into text so it could be joined with the other text.

    fprintf('Radius %.2f m gives area %.2f m^2\n', r, pi*r^2)
    Two slots, two values, filled in order. r is a single number here, so r^2 is fine.
    Lesson 4 of 13 / Organise

    Vectors and matrices

    MATLAB stands for MATrix LABoratory. MATLAB treats every value as a matrix, even a single number. Once you know that, most of the brackets start to make sense.

    A vector is a list of numbers in a single row or a single column.

    A matrix is a grid of numbers arranged in rows and columns. A vector is a matrix with only one row or one column.

    Size is written rows × columns. A 2×3 matrix has 2 rows and 3 columns. A row of four numbers is 1×4. A single number is 1×1, sometimes called a scalar. Rows and columns are the two dimensions of a matrix.

    Building them: square brackets

    r = [1 2 3]          % row: separate with spaces (or commas)
c = [1; 2; 3]        % column: semicolon means "new row"
A = [1 2 3; 4 5 6]   % 2 rows, 3 columns
r'                   % apostrophe: turns the row into a column

    Swapping rows and columns with ' is called transposing.

    Ranges: the colon

    The colon creates values using start:step:stop. The built-in function linspace(start, stop, count) instead creates an exact requested number of evenly spaced values, including both endpoints.

    1:5                  % 1 2 3 4 5
0:2:10               % start:step:stop gives 0 2 4 6 8 10
linspace(0, 1, 5)    % 5 evenly spaced points: 0 0.25 0.5 0.75 1

    Picking items out: round brackets

    Round brackets after a variable name mean "give me the item at this position". Counting starts at 1, not 0. Each item in a vector or matrix is called an element. Its position number is its index, and picking elements by position is called indexing.

    v = [10 20 30 40 50];
v(2)                 % 20
v(end)               % 50: end means the last position
v(2:4)               % 20 30 40
v(2:end)             % 20 30 40 50: from position 2 to the last
A(2, 3)              % row 2, column 3: 6
A(:, 1)              % a lone colon means "all": every row of column 1
v(2) = 99;           % change one item

    The position inside the brackets can be a variable instead of a typed number. MATLAB looks up what is in the variable and uses that as the position:

    v = [10 20 30 40 50];
i = 4;
v(i)                 % same as v(4): 40

    You will need this soon: some functions tell you a position, and you use that number to pick an item.

    The dot: element-wise operations

    Because everything is a matrix, *, / and ^ follow the matrix rules from your maths course: matrix multiplication, matrix division and matrix power. Those rules combine whole rows with whole columns. They do not simply pair up matching items.

    Most engineering calculations want the simple version: element 1 with element 1, element 2 with element 2, and so on. For that, put a dot in front of the symbol. Working item by item like this is called element-wise.

    t = [1 2 3];
t .* t               % 1 4 9   (each times itself)
t .^ 2               % 1 4 9   (each squared)
t ^ 2                % error: a 1x3 matrix cannot be matrix-squared

    Rule of thumb: if you mean "do this to every number", use .* ./ .^. Plain + and - are already element-wise.

    Inspecting a matrix

    These built-ins inspect or create arrays: size returns row and column counts, length returns the larger dimension, numel counts all elements, and isempty tests whether an array has no elements. zeros and ones create arrays of a requested size.

    A = [1 2 3; 4 5 6];
size(A)          % 2 3  (rows, columns)
length(A)        % 3    (the larger of rows and columns)
numel(A)         % 6    (total number of items)
isempty([])      % 1    ([] is an empty matrix)
zeros(2,3)       % 2x3 matrix of zeros, often used to set up a results box
ones(1,4)        % 1 1 1 1

    Maths on whole vectors

    These all take a vector and work on every item, or summarise the vector into one number.

    FunctionResult for v = [4 -1 7 2]
    sum(v)12
    mean(v)3
    max(v), min(v)7, -1
    sort(v)-1 2 4 7 (sort(v, 'descend') reverses)
    abs(v)4 1 7 2
    sqrt, expSquare root, ex, applied to each item
    sin, cosSine and cosine of each angle, where MATLAB expects angles in radians
    log, log10Natural log (ln), base-10 log
    round(2.567, 2)2.57 (round(2.5) is 3)
    floor, ceilRound down, round up: floor(2.9) is 2
    mod(17, 5)2 (remainder). mod(n, 2) == 0 tests for even.
    0/0NaN, short for "Not a Number": the result of a calculation with no answer

    Functions that give back more than one answer

    So far every function has given back one result. Some give back more. max works out two things every time it runs: the largest value, and the position where it was found. How many of those you receive depends on how many boxes you put on the left of the =.

    v = [4 -1 7 2];

m = max(v)           % one box: you get only the value
[m, i] = max(v)      % two boxes: value, then position
    m = 7

m = 7
i = 3

    On the left of =, square brackets do not build a vector. They are a list of boxes to receive the outputs, filled in order. The order is fixed by the function: for max and min, value first, position second. The names are your choice.

    Why the position is useful: it lets you find the matching item in another list. If v holds the stresses of four rods in rod order, position 3 means rod 3:

    stress = [19.89 19.10 19.45 19.49];
[sMax, rod] = max(stress)      % sMax = 19.89, rod = 1

    If you only want the position, put ~ in the first slot. It means "I don't need this output":

    [~, rod] = max(stress)         % rod = 1, value discarded

    min and sort work the same way. help max lists the outputs of any function, in order.

    Printing a table: stacking rows

    Given a vector, fprintf reuses its pattern until every value is used, so one line prints a whole list:

    fprintf('%d\n', [5 10 15])     % one value per line

    To print two or more lists side by side, stack them as rows of a matrix with ;. fprintf reads a matrix column by column, so each column, which is one item from every list, fills one line of the pattern:

    speeds = [10 20 30];
times  = [2 4 5];
fprintf('%d m/s for %d s\n', [speeds; times])
    10 m/s for 2 s
20 m/s for 4 s
30 m/s for 5 s

    The stacked matrix is [10 20 30; 2 4 5]. Its first column is 10, 2, which fills the first line, and so on.

    Given v = 10:10:50, what are v(3), v(end) and v(2:4)?

    v is 10 20 30 40 50. So 30, 50, and 20 30 40.

    Given A = [1 2 3; 4 5 6], what is A(:, 2)?

    Every row of column 2, as a column:
    2
5

    You have distances d = [100 200 300] and times t = [10 20 25]. Write one line for the speed of each trip.

    s = d ./ t gives 10 10 12. Without the dot, d / t attempts a matrix division and gives back a single number, which is not what you want.

    For v = [3 1 2], what does [s, i] = sort(v) give?

    s = 1 2 3 and i = 2 3 1: the positions the sorted values came from.

    For v = [8 3 12 5], what do these give?

    [m, i] = min(v)
[~, p] = max(v)
    m = 3, i = 2, then p = 3. In the second line the largest value (12) is discarded and only its position is kept.

    Times are t = [0 1 2 3] and heights are h = [0 4 6 5]. Write two lines that find the greatest height and the time it happened.

    [hMax, i] = max(h);    % hMax = 6, i = 3
tAtMax = t(i)          % t(3) = 2
    The position from h picks the matching item from t, because both lists are in the same order.

    What prints?

    fprintf('%d-', [1 2 3]); fprintf('\n')
    1-2-3-. The pattern %d- is reused for each value, then the second call ends the line.
    Lesson 5 of 13 / Control

    Logicals: yes/no answers

    A comparison asks MATLAB a question. The answer is a logical value: 1 for true, 0 for false. A program uses these answers to make decisions and to pick out values from a list.

    x = 7;
x > 5                % 1  (true)
x == 3               % 0  (false)

    Symbols that compare or combine values are called operators. + and * are operators too.

    OperatorQuestion it asks
    ==Equal? (Two signs. One sign stores.)
    ~=Not equal? The tilde ~ means NOT.
    < > <= >=Less, greater, or equal versions
    &AND: both true?
    |OR: at least one true?
    ~NOT: flip true and false

    On a vector: one answer per item

    Ask a question of a whole vector and you get a vector of answers. Use that vector of answers inside round brackets and MATLAB keeps only the items marked 1. This is called logical indexing. You will use it whenever you need "only the values that pass a test".

    Try it. Pick a condition and watch which marks survive.

    marks
    marks > 60
    

    


    marks = [45 82 67 91 38];
marks(marks > 60)        % 82 67 91
sum(marks > 60)          % 3: counts the 1s, so 3 students passed 60
marks(marks < 50) = 50;  % replace every mark under 50 with 50
    

    Logical helpers
    

    The function find returns positions where a condition is true. any asks whether at least one value is true, all asks whether every value is true, and strcmp compares two pieces of text.
    

    v = [3 8 1 9 4];
find(v > 4)          % 2 4: the positions, not the values
find(v > 4, 1)       % 2: the second input 1 means "only the first match"
any(v > 8)           % 1: is at least one true?
all(v > 0)           % 1: are all true?
strcmp('steel', 'steel')   % 1: compare two pieces of text
    

    Use strcmp for text, not ==. Text is a row of characters, so 'abc' == 'abd' compares letter by letter and gives 1 1 0, and texts of different lengths cause an error.

    Lesson 6 of 13 / Control
    

    Decisions and loops
    

    So far every line runs once, top to bottom. Control flow means controlling that order: if chooses which lines run, and a loop repeats lines. Each section starts with a special word (if, for, while) and closes with end. The lines between the start and the end are called a block.
    


    if, elseif and else: one answer out of several
    

    Think of a row of doors with a question written on each. MATLAB walks past them in order. It goes through the first door whose answer is "yes" and ignores all the doors after it.
    

      

    • if is the first door. It asks the first question.
      • 

    • elseif means "otherwise, if". It asks another question, but MATLAB only gets to it when every question above it was answered "no".
      • 

    • else is the last door and has no question on it. It is for "anything else": whatever got a "no" from every other door ends up here.
      • 

    

    temp = 25;
if temp > 30
    disp('Hot')
elseif temp > 20
    disp('Warm')
else
    disp('Cold')
end
    

    Follow it with temp = 25. Is 25 more than 30? No, move on. Is 25 more than 20? Yes, so it prints Warm, skips everything else, and jumps to end.
    

    With temp = 10, both questions get "no", so it falls through to else and prints Cold.
    


    Why not just write separate ifs?
    

    if temp > 30
    disp('Hot')
end
if temp > 20
    disp('Warm')
end
    

    With temp = 35 this prints both Hot and Warm, because each if is checked on its own. Joining them with elseif makes them one decision, so only one answer comes out.
    


    The rules
    

      

    • One if, at the start.
      • 

    • As many elseifs as you need, or none.
      • 

    • At most one else, always last, and it never has a question.
      • 

    • If there is no else and every answer is "no", nothing runs. That is allowed.
      • 

    


    Combining conditions on single values
    

    Inside an if or while, && means AND and || means OR for single yes/no values. These doubled operators short-circuit: MATLAB stops as soon as the final answer is known. This can prevent an unsafe second calculation from running.
    

    if x ~= 0 && 1/x > 2
    disp('Condition passed')
end
    

    If x is zero, the first comparison is false, so MATLAB does not evaluate 1/x. Use & and | when comparing whole vectors item by item; use && and || for combined scalar conditions in control flow.
    


    Using the Hot / Warm / Cold code above, what prints for each temperature?
    

    temp = 31
temp = 30
temp = 21
temp = 20
    


    Hot, Warm, Warm, Cold.
    
30 is not more than 30, so the first question says no; 30 is more than 20, so Warm.
    
20 is not more than 20, so both questions say no and else prints Cold. Watch the numbers right on the edge: > and >= give different answers there.
    


    This code has no else. What prints when speed = 40?
    

    if speed > 100
    disp('Too fast')
elseif speed > 60
    disp('Fast')
end
    


    Nothing. Both questions say no, and there is no else door to catch it, so MATLAB goes straight to end.
    


    for: repeat a known number of times
    

    for k = 1:5
    disp(k)               % runs 5 times; k is 1, then 2, ... then 5
end
    


    Looping through a list
    

    The loop variable is just a number, so it can be used as a position (Lesson 4). This visits each item of a list in turn:
    

    marks = [92 47 68];
for k = 1:numel(marks)    % k is 1, 2, 3
    m = marks(k);         % the k-th mark
    fprintf('Student %d scored %d\n', k, m);
end
    

    Use this when each item needs its own decision or text output. If the same formula applies to every item, a vector operation is shorter and needs no loop.
    


    Nested loops: one loop inside another
    

    A nested loop is a loop placed inside another loop. For each single pass of the outer loop, the inner loop completes all of its passes.
    

    for row = 1:2
    for column = 1:3
        fprintf('row %d, column %d\n', row, column);
    end
end
    

    The outer loop has 2 passes. During each outer pass, the inner loop has 3 passes, so the fprintf statement executes 2 × 3 = 6 times. The order is:
    

    row 1, column 1

    Functions: named machines
    

    A function takes inputs, does a fixed job, and hands back outputs. Programmers say a function returns its outputs. You have been using them already: sqrt(81), sum(v), class(x). Round brackets after a function name hold its inputs.
    


    Writing your own
    

    Save this in a file called circleArea.m. The file name must match the function name.
    

    function A = circleArea(r)
    % A is the output, r is the input
    A = pi * r.^2;
end
    

    circleArea(2)              % 12.5664
circleArea([1 2 3])        % works on a vector thanks to .^
    

    Variables created inside a function are private to it. The function only sees its inputs and only returns its outputs. This is deliberate: a function cannot accidentally change or overwrite the variables in your script, so you can reuse it anywhere safely.
    


    Writing a function with several outputs
    

    Lesson 4 showed that max can give back two answers. Now you can see how that is built: list the outputs in square brackets on the first line.
    

    function [total, average] = summary(v)
    total = sum(v);
    average = mean(v);
end
    

    t = summary([2 4 6])             % one box: only total (12)
[t, a] = summary([2 4 6])        % two boxes: total 12, average 4
[~, a] = summary([2 4 6])        % only the average
    

    The built-in max is defined the same way, as if its first line were function [value, position] = max(v). Whoever uses the function chooses how many outputs to collect, from the left.
    


    One function inside another
    

    The input to a function can be the result of another function. Code placed inside other code like this is called nested, like boxes packed inside boxes. MATLAB works from the inside out: the inner function runs first, and its result becomes the input of the outer one.
    

    sqrt(abs(-16))                   % abs(-16) is 16, then sqrt(16) is 4
num2str(find([3 8 9] > 4))       % find gives 2 3, num2str turns that into text '2  3'
    

    If a line with one function inside another confuses you, split it into steps, storing each inner result in a variable first:
    

    a = abs(-16);        % inner step first: 16
b = sqrt(a)          % then the outer step: 4
    

    Both versions do the same thing. The same applies to loops and if blocks: an if inside a for loop (Problem 6) is nested too.
    


    Script or function?
    

    A script is a sequence of steps that works on whatever is in the Workspace. A function is a reusable tool with defined inputs and outputs. Lab tasks usually have a script that calls one or more functions.

    2. One case by hand

    3. Choose the tool
    

    Four rods, the same three formulas, and no rod depends on another. "Corresponding" says the two lists line up item by item, which is exactly what .* and ./ do. Vectors, no loop needed.
    

    Prediction
    

    The trap is to pick rod 4 because it carries the largest load. Area grows with the square of the diameter, so compare load / d2: rod 1 gives 1000/64 = 15.6, rod 2 gives 15.0, rods 3 and 4 give 15.3. Rod 1 should have the greatest stress despite carrying the smallest load.

    As shown in Step 4 above.

    clc; clear; close all;

    Problem 10: Finding the end of the linear regionStretch
    

    A tensile test gives loads of 0, 2, 4, 6, 8, 10 and 12 kN with extensions of 0, 0.10, 0.21, 0.30, 0.41, 0.62 and 0.95 mm. Stiffness at each point is load / extension. Take the initial stiffness as the mean of the first four non-zero points. Find the first load where stiffness drops below 90% of the initial value, print it, and plot load against extension with that point marked.
    

    Practises: everything together: indexing ranges, element-wise division, logicals, find, index offsets, plotting
    


    Break it down
    Given: two matching lists. Find: the load where behaviour stops being linear, and a plot. Rules: k = load / extension; initial k = mean of first four; threshold = 0.9 × initial.
    

    By hand
    Skip the first point (0/0 is undefined). k = 20.00, 19.05, 20.00, 19.51, 16.13, 12.63 kN/mm. Initial = (20 + 19.05 + 20 + 19.51)/4 = 19.64. Threshold = 17.68. First below: 16.13, at 10 kN.
    

    Tool
    Split it into the problems you have already solved: element-wise division (Problem 3), a summary with mean (Problem 4), a condition with find (Problem 4), a plot with a marker (Problem 9). find(..., 1) returns only the first match. One new trap: k starts at data point 2, so position 5 in k is position 6 in the original data. That offset of 1 must be added back.
    


    store loads and extensions
k = load / extension for points 2 to end
k0 = mean of first four k values
idx = first position where k is below 0.9 * k0
data position = idx + 1 (k skipped point 1)
print stiffness list, k0, and the load at that point
plot load vs extension, mark that point
    


    clc; clear; close all;
load_kN = [0 2 4 6 8 10 12];
ext_mm  = [0 0.10 0.21 0.30 0.41 0.62 0.95];

k  = load_kN(2:end) ./ ext_mm(2:end);    % skip point 1: 0/0 gives NaN (Not a Number)
k0 = mean(k(1:4));                        % initial stiffness
idx = find(k < 0.9 * k0, 1);             % first point below 90%
p   = idx + 1;                            % shift back to data position

fprintf('Stiffness (kN/mm): '); fprintf('%.2f ', k); fprintf('\n');
fprintf('Initial stiffness: %.2f kN/mm\n', k0);
fprintf('Linear behaviour ends near %d kN (extension %.2f mm)\n', load_kN(p), ext_mm(p));

plot(ext_mm, load_kN, 'o-')
hold on
plot(ext_mm(p), load_kN(p), 'r*', 'MarkerSize', 12)
hold off
xlabel('Extension (mm)'); ylabel('Load (kN)');
title('Tensile test'); grid on
    Stiffness (kN/mm): 20.00 19.05 20.00 19.51 16.13 12.63 
Initial stiffness: 19.64 kN/mm
Linear behaviour ends near 10 kN (extension 0.62 mm)
    Check
    Matches the hand working at every stage. Forgetting the + 1 would report 8 kN, a wrong answer that still looks reasonable; checking against the hand result is what catches it. With real lab data, replace the two lists with data = readmatrix('test.csv') and take the columns.
