Step-by-step on a Windows PC

Step 1 · GitHub account (Gmail)
  1. Open github.com/signup.
  2. Use your Gmail (or “Continue with Google”) to create the account.
  3. Pick a username, set a password, and finish email verification.
Step 2 · Install GitHub Desktop (easiest on Windows)
  1. Download from desktop.github.com → Download for Windows.
  2. Run the installer; open GitHub Desktop.
  3. Click Sign in to GitHub.com and authorise in the browser.
  4. In File → Options → Git, set your name and the same Gmail address, then Save.
Step 3 · Create a folder for MATLAB work
  1. On Windows, create a folder such as Documents\DPEN100-MATLAB.
  2. Inside it, make subfolders if you like: practicals, projects, plots.
  3. Save your .m scripts here when you work in MATLAB (File → Save As… into this folder).
Step 4 · Create the repository and publish it

In GitHub Desktop:

  1. File → New repository…
  2. Name: e.g. dpen100-matlab (no spaces).
  3. Local path: choose Documents (or the parent of your project folder).
  4. Tick Initialize this repository with a README.
  5. Click Create repository.
  6. At the top, click Publish repository (keep it Private if you prefer, then Publish).

You should now see the repo on github.com under your account.

Step 5 · Everyday workflow (after each practical / project session)
  1. Edit / create MATLAB scripts in your local repo folder.
  2. Open GitHub Desktop — changed files appear on the left.
  3. Tick the files to include → type a short summary (e.g. Add proj1_partA plots).
  4. Click Commit to main.
  5. Click Push origin to upload to GitHub.
Optional · Command line on Windows (if you prefer Git Bash)

Install Git for Windows from git-scm.com, then in your project folder:

git init
git add .
git commit -m "Initial MATLAB project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/dpen100-matlab.git
git push -u origin main

Replace YOUR_USERNAME with Siddharth’s GitHub username. After the first push, later updates are just git add . → git commit -m "…" → git push.

What to put in the repo. MATLAB scripts (.m), exported figures (PNG/PDF), short write-ups, and a README listing which practical/project each file belongs to. Do not upload huge videos, private uni login details, or copyrighted textbook PDFs.
