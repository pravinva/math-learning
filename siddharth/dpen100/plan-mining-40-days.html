40 DAYS + 6 MONTHS

Mine haul-cycle: MATLAB and kinematics, not an exam sprint

Forty days to become fluent in MATLAB by building one open-pit haul model. Six months afterwards, keep the same repo alive with one small feature at a time. Course tests and the mock final stay unused until you later want HD practice.

This plan Mine project spec GitHub setup Practicals Old exam-oriented 40-day plan DPEN100 home
Budget: Days 1–17 at about 90% (~2.5–2.7 h). Days 18–40 at full effort (~3.5 h). Then 45–60 minutes twice a week for six months.
Spine: the mine haul-cycle project. Every new MATLAB idea is used on the truck, the ramp, or the conveyor — not on a throwaway script you never open again.
What this is not. It is not the older plan that ends in tutorials and a timed mock. Skip Excel. Skip the 48 tutorial problems unless a syntax hole appears. Guide 4 is coded into the conveyor projectile, not studied as a second physics course.

Six-month keep-warm

Two sessions a week, 45–60 minutes. Open the repo. Add one extension a month. If run_all.m is broken, that session’s only job is to make it run.

MonthFeature (from the spec)
1Loaded vs empty on the same speed–time axes; print \(\Delta T_{\mathrm{cycle}}\).
2Second, gentler ramp CSV. Same functions. Which ramp wins on tph?
3Waste-dump projectile with different \(v_0,\theta,h\).
4Twenty cycles with a random extra dump wait; histogram of tph.
5Truck marker animation along the centreline.
6Clean-session freeze only. Then optional HD: the course mock, if you want marks later.
Missing a week is fine. Starting a second unrelated MATLAB toy is not — it splits the warm cycle. The mine is the only file you owe these six months.
