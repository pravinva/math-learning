Numerical Integration: The Trapezoidal Rule & Simpson's Rule

Not every integrand has an elementary antiderivative. Numerical integration approximates the area under a curve directly — first with straight-line segments (trapezoids), then with a dramatically more accurate parabola-fitting approach (Simpson's Rule). Start here The big picture — what this week is about

Here is an uncomfortable truth: most integrals cannot be done by hand. There is no elementary antiderivative for $\int e^{-x^2}\,dx$ (the bell curve), for $\int \frac{\sin x}{x}\,dx$, or for the arc-length integrals of most curves — and when your integrand is sensor data, there is no formula at all. When you cannot find an antiderivative, you approximate the area directly from sample values. That is numerical integration.

The strategy is always the same: chop $[a,b]$ into thin strips and approximate the area of each. The trapezoidal rule caps each strip with a straight line; Simpson’s rule fits a parabola through pairs of strips and is dramatically more accurate for the same effort. Just as important as the estimate is the error bound: a formula that tells you, in advance, how many strips guarantee a given accuracy — so you compute no more than you must.

Why this matters

This is how integration actually happens in practice. Every calculator, spreadsheet, and simulation package evaluates definite integrals numerically. CFD (fluid flow), FEA (stress analysis), signal processing, and financial modelling all rest on rules descended from Simpson’s. When the integrand is experimental data — flow rates, accelerations, power readings — numerical integration is the only option, and the error bound is what separates a defensible answer from a guess.

The roadmap — how the pieces connect

We start with the trapezoidal rule and its error term, then upgrade to Simpson’s rule and see why the parabolic fit buys an extra two orders of accuracy. Along the way we use the error formulas backwards — solving for the number of subintervals needed to hit a target precision. This week is as much about disciplined estimation as about theory.

Lay of the land — this week's toolkit
  • Trapezoidal Rule: $T_n=\dfrac{h}{2}\big[f(x_0)+2f(x_1)+2f(x_2)+\cdots+2f(x_{n-1})+f(x_n)\big]$, $h=\dfrac{b-a}{n}$.
  • Trapezoidal error bound: $|E_T|\le\dfrac{(b-a)h^2}{12}\max|f''(x)|$ — error $\propto h^2$.
  • Simpson's Rule (requires $n$ even): $S_n=\dfrac{h}{3}\big[f(x_0)+4f(x_1)+2f(x_2)+4f(x_3)+\cdots+4f(x_{n-1})+f(x_n)\big]$.
  • Simpson's error bound: $|E_S|\le\dfrac{(b-a)h^4}{180}\max|f^{(4)}(x)|$ — error $\propto h^4$, so halving $h$ cuts the error by $16\times$, not just $4\times$.
  • Key fact: Simpson's Rule is exact for any polynomial of degree $\le3$ (its fourth derivative is zero), which is why it usually massively outperforms the trapezoidal rule for the same $n$.

Trapezoid Rule — Theory & Intuition

StudySession · 5:28

Short companion on why the error behaves the way it does.

Open on YouTube ↗

Split $[a,b]$ into $n$ equal subintervals of width $h=\dfrac{b-a}{n}$. On each subinterval, approximate the area under the curve by a trapezoid (rather than a rectangle) — using the straight line connecting $(x_{i-1},f(x_{i-1}))$ and $(x_i,f(x_i))$ as the top edge. A single trapezoid's area is $\dfrac{h}{2}\big(f(x_{i-1})+f(x_i)\big)$.

Summing over all $n$ trapezoids, each interior function value gets counted twice (once as the right edge of one trapezoid, once as the left edge of the next), while the two endpoints are counted once each — giving the $1,2,2,\dots,2,1$ coefficient pattern.

Error. Since each trapezoid replaces a curved top with a straight line, the error depends on how much the function curves (its second derivative). For a concave-up function, the chord sits above the curve, so the trapezoidal rule systematically overestimates such integrals; for concave-down, it underestimates.

Key idea

$$T_n = \frac{h}{2}\Big[f(x_0)+2f(x_1)+\cdots+2f(x_{n-1})+f(x_n)\Big], \qquad |E_T|\le\frac{(b-a)h^2}{12}\max|f''(x)|$$

Worked example

Example. Estimate $\displaystyle\int_0^2 x^2\,dx$ using $n=4$ trapezoids, and bound the error (given $f''(x)=2$).

$h=0.5$; $x_0,\dots,x_4=0,0.5,1,1.5,2$; $f$-values: $0,0.25,1,2.25,4$.

$T_4=\dfrac{0.5}{2}\big[0+2(0.25)+2(1)+2(2.25)+4\big]=0.25(11)=2.75$ (true value $\tfrac83\approx2.667$).

$|E_T|\le\dfrac{2(0.5)^2(2)}{12}=\dfrac{1}{12}\approx0.083$ (actual error was $2.75-2.667=0.083$ — matches almost exactly).

Practice 1

Estimate $\displaystyle\int_0^{\pi} \sin x\,dx$ using the Trapezoidal Rule with $n=6$, and compare with the exact value $2$.

Solution

$h=\pi/6\approx0.5236$; $x_i=0,\pi/6,\pi/3,\pi/2,2\pi/3,5\pi/6,\pi$.

$f$-values: $0, 0.5, 0.8660, 1, 0.8660, 0.5, 0$.

$T_6=\dfrac{h}{2}\big[0+2(0.5+0.8660+1+0.8660+0.5)+0\big]=\dfrac{0.5236}{2}\big[2(3.732)\big]=\dfrac{0.5236}{2}(7.464)=1.954$.

Answer: $T_6\approx1.954$, slightly below the exact value of $2$ (as expected: $\sin x$ is concave-down on this interval, so the trapezoidal rule underestimates).

Practice 2

A function $f$ has $\max|f''(x)|=8$ on $[1,5]$. Find the minimum number of subintervals $n$ (even count not required here) needed to guarantee the Trapezoidal Rule error is less than $0.001$.

Solution

$|E_T|\le\dfrac{(b-a)h^2}{12}\max|f''|=\dfrac{4h^2(8)}{12}=\dfrac{32h^2}{12}=\dfrac{8h^2}{3}$.

Require $\dfrac{8h^2}{3}<0.001 \implies h^2<\dfrac{0.003}{8}=3.75\times10^{-4} \implies h<0.01936$.

Since $h=(b-a)/n=4/n$: $n>4/0.01936\approx206.6$, so $n=207$ (or round up further for a convenient value).

Answer: $n\ge207$.

Practice 3

Estimate $\displaystyle\int_1^3 \ln x\,dx$ using $n=4$ trapezoids (to 4 decimal places), and compare with the exact value $3\ln3-2\approx1.2958$.

Solution

$h=0.5$; $x_i=1,1.5,2,2.5,3$; $f$-values: $0, 0.4055, 0.6931, 0.9163, 1.0986$.

$T_4=\dfrac{0.5}{2}\big[0+2(0.4055+0.6931+0.9163)+1.0986\big]=0.25\big[2(2.0149)+1.0986\big]=0.25(5.1284)=1.2821$.

Answer: $T_4\approx1.2821$, slightly under the exact value $1.2958$ (consistent with $\ln x$ being concave-down, so trapezoidal underestimates).

Practice 4

A car\'s speedometer is sampled every $2$ seconds. The recorded speeds (m/s) are $$v(0)=0,\ v(2)=4,\ v(4)=9,\ v(6)=12,\ v(8)=11,\ v(10)=7.$$ Use the Trapezoidal Rule to estimate the distance travelled over $[0,10]$, and explain whether the estimate is likely high or low if $v$ is smooth and roughly concave-down on the last few intervals.

Solution

$h=2$, $n=5$ subintervals. Values: $0,4,9,12,11,7$.

$T=\dfrac{h}{2}\big[v_0+2\sum_{\text{interior}}v_i+v_n\big]=\dfrac{2}{2}\big[0+2(4+9+12+11)+7\big]=2(4+9+12+11)+7=72+7=79$.

So distance $\approx 79\,\mathrm{m}$.

On late intervals the velocity curve is declining and often concave-down there; chords then sit below the curve, so trapezoidal underestimates locally. Overall bias is mixed, but the late-interval contribution is likely a mild underestimate.

Answer: $\approx 79\,\mathrm{m}$ (with a mild underestimation tendency on the descending part).

Practice 5

For $f(x)=\cos x$ on $[0,\pi/2]$, show that $f''(x)=-\cos x$, hence $\max|f''|=1$. Find the smallest $n$ guaranteeing $|E_T|<5\times10^{-4}$, then compute $T_n$ for that $n$ (or the next convenient larger $n$) and compare with the exact value $1$.

Solution

$f''(x)=-\cos x$, so $|f''|\le 1$ on $[0,\pi/2]$.

$|E_T|\le\dfrac{(b-a)h^2}{12}M=\dfrac{(\pi/2)h^2}{12}$. Need $\dfrac{\pi h^2}{24}<5\times10^{-4}$ $\implies h^2<\dfrac{0.012}{\pi}\approx0.003820$ $\implies h<0.0618$.

$h=(\pi/2)/n$, so $n>(\pi/2)/0.0618\approx25.4$. Take $n=26$.

For a hand-checkable companion, $n=4$ is too coarse for the bound, but the bound itself is the exam target. Computing $T_4$ for illustration: $h=\pi/8$, values $1, \cos(\pi/8),\cos(\pi/4),\cos(3\pi/8),0$.

$T_4\approx\dfrac{\pi/8}{2}\big[1+2(0.9239+0.7071+0.3827)+0\big]\approx0.987$

(still below $1$, as expected for concave-down $\cos$ on this interval). With $n=26$ the bound guarantees error $<5\times10^{-4}$.

Answer: $n\ge26$; $T_4\approx0.987$ (illustration); exact $=1$.

Practice 6

An experimental cooling rate $q(t)$ (kW) is measured at $t=0,1,2,3,4$ minutes: $$q=12.0,\ 10.5,\ 9.4,\ 8.6,\ 8.0.$$ (a) Estimate the energy $\displaystyle\int_0^4 q(t)\,dt$ (kW·min) by the Trapezoidal Rule. (b) If the true energy is later found to be $39.2$, compute the absolute and percentage errors. (c) Without more data, why can you not use the theoretical $|E_T|$ bound here?

Solution

(a) $h=1$; $T_4=\dfrac{1}{2}\big[12+2(10.5+9.4+8.6)+8\big]=\dfrac12\big[12+2(28.5)+8\big]=\dfrac12(12+57+8)=38.5$.

(b) Absolute error $|38.5-39.2|=0.7$. Percentage: $0.7/39.2\times100\%\approx1.79\%$.

(c) The classical bound needs $\max|q''|$ on $[0,4]$, which cannot be read off from five discrete samples alone (and $q$ is empirical, not a known twice-differentiable formula).

Answer: $38.5$ kW·min; abs. error $0.7$ ($\approx1.8\%$); bound unavailable without $q''$ information.

Simpson's 1/3 Rule — Theory & Derivation

StudySession · 8:03

Where the coefficients actually come from (fitting parabolas).

Open on YouTube ↗

The trapezoidal rule fits a straight line across each pair of points. Simpson's Rule instead fits a parabola through each set of three consecutive points, using its area as the approximation instead of two trapezoids — this requires $n$ to be even (so the points pair up completely).

The parabola-fitting calculation produces the weighting pattern $1,4,2,4,2,\dots,4,1$ — odd-indexed points get weight $4$, even-indexed interior points get weight $2$.

Error. Since Simpson's Rule matches any parabola exactly, the error depends on the fourth derivative rather than the second. Because the error bound uses $h^4$ rather than $h^2$, halving $h$ shrinks the error by a factor of $16$, not just $4$ — this is why Simpson's Rule usually converges far faster than the trapezoidal rule.

Key idea

$$S_n = \frac{h}{3}\Big[f(x_0)+4f(x_1)+2f(x_2)+4f(x_3)+\cdots+4f(x_{n-1})+f(x_n)\Big], \quad n\text{ even}$$ $$|E_S|\le\frac{(b-a)h^4}{180}\max|f^{(4)}(x)|$$

Worked example

Example. Estimate $\displaystyle\int_0^2 x^2\,dx$ using Simpson's Rule with $n=4$ (same data as the trapezoidal example).

$h=0.5$; $f$-values: $0,0.25,1,2.25,4$; weights: $1,4,2,4,1$.

$S_4=\dfrac{0.5}{3}\big[0+4(0.25)+2(1)+4(2.25)+4\big]=\dfrac{0.5}{3}(16)=\dfrac83$ — exactly matches the true value, since $x^2$ is itself a parabola (Simpson's Rule is exact for polynomials up to degree 3).

Practice 7

Estimate $\displaystyle\int_0^{\pi} \sin x\,dx$ using Simpson's Rule with $n=6$ (same nodes as the trapezoidal practice question above), and compare with the exact value $2$.

Solution

$h=\pi/6$; $f$-values: $0, 0.5, 0.8660, 1, 0.8660, 0.5, 0$; weights: $1,4,2,4,2,4,1$.

$S_6=\dfrac{\pi/6}{3}\big[0+4(0.5)+2(0.8660)+4(1)+2(0.8660)+4(0.5)+0\big]$

$=\dfrac{\pi}{18}\big[2+1.732+4+1.732+2\big]=\dfrac{\pi}{18}(11.464)=2.0002$.

Answer: $S_6\approx2.0002$ — dramatically closer to the exact value $2$ than the trapezoidal estimate ($1.954$), consistent with Simpson's Rule's much smaller error for the same $n$.

Practice 8

A function $f$ satisfies $\max|f^{(4)}(x)|=16$ on $[0,4]$. Compare the Simpson's Rule error bound for $n=4$ against $n=8$, and verify the factor-of-16 improvement.

Solution

For $n=4$: $h=1$. $|E_S|\le\dfrac{4(1)^4(16)}{180}=\dfrac{64}{180}=0.3556$.

For $n=8$: $h=0.5$. $|E_S|\le\dfrac{4(0.5)^4(16)}{180}=\dfrac{4(0.0625)(16)}{180}=\dfrac{4}{180}=0.0222$.

Ratio: $0.3556/0.0222=16.0$ — exactly the factor of $16$ predicted, since halving $h$ divides $h^4$ by $2^4=16$.

Answer: error bounds are $0.3556$ ($n=4$) and $0.0222$ ($n=8$); ratio $=16$, confirming the $h^4$ scaling.

Practice 9

Estimate $\displaystyle\int_1^3 \ln x\,dx$ using Simpson's Rule with $n=4$ (same nodes as the earlier trapezoidal question), and compare both estimates against the exact value $3\ln3-2\approx1.2958$.

Solution

$h=0.5$; $f$-values: $0, 0.4055, 0.6931, 0.9163, 1.0986$; weights: $1,4,2,4,1$.

$S_4=\dfrac{0.5}{3}\big[0+4(0.4055)+2(0.6931)+4(0.9163)+1.0986\big]$

$=\dfrac{0.5}{3}\big[1.622+1.3862+3.6652+1.0986\big]=\dfrac{0.5}{3}(7.772)=1.2953$.

Answer: $S_4\approx1.2953$, compared with the trapezoidal $T_4\approx1.2821$ and exact value $1.2958$ — Simpson's estimate is roughly $14\times$ closer to the true value than the trapezoidal estimate, despite using the same 5 function evaluations.

Practice 10

Explain why applying Simpson's Rule to $n=5$ subintervals is not directly possible, and describe two valid workarounds.

Solution

Simpson's Rule pairs subintervals into groups of two, fitting one parabola across each pair — this requires the total count $n$ to be even so every subinterval belongs to exactly one pair. With $n=5$ (odd), one subinterval is left over with no partner.

Workaround 1: use $n=6$ instead (round up to the nearest even number), recomputing function values at the extra node.

Workaround 2: apply Simpson's Rule to the first 4 (even) subintervals, then use the Trapezoidal Rule (or another method) on the single remaining subinterval, combining the two partial results — a valid but less commonly used hybrid approach.

Using $f(x)=e^{-x^2}$ values, $T_8\approx0.7462$.

Answer: $T_8\approx0.7462$.

Practice 13

Find the smallest even $n$ guaranteeing Simpson error below $10^{-4}$ for $\int_0^2 \ln(1+x)\,dx$, given $\max|f^{(4)}(x)|=\frac{6}{(1+x)^4}\le 6$.

Solution

$|E_S|\le \dfrac{(b-a)h^4}{180}M=\dfrac{2h^4}{180}\cdot6=\dfrac{h^4}{15}$.

Need $h^4/15<10^{-4}\Rightarrow h<0.1968$.

$h=2/n$, so $n>10.16$; smallest even $n$ is $12$.

Practice 14

Apply Simpson's Rule with $n=4$ to $\displaystyle\int_0^1 \frac{1}{1+x^2}\,dx$ and compare with exact $\arctan(1)=\pi/4$.

Solution

$h=0.25$, values at $0,0.25,0.5,0.75,1$: $1,0.9412,0.8,0.64,0.5$.

$S_4=\frac{0.25}{3}[1+4(0.9412)+2(0.8)+4(0.64)+0.5]\approx0.7854$.

Exact is $\pi/4\approx0.7854$; extremely close.

Practice 15

Explain, with one concrete polynomial example, why Simpson's Rule is exact for degree 3 but generally not for degree 4.

Solution

Error term contains $f^{(4)}$. For cubic, $f^{(4)}=0$, so error bound is zero.

Example: $f(x)=x^3$ gives exact Simpson value. But for $f(x)=x^4$, $f^{(4)}=24\neq0$, so nonzero error generally occurs.

Practice 16

Use Trapezoidal Rule with $n=10$ to estimate $\int_0^2 \frac{1}{1+x}\,dx$, and state whether it over- or underestimates.

Solution

$h=0.2$, compute table values $f(x_i)=1/(1+x_i)$.

Numerically $T_{10}\approx1.1029$.

Since $f''(x)=2/(1+x)^3>0$ (concave up), trapezoidal overestimates. Exact is $\ln3\approx1.0986$.

Practice 17

Use Simpson's Rule with $n=10$ for the same integral in Practice 16 and compare errors.

Solution

Using same nodes and Simpson weights gives $S_{10}\approx1.0986$ (to 4 d.p.).

Error is far smaller than trapezoidal, consistent with $h^4$ vs $h^2$ scaling.

Practice 18

An engineer has function values at 7 equally spaced nodes. Which rule (Trapezoidal/Simpson) can be applied directly over the full interval? Justify using subinterval count.

Solution

7 nodes means 6 subintervals. Simpson needs even $n$; here $n=6$ so Simpson applies directly.

Trapezoidal always applies too, but Simpson is usually preferred for accuracy at same nodes.

Practice 19

Compute $T_4$ and $S_4$ for $\int_0^2 x^3\,dx$, and comment on exactness.

$T_4=4.25$ (not exact). $S_4=4.00$ exactly.

Confirms Simpson exactness for cubic polynomials.

Practice 20

Given $|E_T|\le \frac{K}{n^2}$ and current trapezoidal error tolerance uses $n=40$, estimate required $n$ to make tolerance 9 times tighter.

Solution

Error scales like $1/n^2$. To reduce error by factor 9, multiply $n$ by $\sqrt{9}=3$.

Required $n\approx120$.

Practice 21

Given $|E_S|\le \frac{C}{n^4}$ and Simpson currently uses $n=8$, estimate required $n$ to make tolerance 16 times tighter.

Solution

Need error factor $16$, so $n$ scales by $16^{1/4}=2$.

Required $n=16$ (and still even).

Practice 22

Estimate $\int_0^1 \sqrt{1+x}\,dx$ with $T_6$, then use concavity to state whether the estimate is above or below the exact value.

Solution

Using $h=1/6$, computation gives $T_6\approx1.2199$.

$f''(x)=-\frac{1}{4}(1+x)^{-3/2}<0$ so concave down; trapezoidal underestimates.

Practice 23

A student applies Simpson with weights $1,2,4,2,\dots,4,1$. Explain the structural mistake and consequence.

Solution

Simpson weights must alternate $4,2,4,2,\dots$ on interior nodes starting with $4$ at $x_1$.

Swapping the first interior weight breaks the quadratic interpolation derivation and produces a biased estimate.

Practice 24

Challenge: For fixed node count, why is Simpson often preferred over trapezoidal for smooth functions, and when might trapezoidal still be chosen in practice?

Solution

Simpson has fourth-order error ($h^4$) versus second-order ($h^2$), so accuracy improves much faster as grid is refined.

Trapezoidal may still be chosen for streaming data, odd subinterval counts, simpler implementation, or when function noise makes higher-order fitting less reliable.

Practice 25

The same velocity table as in the new Trapezoidal data problem: $$v(0)=0,\ v(2)=4,\ v(4)=9,\ v(6)=12,\ v(8)=11,\ v(10)=7$$ (m/s, $h=2$). Can Simpson\'s Rule be applied over the whole interval? If not, propose a justified hybrid and compute it.

Solution

There are $6$ nodes $\Rightarrow n=5$ subintervals (odd), so classical Simpson cannot cover the whole interval.

Hybrid: Simpson on first $4$ subintervals ($t=0$ to $8$), trapezoid on last subinterval ($8$ to $10$).

$S_4$ on $[0,8]$ with $h=2$, values $0,4,9,12,11$: $S=\dfrac{2}{3}\big[0+4(4)+2(9)+4(12)+11\big]=\dfrac{2}{3}(16+18+48+11)=\dfrac{2}{3}(93)=62$.

Last trap: $\dfrac{2}{2}(11+7)=18$.

Total $\approx62+18=80\,\mathrm{m}$ (compare pure trapezoidal $79\,\mathrm{m}$).

Answer: not directly; hybrid $\approx80\,\mathrm{m}$.

Practice 26

For $f(x)=e^{x}$ on $[0,1]$, compute $f^{(4)}(x)=e^{x}$ so $\max|f^{(4)}|=e$. Find the smallest even $n$ with $|E_S|<10^{-5}$, then explain why this $n$ is much smaller than the $n$ you would need for the Trapezoidal Rule to the same tolerance (order-of-magnitude argument only).

Solution

$|E_S|\le\dfrac{(1)h^4}{180}e=\dfrac{e\,h^4}{180}$. Need $e h^4/180<10^{-5}\Rightarrow h^4<180\times10^{-5}/e\approx6.62\times10^{-4}\Rightarrow h<0.160$.

$h=1/n\Rightarrow n>6.24$, smallest even $n=8$.

Trapezoidal error scales like $h^2\sim1/n^2$; Simpson like $h^4\sim1/n^4$. For tolerance $\varepsilon$, trapezoidal needs $n\sim\varepsilon^{-1/2}$ while Simpson needs $n\sim\varepsilon^{-1/4}$ — for $\varepsilon=10^{-5}$ that is roughly hundreds vs single digits.

Answer: $n=8$; Simpson\'s $h^4$ scaling needs far fewer strips than trapezoidal\'s $h^2$ scaling.

Practice 27

A flow rate $Q(t)$ (L/s) through a pipe is logged every $0.5$ s for $2$ s: $$Q=3.0,\ 3.6,\ 4.1,\ 4.4,\ 4.5.$$ Estimate the volume $\displaystyle\int_0^2 Q(t)\,dt$ by Simpson\'s Rule. State units.

$h=0.5$, $n=4$ (even). Values $3.0,3.6,4.1,4.4,4.5$.

$S_4=\dfrac{0.5}{3}\big[3+4(3.6)+2(4.1)+4(4.4)+4.5\big]=\dfrac{0.5}{3}\big[3+14.4+8.2+17.6+4.5\big]=\dfrac{0.5}{3}(47.7)=7.95$.

Practice 29

Someone claims: "Since Simpson is exact for cubics, $S_n$ for $\int_0^1 x^4\,dx$ must also be exact for any even $n$." Refute with a calculation for $n=2$, comparing to the exact value $1/5$.

$n=2$, $h=0.5$, values $0, (0.5)^4=0.0625, 1$.

Practice 30

You need $|E_S|<0.01$ for $\int_1^3 \sqrt{x}\,dx$. First find a usable upper bound for $|f^{(4)}|$ on $[1,3]$, then determine the smallest even $n$. (Hint: $f^{(4)}(x)=-\dfrac{15}{16}x^{-7/2}$.)

Solution

$|f^{(4)}(x)|=\dfrac{15}{16}x^{-7/2}$ is maximised at the left endpoint $x=1$: $M=\dfrac{15}{16}$.

$|E_S|\le\dfrac{(3-1)h^4}{180}\cdot\dfrac{15}{16}=\dfrac{2h^4}{180}\cdot\dfrac{15}{16}=\dfrac{h^4}{96}$.

Need $h^4/96<0.01\Rightarrow h^4<0.96\Rightarrow h<0.990$. With $h=2/n$, $n>2.02$. Smallest even $n=4$.

(The bound is loose near $x=1$ but still valid; in practice $n=4$ already gives a small true error.)

Answer: $M=15/16$; $n=4$.

Practice 31

Given the table for $f$ on $[0,1]$ with $h=0.25$: $$f(0)=1.000,\ f(0.25)=0.969,\ f(0.5)=0.882,\ f(0.75)=0.750,\ f(1)=0.607$$ (approximation of $e^{-x^2}$). Compute $S_4$ and state how many function evaluations were required compared with a 5-point Trapezoidal estimate.

Solution

$S_4=\dfrac{0.25}{3}\big[1+4(0.969)+2(0.882)+4(0.750)+0.607\big]$ $=\dfrac{0.25}{3}\big[1+3.876+1.764+3.000+0.607\big]=\dfrac{0.25}{3}(10.247)\approx0.8539$.

Both $S_4$ and $T_4$ use the same five samples; Simpson is not more expensive in function evaluations — only the weights change.

Answer: $S_4\approx0.8539$; same $5$ evaluations as $T_4$.

Practice 32

A student computes Simpson\'s Rule with $n=6$ but uses weights $1,4,4,4,4,4,1$. Identify the conceptual error (what the weights are supposed to encode) and predict the qualitative effect on the estimate for a positive concave-down integrand.

Solution

Correct interior pattern is $4,2,4,2,4$ (parabola on each pair of strips). Using all $4$s treats every interior node as an "odd" midpoint of a parabolic panel, which double-counts/overweights the even nodes that should only glue adjacent panels (weight $2$).

For a positive concave-down function, over-weighting interior points that sit below the chords\' mid-heights typically inflates the estimate relative to true Simpson (often pushing it above the true integral).

Answer: weights must alternate $4,2,\ldots$; all-$4$ overweights even nodes and usually overestimates for concave-down positive $f$.

Practice 33

Compare computational cost vs accuracy: to integrate a smooth $f$ on a fixed interval, which strategy is smarter — Trapezoidal with $n=64$, or Simpson with $n=16$? Justify using big-O error scaling (assume comparable $M_2,M_4$).

Solution

Trapezoidal: $|E_T|\propto h^2=(L/64)^2\propto 1/4096$.

Simpson: $|E_S|\propto h^4=(L/16)^4\propto 1/65536$.

So Simpson with $n=16$ already targets a smaller order of error than Trapezoidal with $n=64$, while using $17$ vs $65$ samples. For smooth $f$, Simpson $n=16$ is the smarter strategy.

Answer: prefer Simpson $n=16$ (better order, far fewer samples).

Practice 34

Estimate $\displaystyle\int_0^1 \frac{1}{1+x^3}\,dx$ using Simpson\'s Rule with $n=4$. Then, without finding the exact antiderivative, explain how you could check plausibility of your answer using a simple bound.

Solution

$h=0.25$; $x=0,0.25,0.5,0.75,1$; $f=1,\ 0.9846,\ 0.8889,\ 0.7037,\ 0.5$ (approx).

$S_4=\dfrac{0.25}{3}\big[1+4(0.9846)+2(0.8889)+4(0.7037)+0.5\big] \approx\dfrac{0.25}{3}(1+3.938+1.778+2.815+0.5)\approx0.836$.

Plausibility: on $[0,1]$, $1/2\le f(x)\le1$, so integral $\in[0.5,1]$. Also $f$ decreases, so a midpoint/rectangle guess around $f(0.5)\approx0.89$ is in the same ballpark as $0.84$.

Answer: $S_4\approx0.836$ (plausible since $0.5<I<1$).

Practice 35

Power $P(t)$ (W) of a device is recorded at $t=0,2,4,6,8$ s: $$P=40,\ 55,\ 62,\ 58,\ 50.$$ Estimate energy $\int_0^8 P(t)\,dt$ (joules) by Simpson\'s Rule. If the recording interval had been every $3$ s instead (forcing an awkward node count), what rule would you fall back to and why?

Solution

$h=2$, $n=4$. $S=\dfrac{2}{3}\big[40+4(55)+2(62)+4(58)+50\big]=\dfrac{2}{3}\big[40+220+124+232+50\big]=\dfrac{2}{3}(666)=444\,\mathrm{J}$.

Every $3$ s on $[0,8]$ gives nodes at $0,3,6$ and leftover to $8$ — not a uniform even-$n$ Simpson grid over the full span. Use Trapezoidal (always works for any $n$) or a Simpson+Trapezoid hybrid on uniform subintervals you can form.

Answer: $444\,\mathrm{J}$; fall back to trapezoidal/hybrid when $n$ cannot be even on a uniform grid.

Practice 36

Show that for any even $n$, Simpson\'s Rule applied to $\int_a^b (Ax^3+Bx^2+Cx+D)\,dx$ must return the exact integral. Then give one reason this fails for a spline-like integrand that is only $C^2$ (continuous second derivative but discontinuous third).

Solution

For a cubic polynomial, $f^{(4)}\equiv0$, so the Simpson error bound is identically zero for every even $n$ — hence exactness.

If $f$ is only $C^2$, $f^{(4)}$ need not exist (or be bounded) on the whole interval, so the classical error theorem does not apply; locally the parabolic fit can be a poor model across a kink in curvature, and the $O(h^4)$ guarantee is lost.

Answer: exact on cubics because $f^{(4)}=0$; $C^2$-only data may break the $h^4$ theory.

Practice 37

Using the known exact value $\int_0^1 e^{-x}\,dx=1-e^{-1}\approx0.632121$, compute the absolute errors of $T_4$ and $S_4$. Verify roughly that the Simpson error is far smaller, consistent with higher order.

Solution

$h=0.25$; $e^{-x}$ values: $1,\ 0.7788,\ 0.6065,\ 0.4724,\ 0.3679$.

$T_4=\dfrac{0.25}{2}\big[1+2(0.7788+0.6065+0.4724)+0.3679\big]=0.125\big[1+2(1.8577)+0.3679\big]=0.125(5.0833)\approx0.6354$.

$S_4=\dfrac{0.25}{3}\big[1+4(0.7788)+2(0.6065)+4(0.4724)+0.3679\big]=\dfrac{0.25}{3}(7.5835)\approx0.6320$.

Errors: $|T-I|\approx0.0033$, $|S-I|\approx0.0001$ — Simpson ~$30\times$ tighter here.

Answer: $T_4\approx0.6354$, $S_4\approx0.6320$; Simpson error much smaller.

Practice 38

Design question: you may evaluate $f$ at most $9$ times. What is the largest even $n$ you can use for Simpson, and how does that compare with the largest $n$ for Trapezoidal under the same budget?

Solution

$n$ subintervals need $n+1$ nodes. With $\le9$ evaluations: $n+1\le9\Rightarrow n\le8$.

Simpson requires even $n$, so max $n=8$ (exactly $9$ points).

Trapezoidal allows any $n$, so also max $n=8$ under the same budget — the difference is accuracy, not the maximum $n$.

Answer: both max out at $n=8$ with $9$ samples; choose Simpson for accuracy.

Practice 39

A noisy laboratory signal is sampled on an even grid. A colleague insists on Simpson "because it is always more accurate." Give two concrete reasons trapezoidal might be preferable for this dataset.

Solution

(1) Measurement noise: Simpson\'s higher-order fit can amplify high-frequency noise (essentially fitting parabolas through jitter), while trapezoidal\'s linear panels average more stably.

(2) If the underlying response is only piecewise-linear / weakly curved, the extra accuracy of Simpson is illusory, and the simpler weights are easier to audit in a lab report.

Answer: noise amplification and limited smoothness / auditability can favour trapezoidal.

Practice 40

Compute $S_2$ and $S_4$ for $\int_0^2 \dfrac{1}{1+x}\,dx$ (exact $\ln3\approx1.0986$). Estimate the observed convergence factor $(E_2/E_4)$ and compare with the theoretical factor $16$ expected from halving $h$.

Solution

$S_2$: $h=1$, values $1,1/2,1/3$. $S_2=\dfrac{1}{3}\big[1+4(0.5)+1/3\big]=\dfrac{1}{3}(1+2+0.333)=1.1111$. Error $E_2\approx0.0125$.

$S_4$: $h=0.5$, values $1,1/1.5,1/2,1/2.5,1/3\approx1,0.6667,0.5,0.4,0.3333$. $S_4=\dfrac{0.5}{3}\big[1+4(0.6667)+2(0.5)+4(0.4)+0.3333]=\dfrac{0.5}{3}(6.6001)\approx1.1000$. Error $E_4\approx0.0014$.

Ratio $E_2/E_4\approx0.0125/0.0014\approx8.9$ — same order as $16$, not exact because the leading-error asymptotic is approached for smaller $h$, and $f^{(4)}$ varies.

Answer: $S_2\approx1.111$, $S_4\approx1.100$; ratio $\sim9$ (order-consistent with $16$).

Practice 41

Challenge: Explain why applying Simpson\'s Rule to $\int_0^1 x^{1/2}\,dx$ with small $n$ can still look decent numerically, yet the classical $|E_S|$ bound involving $\max|f^{(4)}|$ on $[0,1]$ is useless. What practical fix restores a valid bound?

Solution

$f(x)=\sqrt{x}$ has $f^{(4)}(x)$ blowing up as $x\to0^+$ (derivatives of $\sqrt{x}$ are singular at $0$), so $\max|f^{(4)}|$ on $[0,1]$ is infinite — the textbook bound gives no information.

The integral itself is fine ($\int_0^1\sqrt{x}=\tfrac23$), and low-$n$ Simpson can still be numerically close by accident/cancellation, but that is not a certificate.

Fix: integrate on $[\delta,1]$ with a valid bound, handle $[0,\delta]$ analytically or with a specialised singular quadrature; or use a substitution $x=u^2$ to remove the singularity before applying Simpson.

Answer: $f^{(4)}$ unbounded near $0$ voids the bound; regularise by cutoff, substitution, or analytic treatment of the singular end.

Practice 42

Exam-style multi-part. For $\int_0^2 (1+x^2)^{-1}\,dx$: (a) Compute $T_4$ and $S_4$. (b) The exact value is $\arctan2\approx1.1071$. Which estimate is better? (c) Using only the signs of $f\'\'$ / the error formulas\' spirit, did you expect trapezoidal to over- or under-shoot?

Solution

(a) $h=0.5$; $x=0,0.5,1,1.5,2$; $f=1,\ 0.8,\ 0.5,\ 0.3077,\ 0.2$.

$T_4=\dfrac{0.5}{2}\big[1+2(0.8+0.5+0.3077)+0.2\big]=0.25\big[1+2(1.6077)+0.2\big]=0.25(4.4154)\approx1.1039$.

$S_4=\dfrac{0.5}{3}\big[1+4(0.8)+2(0.5)+4(0.3077)+0.2\big]=\dfrac{0.5}{3}\big[1+3.2+1+1.2308+0.2\big]=\dfrac{0.5}{3}(6.6308)\approx1.1051$.

(b) Errors: $|T-I|\approx0.0032$, $|S-I|\approx0.0020$ — Simpson slightly better here.

(c) $f''(x)$ for $(1+x^2)^{-1}$ changes sign on $[0,2]$ (inflection behaviour), so a single global over/under prediction from concavity is unreliable — which matches the small mixed errors observed.

Answer: $T_4\approx1.1039$, $S_4\approx1.1051$; Simpson closer; concavity not uniform so bias direction is mixed.
