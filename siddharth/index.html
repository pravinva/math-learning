Two-Strand Programme
DPEN104 + DPEN143 · three phases
Pre-read, keep-warm, then HD class
Phase 1 is the Nov–Jan first pass, both subjects side by side. Phase 2 is March–June at 45–60 minutes twice a week so the sheets stay warm. Phase 3 is the 13-week in-session class aimed at HD: closed-book tutorials, mixed weekends, timed tests.
